# My tickets

Use this page to submit suggestions, report bugs, and track the review status of your tickets.

## Page purpose

- Submit new tickets, suggestions, or bug reports.
- Browse your submitted tickets with filters and search.
- View full details including reviewer replies and comment threads.
- Edit tickets that are still under review.

## What you will see

### Ticket form

- Type selector: suggestion, bug, or other.
- Contact info field for optional follow-up contact.
- Title and description (required).
- Source page — note which page you were on.
- Reproduce steps — detailed steps to reproduce the issue.

### Ticket list

- Searchable by keyword.
- Filterable by workflow status (`pending`, `processing`, `accepted`, `rejected`, `completed`) and type.
- Each entry shows title, type badge, status badge, priority, and last reply time.
- Click **View detail** to open the full detail drawer.

### Ticket detail drawer

- Full metadata: type, status, priority, submitter, assignee, timestamps.
- Full description and reproduce steps.
- Comment timeline showing reviewer and user replies.
- Reply editor to add comments when the ticket is not in a terminal status.

## Common actions

1. Fill in the form and submit a new ticket or bug report.
2. Search or filter the list to find a specific item.
3. Click a ticket item to view its full detail and reply history.
4. Edit a ticket entry if you need to add more information.
5. Post a comment to communicate with the reviewer.

## Notes

- Tickets in **rejected** or **completed** status cannot be edited.
- Comments are public to the ticket thread — do not include private information.
- The workspace suggestions page (`/workspace/suggestions`) shares the same component and can be embedded in other pages for guests.
