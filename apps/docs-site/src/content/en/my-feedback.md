# My feedback

Use this page to submit suggestions, report bugs, and track the review status of your feedback.

## Page purpose

- Submit new feedback, suggestions, or bug reports.
- Browse your submitted feedback with filters and search.
- View full details including admin replies and comment threads.
- Edit feedback that is still under review.

## What you will see

### Feedback form

- Type selector: suggestion, bug, or other.
- Contact info field for optional follow-up contact.
- Title and description (required).
- Source page — note which page you were on.
- Reproduce steps — detailed steps to reproduce the issue.

### Feedback list

- Searchable by keyword.
- Filterable by workflow status (pending, processing, accepted, rejected, completed) and type.
- Each entry shows title, type badge, status badge, priority, and last reply time.
- Click **View detail** to open the full detail drawer.

### Feedback detail drawer

- Full metadata: type, status, priority, submitter, assignee, timestamps.
- Full description and reproduce steps.
- Comment timeline showing admin and user replies.
- Reply editor to add comments (when the feedback is not in a terminal status).

## Common actions

1. Fill in the form and submit a new feedback or bug report.
2. Search or filter the list to find a specific item.
3. Click a feedback item to view its full detail and reply history.
4. Edit a feedback entry if you need to add more information.
5. Post a comment to communicate with the reviewer.

## Notes

- Feedback in **rejected** or **completed** status cannot be edited.
- Comments are public to the feedback thread — do not include private information.
- The workspace suggestions page (`/workspace/suggestions`) shares the same component and can be embedded in other pages for guests.
