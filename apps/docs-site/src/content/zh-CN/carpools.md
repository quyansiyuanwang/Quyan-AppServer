# 拼车

拼车用于与受信任的朋友通过**私有邀请**共同购买可交付的月卡额度。它不是公开市场：只有车主生成邀请后，被邀请人才能加入。

## 页面流程提示

“我的拼车”页面按“选择套餐 → 邀请成员 → 成员确认 → 提交发车 → 交付完成”展示流程。订单列表会突出当前状态和下一步；移动端使用可换行的步骤卡片，信息仍以订单详情和服务端状态为准。

邀请页在接受前不会猜测订单内容；登录后接受邀请，服务端确认邀请仍有效并返回订单摘要，再进入订单详情。

## 开始前

- 拼车套餐、额度、有效期、最多人数和成团期限以页面当前显示为准。
- 创建订单后，套餐的价格、成本、额度、模型和渠道限制、月卡模板及成团期限会被保存为订单快照。之后管理员编辑套餐，不会改变已创建订单。
- 加入邀请不会立即扣款；确认自己的份额后，系统只冻结你的应付金额，直到订单继续处理或被关闭。

## 创建和邀请

1. 在“我的拼车”选择一个已发布套餐并创建拼车。
2. 查看成团截止时间、成员数和满员时的均分预估。
3. 车主在订单详情中生成邀请链接，可选择 1、24 或 72 小时，默认 24 小时。如果成团截止时间更早，邀请链接会在成团截止时失效。
4. 将链接发给受信任的成员。每个邀请链接只能接受一次；需要邀请多位成员时分别生成链接。历史邀请链接不会在订单时间线中再次显示。如果自动复制失败，请在弹出的提示中手动复制。

邀请页会说明接受后需要完成的操作。链接过期或已使用、订单已满员或已关闭时，将无法加入；过期和已使用的链接可能显示相同的无效提示。如果接受请求中断或结果不确定，请先回到“我的拼车”刷新订单列表，检查状态筛选、搜索条件和其他分页，确认是否已经加入，再决定是否请车主重新邀请。

## 分摊与确认

默认使用**均分**：每位当前活跃成员的付款比例和额度比例会由系统重新计算。新成员加入或成员退出后，系统会清除旧确认并重新计算，因此每个人都需要再次确认。

车主可以进入“高级自定义分摊”，分别设置付款比例和额度比例。两组比例都必须合计 100%。保存高级分摊会释放旧冻结、清除所有确认，并提示成员重新确认。自定义分摊下成员加入或退出时，系统会释放冻结并清除确认，但不会自动重新分配比例；车主应检查并按需调整比例。切回均分会立即重新计算比例、释放冻结并清除确认，成员需要重新确认。

进入自定义模式并修改比例后，点击**保存分摊**才会提交更改；保存前页面显示的应付金额和额度仍是原来的结果。保存成功并重新加载后，核对各成员的金额、额度和确认状态，再通知成员确认。如果保存或重新加载失败，请重新打开订单详情，确认服务端状态后再继续操作。

在截止时间前：

- 每位成员确认自己的份额后，系统冻结其个人应付金额。
- 非车主且未确认的成员可以退出。确认后不能直接退出；请车主先调整分摊以重置确认并释放冻结，再退出。
- 只有车主可以取消仍处于开放状态的拼车；取消会释放所有未扣款冻结。
- 成团截止后，未提交的订单会自动关闭并释放冻结。

## 提交与交付

当所有活跃成员均已确认、付款和额度比例各合计 100% 时，车主可以提交发车。提交时系统从各成员余额扣除已冻结的应付金额；若余额发生变化而无法扣款，提交会失败，请按提示处理。提交后，运营人员会受理并采购交付；页面会显示当前阶段和下一步。

交付完成后，成员可从自己的月卡和 Relay Token 安全入口查看可用资源。拼车页面只展示渠道或交付摘要，**不会显示 Relay token 明文**。

如运营交付失败，系统会记录原因并按订单资金流程退款。请在订单详情中查看失败原因和事件时间线。

## 操作结果不确定时

确认份额、退出、取消或提交后，详情页会重新加载。如果请求中断，或出现成功提示但详情加载失败，页面仍可能显示旧状态。请重新打开订单详情，核对订单状态、成员确认和冻结金额；涉及扣款时还应查看余额和资金流水。确认结果后再决定是否重试；仍无法确认时联系管理员，避免重复操作。
