# 拼车

拼车用于与受信任的朋友通过**私有邀请**共同购买可交付的月卡额度。它不是公开市场：只有车主生成邀请后，被邀请人才能加入。

## 开始前

- 拼车套餐、额度、有效期、最多人数和成团期限以页面当前显示为准。
- 创建订单后，套餐的价格、成本、额度、模型和渠道限制、月卡模板及成团期限会被保存为订单快照。之后管理员编辑套餐，不会改变已创建订单。
- 加入邀请不会立即扣款；确认自己的份额后，系统只冻结你的应付金额，直到订单继续处理或被关闭。

## 创建和邀请

1. 在“我的拼车”选择一个已发布套餐并创建拼车。
2. 查看成团截止时间、成员数和满员时的均分预估。
3. 车主在订单详情中生成邀请链接，并选择邀请链接有效期。邀请链接不能晚于订单成团截止时间。
4. 将链接发给受信任的成员。历史邀请链接不会在订单时间线中再次显示。

邀请页会说明接受后需要完成的操作。链接过期、已使用、订单已满员或订单已关闭时，系统会显示无法加入的原因。

## 分摊与确认

默认使用**均分**：每位当前活跃成员的付款比例和额度比例会由系统重新计算。新成员加入或成员退出后，系统会清除旧确认并重新计算，因此每个人都需要再次确认。

车主可以进入“高级自定义分摊”，分别设置付款比例和额度比例。两组比例都必须合计 100%。保存高级分摊会释放旧冻结、清除所有确认，并提示成员重新确认。

在截止时间前：

- 每位成员确认自己的份额后，系统冻结其个人应付金额。
- 未确认的成员可以退出；退出后会释放其冻结金额。
- 只有车主可以取消仍处于开放状态的拼车；取消会释放所有未扣款冻结。
- 成团截止后，未提交的订单会自动关闭并释放冻结。

## 提交与交付

当所有活跃成员均已确认且成员数满足套餐要求时，车主可以提交发车。提交后，运营人员会受理并采购交付；页面会显示当前阶段和下一步。

交付完成后，成员可从自己的月卡和 Relay Token 安全入口查看可用资源。拼车页面只展示渠道或交付摘要，**不会显示 Relay token 明文**。

如运营交付失败，系统会记录原因并按订单资金流程退款。请在订单详情中查看失败原因和事件时间线。
