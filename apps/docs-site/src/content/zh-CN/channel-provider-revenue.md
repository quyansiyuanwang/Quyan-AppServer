# 渠道供应与收益

此页面面向提供独立中转渠道的用户。你可以提交渠道、查看审核状态，并查看由实际消费产生的收益。

## 提交渠道

提交时只能创建独立渠道。为每个启用的协议格式填写对应上游 URL 与 API Key；密钥仅发送给服务端用于审核和后续转发，提交列表、收益列表和错误提示都不会显示密钥。

提交后渠道会处于待审核状态。管理员可以上架、拒绝或下架渠道，并在上架后调整售价倍率、追加提供者以及为每位提供者配置分成和结算方式。

提交表单还可以配置格式和模型限制、模型映射、缓存读取计费、时段倍率及上下文长度倍率。上线后原提交人不能直接编辑线上配置，只能在“我的修改申请”中提交完整配置申请；申请会显示待审核、已应用或已拒绝状态及审核原因，只有管理员通过后才会一次性应用。

在格式和模型限制中可以使用“探测 /v1/models”读取对应上游的模型 ID。服务端不会保存临时探测凭据，也不会回传密钥。全局定价中能匹配的模型可一键加入限制，未匹配模型仍会保留展示，方便管理员补充定价。

拥有 `RELAY_CHANNEL_REVIEW` 权限的管理员在独立“渠道供应审核”页面处理初始提交和修改申请，并可单独保存倍率、提供者及结算方式。

## 收益与结算

收益只来自实际从消费者余额扣除的金额：失败请求、零扣费和月卡完全覆盖的请求不会产生收益；月卡只覆盖一部分时，只按剩余的实际扣费计算。每笔收益保存发生时的渠道、提供者和比例快照，后续调整不会修改历史记录。

提供者可配置实时、每 N 天、每日固定时刻或手动结算。实时收益会直接进入可消费余额；定时结算按服务端上海时区运行；手动模式可在此页面点击“转入余额”。转入后收益作为独立佣金流水计入可消费余额，不会被记为充值。

同一渠道可以有多位提供者。单个人的比例范围是 0% 到 100%，但总比例可以超过 100%；超出的部分由平台补贴，管理员会在渠道编辑器中明确看到总比例和平台剩余或补贴。
