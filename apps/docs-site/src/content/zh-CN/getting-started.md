# 用户手册

在这里查找账户、产品和管理功能的使用方法。你可以通过目录浏览，也可以搜索页面名称或要完成的操作。

## 开始使用

1. 如果还没有账户，请先阅读[登录与注册]({{DOCS_BASE_URL}}/zh-CN/login-register)。
2. 登录后，在应用的站点切换器中选择需要使用的控制台。可见入口取决于你的权限。
3. 从文档目录选择相应功能，或使用搜索框查找操作说明。切换语言后仍会停留在当前文章。
4. 需要分享说明时，使用页面上的“复制页面链接”。

如果忘记密码，请参阅[找回密码]({{DOCS_BASE_URL}}/zh-CN/forgot-password)。

## 选择控制台

不同产品和管理功能使用各自的站点。站点切换器按用户站点、产品控制台、用户控制台和运营管理分组，仅显示你有权访问的入口。公共首页也提供站点总览。

登录后的站点概览会根据当前站点和你的权限显示相关统计及常用入口。跨站功能会打开对应站点；已知的旧版链接和打开在错误站点的页面会跳转至正确位置，并保留筛选条件和锚点。

## 查找帮助

搜索支持标题、标签和正文。可以输入功能名称，也可以尝试“密码”“余额”或“权限”等关键词。搜索按输入的完整文本匹配；没有结果时，缩短关键词或更换一个词再试。选择结果或在搜索框按 Enter 打开首条结果后，搜索结果仍显示在正文上方；点击结果区的“清除”可收起结果。嵌入应用的窄窗口可能隐藏目录和搜索框，可在较宽窗口或独立文档站中浏览。文档中的功能入口、可用额度和管理操作可能因账户权限及当前服务配置而不同。

在应用中，将鼠标悬停在头像上可以查看账户信息和余额；桌面端右侧的快捷栏提供按权限显示的常用入口。也可以通过[应用]({{APP_BASE_URL}})或 [API 参考]({{SWAGGER_DOCS_URL}})继续操作。
