# 用户手册

在这里查找账户、产品和管理功能的使用方法。你可以通过目录浏览，也可以搜索页面名称或要完成的操作。

## 开始使用

1. 如果还没有账户，请先阅读[登录与注册]({{DOCS_BASE_URL}}/zh-CN/login-register)。
2. 登录后，在应用的站点切换器中选择需要使用的控制台。可见入口取决于你的权限。
3. 从文档目录选择相应功能，或使用搜索框查找操作说明。切换语言后仍会停留在当前文章。
4. 需要分享说明时，使用页面上的“复制页面链接”。该链接指向当前语言的文章，不包含搜索条件、章节锚点或嵌入状态。

窄屏时，点击顶部菜单按钮打开文档导航，或点击“搜索”查找文档。也可以使用 Ctrl+K（macOS 为 Cmd+K）搜索。正文前的“本页目录”可展开查看章节；点击章节后目录自动收起。

代码块提供“复制”和“自动换行”按钮。长代码行默认保持原始结构，可横向滚动查看；需要在当前代码块内折行时，开启“自动换行”。复制的内容不包含按钮和语言标签。

复制按钮依赖浏览器剪贴板权限；无法复制页面链接时，请从地址栏手动复制。在嵌入窗口中，可先打开独立文档站。要分享具体章节，请先点击该章节的目录链接，再复制地址栏中的链接。

如果忘记密码，请参阅[找回密码]({{DOCS_BASE_URL}}/zh-CN/forgot-password)。

## 选择控制台

不同产品和管理功能使用各自的站点。站点切换器按用户站点、产品控制台、用户控制台和运营管理分组。公共首页也提供站点总览。

1. 登录后，点击应用顶部左侧的菜单按钮，打开站点切换器。
2. 从分组或最近访问中选择目标站点。默认在新标签页打开；实际打开方式取决于已保存的偏好。
3. 在目标站点的导航中选择要使用的功能。

入口会根据权限加载结果调整，当前站点和公共站点仍会保留。权限尚未加载完成时，可能暂时显示更多入口；入口可见不保证能访问页面或执行操作。找不到所需功能时，先确认登录账户，再请管理员核对权限。

登录后的站点概览会根据当前站点和你的权限显示相关统计及常用入口。看到部分数据加载失败的提示时，使用概览的刷新按钮重试，不要将缺失的统计视为零。

跨站入口会打开对应站点。可识别的旧版链接和打开在错误站点的页面会跳转至正确位置，通常保留筛选条件和锚点；部分敏感参数会被移除，可能需要重新登录或重新发起操作。

## 查找帮助

搜索支持标题、标签和正文。可以输入功能名称，也可以尝试“密码”“余额”或“权限”等关键词。搜索按输入的完整文本匹配；没有结果时，缩短关键词或更换一个词再试。选择结果或在搜索框按 Enter 打开首条结果后，搜索结果仍显示在正文上方；点击结果区的“清除”可收起结果。嵌入应用的窄窗口可能隐藏目录和搜索框，可在较宽窗口或独立文档站中浏览。文档中的功能入口、可用额度和管理操作可能因账户权限及当前服务配置而不同。

登录后，在应用的非嵌入页面中，将鼠标悬停在顶部头像上可以查看账户信息和余额；桌面端的非公共站点还提供右侧快捷栏，常用入口随权限加载结果调整。也可以通过[应用]({{APP_BASE_URL}})或 [API 参考]({{SWAGGER_DOCS_URL}})继续操作。
