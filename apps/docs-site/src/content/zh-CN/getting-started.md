# 用户手册

这是站点公开的双语用户手册。整体布局保持 API 文档站的阅读节奏，但内容改为按真实界面逐页说明，重点是“用户怎么用”。

## 手册如何组织

- 每个 Vue 页面对应一篇手册页面。
- 每篇页面都会说明可见区域、常见操作和使用说明。
- API 风格的参考内容仍会保留为独立页面，例如 `api-documentation`。

## 如何使用

1. 从左侧目录或搜索框查找页面。
2. 打开与你当前正在使用的界面同名的文档页。
3. 切换语言时保持当前文档页不变。
4. 需要分享帮助时，直接复制当前页面链接。

## 多站点导航

应用按职责和产品使用独立的站点地址：AI 中转、开发者应用和 RAM 使用各自的用户控制台；云终端只使用 `terminal`，默认打开产品概览，工作区和订阅与设备管理分别位于 `/workspace` 和 `/subscriptions`。KV、短链、密钥、状态、验证码、IP 地理位置、推送和 OJ Submitter 也分别使用独立的产品控制台，并使用与功能对应的能力路径。开发者产品不再提供统一目录总览。`management` 及其产品子域用于运营管理。左上角的站点切换器按用户站点、产品控制台、用户控制台和运营管理分组，只显示你拥有至少一个功能权限的入口，并跳转到其规范地址；公共首页也提供同样的站点总览抽屉。停用的旧域名不会迁移，会直接拒绝访问。

运营管理站点的访问控制按职责分为概览、身份管理和权限管理。身份管理包含用户、用户组和角色；角色会打开 RAM 控制台。权限管理把用户级授权、权限来源查看和权限诊断分别放在独立页面，便于区分修改与排查。

登录后的桌面界面右侧提供贴底的快捷图标栏，按权限显示账户自助服务、在线工具、工单和文档入口；将鼠标悬停在图标上可查看功能名称。点击末尾箭头会完全隐藏图标栏，仅在右下边缘保留展开按钮；该按钮可上下拖动，再次点击即可恢复。点击跨站功能时会直接打开它的规范站点地址。

顶栏头像悬停后会展开账户菜单，显示账户名称、账户 ID 和当前账户余额。点击账户名称或 ID 可复制对应内容，余额区域可进入余额记录。

旧版链接或复制到错误站点的已知页面会自动迁移到正确页面，并保留链接中的筛选参数和锚点。无法识别的地址仍会显示未找到页面。

已登录用户可在左侧边栏底部切换原版前端和多域名前端。原版运行在独立的 `legacy` 地址，不会出现在产品站点切换器中；切换时会尽量打开等价页面。没有新版等价页面的原版功能会回到新版首页。出于账户安全考虑，链接中的登录令牌和未验证回跳参数不会随版本切换传递。
