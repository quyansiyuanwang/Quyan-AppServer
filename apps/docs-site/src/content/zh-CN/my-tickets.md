# 我的工单

提交建议、报告 Bug 或其他问题，并在同一张工单中查看处理进度、补充信息和回复处理人员。

## 使用前提

登录后，在账户站点打开“我的工单”。提交、查看自己的工单、编辑和评论分别需要对应权限；如果表单、列表或操作不可见，请联系管理员确认权限。

IAM 强制模式下，列表只展示获准查看的本人工单，总数也只统计这些工单。列表、详情、修改和评论分别授权：能在列表中看到工单不保证能打开详情或修改。公开回复仅对提交者和有权查看该工单的审核人员可见，不是公开发布到全站。

## 提交工单

1. 选择“建议”“问题”（Bug）或“其他”，填写标题和描述。报告 Bug 时，建议说明发生时间、预期结果和实际结果。
2. 按需填写联系方式、来源页面和复现步骤。仅填写处理问题所需的信息，不要提交密码、Access Key 或中转 Token 等凭据。
3. 点击“提交工单”。成功后，表单清空，列表回到第一页，并尝试打开新工单详情。
4. 核对新工单标题和内容。现有筛选条件会保留，新工单不一定符合筛选；列表中找不到时先重置筛选。

标题和联系方式各最多 200 个字符，来源页面最多 500 个字符；描述、复现步骤和每条回复各最多 5000 个字符。标题、描述和回复不能只包含空白。

## 查看处理进度

1. 输入工单编号、标题或描述中的关键词，点击“搜索”或按 Enter。清空关键词也会重新查询；搜索不检索评论内容。
2. 按状态或类型筛选。更改筛选会立即查询并回到第一页；使用分页控件查看其他结果。
3. 点击“查看详情”，核对标题后查看处理人、描述、复现步骤和公开评论时间线。需要更新时，点击列表或详情中的“刷新”。

| 状态                   | 是否可继续编辑或回复                               |
| ---------------------- | -------------------------------------------------- |
| 待处理、处理中、已采纳 | 有相应权限时可以。已采纳不等于已完成。             |
| 已拒绝、已完成         | 不可以；若仍有问题，可另行提交工单并说明关联情况。 |

本页只能操作自己的工单；处理状态、优先级和负责人由审核人员维护。内部审核备注不会显示给提交者。

## 修改工单内容

1. 在列表中点击“编辑”，或在详情中点击“将当前内容填入编辑器”。已保存内容会载入工单表单。
2. 修改类型、标题、描述或其他提交信息，点击“保存修改”。联系方式、来源页面或复现步骤留空保存会清除对应的已有内容。
3. 若要放弃修改，点击“取消编辑”。编辑时点击“重置”仅将表单恢复为默认内容，不会退出当前工单的编辑模式；重新选择编辑可再次载入已保存内容。

## 补充信息与回复

1. 打开目标工单详情，确认标题和状态正确。
2. 在回复区填写补充内容，点击“发送回复”。成功后回复草稿清空，页面重新加载详情和列表。
3. 查看评论时间线，确认回复已经保存。

切换工单或关闭详情抽屉不会清空未提交的回复。每次发送前都应确认当前工单和草稿；不再需要的草稿可用回复区的“重置”清空。已提交的评论在本页没有编辑或删除入口。

## 常见问题

| 情况                             | 处理方法                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 搜索、翻页或刷新失败             | 页面可能保留上次成功加载的列表和总数。重新刷新并等待成功，再判断当前筛选下是否有工单。                   |
| 打开详情失败，仍看到上一张工单   | 关闭抽屉并重新打开目标工单；确认标题正确且加载成功后再编辑或回复。                                       |
| 创建、保存或回复后没有看到新内容 | 列表或详情刷新可能失败。先刷新并核对保存结果，再决定是否重试；请求超时或中断时也应先核对，避免重复提交。 |
| 已创建的工单不在列表中           | 重置筛选，确认当前登录账户；仍找不到时请管理员核对查看权限。创建权限不自动授予列表或详情权限。           |
| 编辑或回复按钮消失               | 检查工单是否已拒绝或已完成，并请管理员确认对应权限。                                                     |
