# IP 定位

IP 定位将公网 IP 标准化为国家、地区、城市、ASN、运营商和数据来源，适合地域展示、风控辅助和内容本地化。结果会缓存 24 小时，以降低延迟和供应商调用量。

## 数据源

平台优先使用 `IP_GEOLOCATION_ENDPOINT` 配置的通用 HTTP(S) 定位供应商。该端点留空时，会自动使用已有的百度 IP 定位适配器；只需在部署环境配置 `BAIDU_IP_LOCATION_AK`，无需把密钥传给客户端或写入产品实例。

百度适配器返回中国、省份、城市和完整地址（如供应商提供）。百度响应不包含 ASN 或运营商时，这两个标准化字段会是 `null`，数据来源为 `baidu`。

## API

查询需要 IP 定位查询权限：

```http
GET /v1/products/ip-geolocation/8.8.8.8
Authorization: Bearer dpk_...
```

返回字段会在供应商可用数据范围内提供国家、地区、城市、ASN、运营商、完整地址和数据来源。不要把定位结果当作用户真实身份、精确位置或访问授权的唯一依据。

## 校验、额度与隐私

私网、回环、保留地址和非法 IP 会在平台侧直接拒绝，不会请求第三方供应商，也不会消耗额度。运营管理可按账号设置日免费额度、实例上限和超额扣费；调用审计用于核对使用量。请只查询业务上必要的地址，并遵守适用的数据保护要求。
