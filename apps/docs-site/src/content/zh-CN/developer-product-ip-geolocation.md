# IP 定位

IP 定位将公网 IP 标准化为国家、地区、城市、ASN、运营商和数据来源，适合地域展示、风控辅助和内容本地化。结果来自可配置供应商，并使用短期缓存以降低延迟和供应商调用量。

## API

查询需要 IP 定位查询权限：

```http
GET /v1/products/ip-geolocation/8.8.8.8
Authorization: Bearer dpk_...
```

返回字段会在供应商可用数据范围内提供国家、地区、城市、ASN、运营商和数据来源。不要把定位结果当作用户真实身份、精确位置或访问授权的唯一依据。

## 校验、额度与隐私

私网、回环、保留地址和非法 IP 会在平台侧直接拒绝，不会请求第三方供应商，也不会消耗额度。运营管理可按账号设置日免费额度、实例上限和超额扣费；调用审计用于核对使用量。请只查询业务上必要的地址，并遵守适用的数据保护要求。
