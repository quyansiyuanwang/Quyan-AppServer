# 我的远程终端产品

在远程终端的“我的远程终端产品”页面浏览已发布方案、购买或续期权益，并为自己的设备生成 Agent 安装命令。连接设备后执行命令的操作在[远程终端]({{DOCS_BASE_URL}}/zh-CN/remote-terminal)控制台完成。

## 开始前

- 登录后确认当前身份有权查看方案、本人权益和设备，并执行需要的购买、令牌或解绑操作。能看到方案不代表有权购买，能看到设备也不代表有权连接或解绑。
- 页面顶部显示余额，三个页签分别为“已发布方案”“我的权益”和“我的设备”。只有启用且已发布、当前身份可访问的方案才会显示。
- 当前页面仅加载本人权益和设备各自的前100条，没有翻页入口。列表不全时，请联系管理员或使用获授权的分页接口核对；不要据此认定权益不存在、设备没有绑定或仍可新购。
- 顶部“刷新”会尝试探测设备，并重新获取方案、权益、设备、会话和余额。任一数据请求失败时，页面会保留此前的数据；先成功刷新再核对。页面的时间更新只用于重算状态和估价，不会持续从服务端刷新列表。

## 购买或续期

### 新购权益

1. 在“已发布方案”中确认计费单位、单价、最低和最高购买数量、设备及终端配额范围、限购规则。
2. 选择新购，填写名称、购买单位数、设备数和终端数。设备数和终端数表示购买后的配额，至少一项大于0。方案未提供的计费项目不能购买；单价为0的项目仍可提供。
3. 核对预估价格和明细，点击“领取”，在确认框中确认本次购买。免费方案也通过此流程领取。
4. 成功后到“我的权益”确认有效期和配额，并核对余额。新购从购买时开始生效。

计费中的1周为7天，1月为30天，不按自然月计算。新购金额按“购买单位数 ×（设备单价 × 设备数 + 终端单价 × 终端数）”计算。价格、限额和可购买状态由提交时的服务端配置决定；续期或升级同样使用方案当前价格。

### 合并到已有权益

1. 在同一方案的购买表单中选择合并，并选择本人已有的同模板权益。
2. 填写追加的购买单位数，以及合并后的设备、终端总配额。例如原有2台设备，需增加1台时填3，不是填1。配额不能降低。
3. 核对目标、费用和追加时长后提交，成功后刷新目标权益。

未到期权益保留原生效时间，从原到期时间追加时长；待生效权益不会因此提前生效。已过期但仍启用的权益从本次购买时重新计算生效时间。已禁用的权益不能合并；当前候选列表可能仍列出它们，选中不代表服务端会接受。

**当前限制：**页面允许合并时填写0单位，并提示可仅升级配额，但服务端要求正整数，且不得低于方案最低购买单位数，因此0单位升级会失败。请按方案最低要求填写追加时长；如只想升级而不续期，请先联系管理员确认处理方式。

### 理解估价与实际扣款

合并时，服务端分别计算原配额的追加时长费用，以及新增配额从当前有效区间到合并后到期时间的费用。新增配额的覆盖时长向上取整到天，再按当前计费单位比例计价；待生效权益从原生效时间起算，过期权益只计本次追加时长。费用保留4位小数。

当前页面明细采用“新总配额续期费 + 原剩余时长的配额升级费”，剩余时长向上取整到小时，而页面估价又向上取整到整数。这与服务端的天数和金额精度不同，**预估金额可能与实际扣款不同**，确认框也显示预估金额。对金额有疑问时，先联系管理员确认，再购买；成功后以资金流水核对实付。

每次续期或升级只扣本次费用。权益的购买金额记录历次累计实付，不会再次按累计金额扣款；免费续期保留累计金额。余额不足以支付本次服务端费用时购买失败。

## 安装并注册设备

### 选择安装令牌

设备配额大于0的权益可用于注册设备。只有终端配额的权益不能签发设备注册或安装令牌。安装对话框可打开不代表权益已经生效；实际注册仍检查权益状态、有效期、令牌和剩余设备名额。

| 凭据         | 获取方式与注意事项                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 安装令牌     | 首次打开对话框默认新签发，当前有效期为15分钟；它不是只能使用一次的令牌，仍受授权、权益和配额限制。到期后重新获取，不要反复运行过期命令。 |
| 长期注册令牌 | 勾选使用长期令牌时，只读取当前列表已经返回的明文，不会自动找回或轮换。其有效期沿用现有令牌设置，“长期”不代表永不过期。                   |

对话框会在本页保留长期令牌选项，再次打开时请检查所选类型。IAM 强制模式下列表不返回长期令牌明文，勾选此选项会得到空令牌；取消勾选以重新签发安装令牌。令牌签发失败时先处理报错。

IAM 强制模式下，新购权益不会同时创建长期注册令牌，而设备注册仍要求该令牌记录存在且有效。首次购买后若尚未创建，请先使用“轮换 Token”创建，再重新获取安装令牌。已存在但被禁用或过期的长期令牌也会阻止安装令牌完成注册；轮换保留旧到期时间，过期问题需联系管理员调整。

### 生成并执行命令

1. 在“我的权益”点击“安装 Agent”，选择设备实际的 Linux、Windows 或 macOS，以及 x64 或 arm64 架构；默认 Linux/x64 不会自动识别你的目标机器。
2. 确认版本。版本列表来自服务端，首次成功加载时预选返回的首项，也支持手动输入。请确认该版本确实提供对应系统和架构的文件；列表加载失败时重试，不要把空版本的命令当作可用命令。
3. 检查令牌和下载地址。命令可能在令牌为空或获取失败时仍显示，请确认完整后再复制；复制后检查剪贴板内容。
4. 在目标设备的可信终端中执行下载及启动操作。Windows 优先使用标注为推荐的 PowerShell 命令；下载报错时先处理错误，确认文件下载成功后再启动，避免运行目录中遗留的旧文件。
5. 回到页面刷新“我的设备”，确认注册记录；再点击“连接设备”进入控制台，选择设备和 Shell 后连接。此按钮仅打开控制台，不会自动连接或选中当前行设备。

在 Linux 或 macOS 的 bash/sh 中，页面生成命令开头的 `RTC_REGISTRATION_TOKEN="..."` 只传给下载程序，不会传给后面的 Agent。请将该赋值改为 `export RTC_REGISTRATION_TOKEN="..."` 并单独执行，再运行后续下载、赋予执行权限和启动命令；使用后执行 `unset RTC_REGISTRATION_TOKEN`。

后台运行选项会为 Agent 追加 `start` 参数，不代表已配置系统服务或开机自启。代理选项只影响生成命令的下载步骤；以 HTTP(S) 开头的值被当作下载反向代理地址，不能据此认定 Agent 连接也经过同一代理。

安装命令含凭据，不要公开分享；注意命令历史可能保留令牌。安装失败时先检查版本、架构、令牌有效性、权益是否生效和设备名额，不要反复购买来解决注册错误。

## 轮换长期注册令牌

在有设备配额的权益行点击“轮换 Token”并确认。成功后旧令牌立即不能用于新的注册，请更新仍保存旧注册令牌的安装脚本或 Agent 配置。页面不提供到期时间编辑，本次轮换沿用已有令牌到期时间；已过期的令牌不会因此获得新的有效期。

IAM 强制模式下，列表不返回 Token 明文，需要获授权的轮换操作取得新 Token。页面会尝试复制新 Token，即使提示复制成功，也请在安全位置确认剪贴板内容。如果未取得明文，可再次轮换并使用最新 Token。

服务端明确拒绝轮换时原令牌保留；请求超时或连接中断时结果可能不确定，请再次轮换取得最新令牌，再更新配置。

## 解绑设备

1. 在“我的设备”找到不再使用的设备，点击“解绑”。
2. 阅读弹窗中的滚动窗口、已用和剩余次数，以及重新绑定的冷却时间。这些值由管理员配置，同一权益的设备共享解绑次数。
3. 勾选已阅读确认后提交。按钮可点击不代表仍有次数，服务端会重新检查；次数用完或解绑被关闭时会拒绝。
4. 成功后刷新，设备从当前绑定列表中移除。解绑只撤销平台绑定，不会卸载设备上的 Agent；如不再使用，请同时在设备上停止它。

重新绑定同一设备需等待冷却时间，并重新通过有效权益、设备配额和令牌检查。解绑提示只是打开弹窗时的快照；其他操作或配置变化都可能影响最终结果。

## 常见问题

| 现象                         | 处理方法                                                                                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 购买成功后仍显示旧权益或余额 | 操作可能已成功，但随后刷新失败。先成功刷新，再核对权益和资金流水，不要立即重复购买。                                                                  |
| 购买或续期超时、连接中断     | 结果可能未知。刷新本页及[账户余额与转出]({{DOCS_BASE_URL}}/zh-CN/balance-history)中的资金流水，确认新权益、目标权益变化和扣款；仍不确定时联系管理员。 |
| 方案、权益或设备消失         | 检查刷新是否成功、当前身份和权限、方案发布状态，以及本页前100条的显示限制。空列表不一定表示已删除。                                                   |
| 安装令牌尚未到期却注册失败   | 检查权益、配额和令牌状态；IAM 强制模式下，授权或身份变化也会使令牌提前失效，请重新获取。                                                              |
| 解绑超时或刷新失败           | 先成功刷新设备列表并重新读取解绑提示，再决定下一步，避免把旧的剩余次数当作当前值。                                                                    |

## IAM 权限与资源范围

启用 IAM 强制模式后，解绑使用 `quyan:remote_terminal:RevokeMyDeviceBinding`，查看解绑提示使用 `quyan:remote_terminal:GetMyUnbindReminder`。两个操作均需获准访问本人绑定的 `acs:remote-terminal:*:<accountId>:product-binding/<userId>/<bindingId>` 和所属权益的 `acs:remote-terminal:*:<accountId>:product-entitlement/<userId>/<entitlementId>`；访问其他用户的绑定始终拒绝。已登录用户可查看自己的解绑提示，解绑仍需对应权限。次数限制按权益共享，并发解绑也不会超过剩余额度；操作期间授权或次数配置发生变化会使操作失败。

本人注册令牌轮换使用 `quyan:remote_terminal:RotateMyRegistrationToken`，同时检查权益 `acs:remote-terminal:*:<accountId>:product-entitlement/<userId>/<entitlementId>` 和令牌 `acs:remote-terminal:*:<accountId>:product-registration-token/<userId>/<entitlementId>/<tokenId>`。登录身份保留本人轮换能力，匹配的显式拒绝仍会阻止操作；首次创建可对当前权益下的令牌使用 `*`。服务端明确拒绝轮换时原令牌保留；如果请求超时或连接中断，轮换结果可能不确定，请再次轮换以取得最新令牌，再更新 Agent 配置。

安装令牌签发使用 `quyan:remote_terminal:GetMyInstallToken`，资源为 `acs:remote-terminal:*:<accountId>:product-entitlement/<userId>/<entitlementId>`。已登录用户保留本人权益的签发能力，匹配的显式拒绝仍会阻止操作；其他用户权益或设备额度为零时不能签发。服务端在返回令牌前复查权益和授权，操作期间变化时不返回凭据。安装令牌仍按响应中的到期时间失效，安装协议保持不变。

在 IAM enforce 模式下，新安装令牌绑定签发主体及当时的授权、身份和权益修订。设备注册时还会重新检查这些信息；策略撤销、签发用户停用或身份修订变化、角色会话撤销、AccessKey 撤销或过期、权益配置变化都可能使尚未到期的令牌失效。此时请重新获取安装令牌。来源 IP、HTTPS 等条件按设备实际注册请求检查，不沿用签发时的浏览器属性。

设备名额检查、绑定保存和令牌使用记录在同一次授权事务中完成；授权失败不会留下新绑定，也不会返回新的设备心跳凭据。重新启用已禁用设备同样占用设备名额，已解绑设备还受现有冷却规则约束。旧格式的安装令牌可在 legacy/shadow 模式继续使用，enforce 模式需要重新签发。新格式令牌在回退授权模式后仍保持原有 IAM 限制。长期注册令牌仍采用其原有有效性和轮换规则。

IAM 强制模式下，购买及续期使用 `quyan:remote_terminal:ClaimPublishedTemplate`，同时检查本人用户资源、已发布商品 `acs:remote-terminal:*:<accountId>:published-template/<userId>/<templateId>` 和最终权益。商品资源表示向该身份开放的已发布套餐，不授予平台模板管理权限。认证用户保留购买本人资源的能力，匹配的显式 Deny 仍可阻止购买。余额扣减、交易流水与权益变更在同一事务中提交；授权失败时不会返回权益或凭据，扣款一并回滚。续期只收取本次续期或升级费用，权益中的购买金额记录累计值。购买结果不返回注册凭据，获取凭据需另行使用注册令牌轮换操作。

个人权益列表使用 `quyan:remote_terminal:ListMyEntitlements`，在计算总数及分页之前逐项检查 `product-entitlement` 资源，拒绝的权益不会出现在列表中。模板名称、注册令牌元数据及已注册设备数量还需要同一 Action 对对应关联资源的读取权限；权限不完整时省略相关字段。IAM 强制模式下，列表不会返回注册令牌明文，获取凭据需使用单独授权的令牌轮换操作。列表始终限制为当前身份的权益，即使其他用户属于同一账号也不会混入。

个人设备列表使用 `quyan:remote_terminal:ListMyDevices`，先逐项检查 `product-binding` 资源，再计算总数和分页，拒绝的设备不会出现在列表中。父权益被拒绝时省略权益名称，注册令牌资源被拒绝时省略令牌引用。列表只返回支持的 Shell 名称，不读取心跳凭据或完整主机快照。设备和所属权益必须归属于当前身份，归属关系不一致时拒绝读取。

在 IAM 强制模式下，已发布套餐列表使用 `quyan:remote_terminal:ListPublishedTemplates`，逐项检查 `acs:remote-terminal:*:<accountId>:published-template/<userId>/<templateId>`。只显示已启用、已发布且当前身份可访问的套餐。显式 Deny 可隐藏指定套餐或全部套餐。查看套餐不授予购买或管理平台模板的权限，这些操作使用独立 Action。
