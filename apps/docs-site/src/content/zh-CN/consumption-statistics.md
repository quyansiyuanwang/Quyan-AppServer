# 消耗统计

此页面用于分析用户、模型、渠道和转发 Token 维度的使用量。

## 管理权限

此页面展示部署范围的消费报告，包括报告中的筛选候选与维度明细。启用 IAM 强制授权时，需要实际部署管理员组中的 `SYSTEM_CONSUMPTION_STATS_READ`，并允许 `quyan:system:GetConsumptionStatistics` 操作 `acs:platform:*:platform:system/consumption-stats`。普通账户所有者和账户内策略不能自行取得部署级管理资格。

时间、用户、模型或渠道筛选只调整报告内容，不能替代管理授权。服务端在读取前和返回前检查授权；显式 Deny、管理员组资格失效或角色会话撤销都会拒绝返回报告。查看个人消费请使用个人账单与消费记录页面。

## 页面用途

- 按时间和资源维度筛选使用数据。
- 比较不同渠道、模型和用户的趋势。
- 查看汇总总量和明细表。
- 使用正则表达式对模型名、渠道名等进行高级筛选。

## 你会看到什么

### 筛选区域

- 时间范围筛选。
- 用户、模型、渠道、转发 Token 的多选筛选（支持关键词搜索和正则表达式）。
- 当前选择的筛选标签。

### 汇总与图表

- 汇总卡片（总请求数、总 Token 量、总费用等）。
- 每日趋势图。
- 渠道分布图。
- 模型分布图。
- 用户分布图。移动端仅显示每日趋势图。

### 明细表

- 渠道表。
- 模型表。
- 用户表。

## 统计口径

- 报告根据所选日期内的 API 使用扣费和月卡覆盖记录统计，并按关联的使用记录归并；未关联使用记录的交易不计入。请求数反映这些已归并的记录，不能直接作为所有转发请求的总数。
- 总费用包含余额扣款金额和月卡覆盖金额，不等同于余额实扣。对账时请结合余额管理查看扣款明细。
- 每日趋势展示费用和请求等数据；渠道图展示费用最高的前 8 项，模型和用户图各展示费用最高的前 10 项。完整维度请结合下方明细表查看。

## 常见操作

1. 先选择与事件或账期对应的时间范围。
2. 再用用户、模型、渠道或 Token 条件缩小范围。
3. 先看汇总卡片，再进入明细表。
4. 对比分布图找出集中点或异常点。
5. 排查特定模型系列时，可在模型筛选框输入正则（如 `gpt-4.*`），选择匹配项后点击**应用筛选**。搜索只缩小候选列表，不会自动选择匹配项。

## 说明

- 某个维度未选择任何选项时，该维度不限制结果；选择选项后点击**应用筛选**更新报告。筛选标签显示当前选择，可能与尚未更新的报告不同；点击刷新或更改日期也会提交当前选择并重新查询。
- 在筛选框内搜索后，**全选**、**反选**和**清空**只影响当前搜索结果，其他已选项会保留。清空搜索后再操作可处理全部候选项。
- 刷新或更改日期后，页面会按新返回的候选项移除不再可选的已选项，并可能再次查询；加载完成后请重新核对筛选范围。查询失败时报告可能仍显示先前结果，或显示尚未完成同步的中间结果；请重试并确认加载成功后再使用数据。
- 过多筛选条件可能掩盖整体趋势，当总量异常时应适当放宽条件。
- 此页既适合性能分析，也适合成本排查。
- 如果要处理单个用户的财务修正，应进一步查看余额管理或业务日志。
- 需要 `SYSTEM_CONSUMPTION_STATS_READ` 权限。
