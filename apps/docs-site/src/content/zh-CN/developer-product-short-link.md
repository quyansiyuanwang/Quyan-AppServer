# 短链接

短链接将目标 HTTP(S) 地址映射为便于分享的短代码，适合活动、下载和渠道归因。你可以在实例内管理链接、修改目标、设置失效时间，并查看访问统计。

## 使用前提

创建启用的短链接产品实例，并取得所需权限：

| 操作                         | 产品权限                    |
| ---------------------------- | --------------------------- |
| 查看列表、复制链接和查看统计 | `product:short_link:read`   |
| 创建、修改、启用或停用链接   | `product:short_link:write`  |
| 删除链接及管理实例、Key      | `product:short_link:manage` |

IAM 强制模式还会分别检查列表、创建、修改、删除和统计动作。统计包含访客信息，应只授予需要查看的主体。实例及授权说明见[开发者产品总览]({{DOCS_BASE_URL}}/zh-CN/developer-products-overview)。

链接管理使用控制台登录身份，公开访问不需要产品 API Key。资源按实例管理，但公开短代码在当前部署中全局唯一，不能在不同实例重复使用同一自定义代码。

## 创建并分享

1. 打开短链接产品控制台，进入目标实例详情，点击创建短链接。
2. 填写完整的目标 URL。地址最长 2000 个字符，必须使用 HTTP 或 HTTPS，不能含用户名或密码；目标主机须可解析，内网或保留地址可能被拒绝。
3. 可选填写自定义代码：3～80 个小写字母、数字或连字符；留空由平台生成。代码已被使用时需更换。
4. 可选设置过期时间。要立即可用，请使用未来时间；设置过去时间会使链接创建后即无法跳转。
5. 保存后点击列表中的“复制”，看到复制成功提示后再分享完整地址。

公开入口为当前部署 API 地址上的 `GET /s/{code}`。复制失败时检查剪贴板权限和浏览器安全上下文；复制出的地址异常时，联系管理员核对控制台的 API 地址配置，不要自行猜测域名。

列表的启用状态只表示链接开关，不保证链接未过期或额度充足。实际分享前请访问一次验证；这次验证也会计入真实访问和产品用量。

## 修改、暂停与删除

- **编辑**：修改目标 URL 或过期时间，代码不变。清空过期时间后保存会移除原到期限制。编辑使用已加载的列表数据，长时间停留后应先重新加载。
- **停用或启用**：点击对应开关按钮后立即提交，没有额外确认。停用阻止后续公开跳转；重新启用不会清除过期时间，过期链接还需调整有效期。
- **删除**：需要确认，会删除链接及其访问明细，控制台无法恢复。不要把删除理解为永久保留短代码；以后创建同代码链接可能使原地址再次有目标。

修改目标会影响之后使用同一短地址的访问，已经发生的跳转不会被收回。链接在处理中的访问可能赶在停用或删除之前完成。需要长期保留控制权时，可停用链接并保留记录。

创建、修改、启停和删除后会重新加载列表。刷新失败时，即使出现操作成功提示，仍可能保留旧数据；点击错误提示中的“重试”并核对结果。列表没有自动轮询；页面顶部刷新只更新实例列表，关闭并重新打开详情可重读链接。

请求超时或连接中断时，先重新加载并确认结果再重试。自动生成代码的创建请求重复提交可能生成多条链接；不能把超时当作未创建成功。

## 公开跳转与费用

公开入口成功时返回原生 `302` 和 `Location` 目标地址，没有 JSON 成功信封，不要求访问者提供 Key。平台不会代理下载目标内容，返回跳转也不代表访问者成功打开目标网站。

暂停、过期、已删除、实例停用或产品停用的链接不会正常跳转。额度或余额不足、调用记录写入失败等也可能阻止跳转。链接控制台可管理不等于公开入口一定可用。

每次公开跳转处理都会按短链接产品规则计量。同一账号下的短链接实例共享每日额度，按服务端日历日期统计；免费额度、超额开关和单价以当前产品配置为准。重复访问、预览和自动化抓取也可能产生用量。单价为零时仍会统计请求数，执行失败的额度退回可能延迟。

控制台创建、编辑和查看统计不经过公开跳转计量接口。点击记录在返回跳转前保存，因此可能已产生统计，但客户端未收到跳转，或后续记录调用失败。不要将统计点击数直接当作成功到达目标的人数或计费次数。

## 查看访问统计

在实例链接列表中选择“统计”。页面默认展示最近 30 个自然日，含当天截至查询时刻，时间按 UTC+8 计算；当前页面不支持自选日期、导出或自动刷新。点击刷新会重新查询当前页及汇总。

| 指标       | 含义                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 累计点击数 | 链接保存的历史点击计数，不限于最近 30 天                              |
| 期间访问数 | 最近 30 个自然日的点击记录数                                          |
| 独立 IP 数 | 期间不同 IP 数，不等于独立访客；缺失 IP 不计入去重                    |
| 按日趋势   | 期间按 UTC+8 自然日汇总，无记录日期可能不显示                         |
| 按小时趋势 | 将期间所有日期按一天中的小时合并，不是连续 30 天的逐小时曲线          |
| 排行与明细 | IP 排行最多 20 项，来源域名最多 10 项；明细每页 25 条，按访问时间倒序 |

来源只保存 Referer 的主机名，不保存完整来源路径；缺失或无法解析的来源显示为直接访问，不能据此证明访客手动输入了地址。国家/地区来自请求携带的信息，不是经过核验的 IP 定位。User-Agent 等字段可能缺失或被截断。

统计加载失败时页面会显示错误并隐藏统计内容，点击刷新后再读取。不同页面和汇总来自实时查询，翻页期间有新访问时可能变化，不是固定快照。

点击明细按超过 90 天的规则由后台任务清理，实际清理时点取决于任务运行；累计计数不会因此归零。删除链接会同时删除其明细。统计含访客 IP、时间和客户端信息，请按业务需要控制查看权限。

## 管理 API 与细粒度授权

实例控制台使用登录会话访问 `GET /v1/products/short_link/instances/{instanceId}/links`，在关联项目上检查 `quyan:developer:ListShortLinks`，返回实例的链接列表，不逐链接过滤。创建需要项目上的 `CreateShortLink`；修改、删除和统计分别检查具体链接的 `UpdateShortLink`、`DeleteShortLink`、`GetShortLinkStats`。

需要逐链接过滤时，使用 `GET /v1/developer/projects/{projectId}/short-links/page`。它接受 `page`、`pageSize`，返回 `items`、`page`、`pageSize`、`hasNext`，没有 `total`。IAM 强制模式先分页候选再按链接授权过滤，空页也可能有后续页；旧数组列表只返回默认第一页。

单个链接 ARN 为 `acs:developer:*:<accountId>:short-link/<projectId>/<linkId>`，末段是链接 ID，不是公开代码。优先使用项目管理响应中的 `resourceArn`。创建权限不自动授予新链接的后续管理权限，列表权限也不自动允许读取访客统计。暂停或过期链接仍可由有权限的主体管理。更多规则见 [RAM 管理]({{DOCS_BASE_URL}}/zh-CN/ram-management)。

## 常见问题

| 现象                         | 处理方法                                                       |
| ---------------------------- | -------------------------------------------------------------- |
| 创建失败或代码冲突           | 检查全局代码是否被使用，核对目标地址格式、解析和可用范围       |
| 显示启用但访问失败           | 检查过期时间、实例及产品状态、额度和余额                       |
| 看不到统计或提示无权限       | 单独核对统计动作授权，列表可见不代表可读访客明细               |
| 累计点击与期间记录不一致     | 二者时间范围不同，且旧明细可能已清理；计数也不证明目标站已打开 |
| 切换实例或刷新失败后仍有列表 | 可能保留上一批数据；成功重载后再修改或删除                     |
