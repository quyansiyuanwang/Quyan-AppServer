# 短链接

短链接将一个受控的目标 URL 映射到短代码，适合活动链接、下载地址、渠道归因和需要集中失效控制的分享链接。短链资源由实例隔离，创建、编辑和统计均在产品控制台完成。

## 创建与发布

创建时填写完整的 HTTP(S) 目标地址，可让平台生成代码，也可填写 3 至 80 位的小写字母、数字和连字符自定义别名。可选过期时间用于活动到期自动失效。创建后可在列表中点击“复制”获取完整公开链接；看到复制成功提示后再分享。如果复制失败，请检查浏览器的剪贴板权限或在支持剪贴板的安全环境中重试。也可暂停、恢复或修改目标地址和过期时间；短代码不能在编辑时修改。编辑时清空过期时间并保存会移除到期限制，链接不会再按原时间自动失效。删除需要确认，删除后链接不可再使用。

公开访问地址为 `GET /s/{code}`。该入口返回原生 `302` 跳转，不需要 API Key，也不会套用 JSON 响应包装。暂停、过期或不存在的代码不会跳转。公开跳转计入该产品实例的用量；可用额度、超额价格和余额要求以当前产品配置为准，实例或产品停用、额度不足等情况也可能导致跳转失败。

## 统计与隐私

在短链接实例列表中，找到目标链接并点击“统计”进入统计页面；可使用页面上的刷新按钮更新数据。成功处理的跳转会记录点击时间、访客 IP、来源域名、User-Agent 和请求提供的国家/地区信息。统计页面展示累计点击数，以及最近 30 个自然日（含当天截至查询时刻）的访问数、独立 IP 数、按日和按小时趋势、IP 和来源排行及分页明细；时间按 UTC+8 计算。独立 IP 数按 IP 去重，不等同于独立访客人数。累计点击数不受该 30 天窗口限制；点击明细在 90 天后清理，因此累计点击数与近期明细数量可能不同。统计包含访客信息，应只授予需要查看统计的主体。

读取、写入和删除分别由短链接读取、写入和管理 RAM 权限控制。

## JWT 项目管理授权

单个短链接的资源为 `acs:developer:*:<accountId>:short-link/<projectId>/<linkId>`，末段使用链接 ID，公开短代码不作为 IAM 标识。响应中的 resourceArn 可直接用于 JSON 策略。

`quyan:developer:CreateShortLink` 在项目 ARN 上控制创建；创建权限不会自动授予新链接的管理权限。`ListShortLinks`、`UpdateShortLink`、`DeleteShortLink` 和 `GetShortLinkStats` 在具体链接 ARN 上分别检查。统计 Action 独立控制访客明细，只有列表权限不能查看统计。

`GET /v1/developer/projects/{projectId}/short-links/page` 接受 page/pageSize，返回 items、page、pageSize、hasNext。先分页同账户有效项目中的候选，再逐链接过滤；空页可能有后续页，没有未授权资源的 total。enforce 下旧数组列表只返回默认第一页。暂停或过期的链接仍可被有权限的主体管理，已禁用的数据行和跨账户资源不能访问。

短链接可以加入资源组；移除成员后下一次授权即时变化。委派保留原项目所有者，目标地址校验仍会阻止内网地址或含凭据的 URL。legacy/shadow 保留个人项目所有权，enforce 使用资源策略。产品实例管理和公开跳转各自使用原有身份与权限入口。更多规则见 [RAM 管理]({{DOCS_BASE_URL}}/zh-CN/ram-management)。
