# 数据分析

数据分析通过三个互补视图帮助您了解用户行为：概览、漏斗和热力图。使用前需确保已配置分析追踪。

## 功能概览

- **概览** — 聚合事件指标：事件总量、独立用户数、事件类型分布和趋势。
- **漏斗** — 定义多步骤转化漏斗，衡量各步骤之间的流失率。
- **热力图** — 在页面截图上展示点击和交互热力分布。

## 概览

概览仪表板展示聚合分析数据。

### 内容展示

- 所选时间范围内的总事件数和独立用户数。
- 事件类型分布（页面浏览、点击、表单提交、自定义事件）。
- 每日趋势图展示事件量随时间的变化。
- 按事件数排名的热门页面。
- 按类型排名的事件。

### 筛选条件

- 日期选择器（预设：近 7 天、30 天、90 天，支持自定义）。
- 事件类型筛选。
- 页面路径筛选。

## 漏斗

漏斗衡量用户通过一系列步骤的转化情况。每个步骤对应一个追踪事件。

### 创建漏斗

1. 命名漏斗并选择日期范围。
2. 定义步骤：每个步骤包含名称和事件筛选条件（事件类型 + 可选页面路径）。
3. 漏斗将计算完成各步骤的用户数及步骤间的转化率。
4. 保存漏斗以便后续复用。

### 阅读漏斗图

- 每一步显示用户数及相对于第一步的百分比。
- 相邻步骤间的流失百分比高亮显示。
- 悬停步骤可查看详细数据。

## 热力图

热力图展示用户在指定页面上的点击和交互分布。

### 端点配置

热力图端点可在系统配置中设置。如未收集到数据，请联系管理员确认配置。

### 查看热力图

1. 从已追踪页面中选择页面 URL。
2. 选择日期范围。
3. 热力图将点击密度叠加在页面截图上渲染。
4. 暖色（红色）表示高点击密度，冷色（蓝色）表示低密度。

### 数据采集

热力图仅在端点已配置且目标页面加载了追踪脚本时才会采集数据。

## 所需权限

| 操作 | 所需权限 |
|------|---------|
| 查看分析概览 | `ANALYTICS_OVERVIEW` |
| 查看分析漏斗 | `ANALYTICS_FUNNEL` |
| 查看分析热力图 | `ANALYTICS_HEATMAP` |
| 配置热力图端点 | `SYSTEM_CONFIG` |

## 注意事项

- 分析数据依赖客户端追踪脚本，请确保已在所有需追踪的页面上正确安装。
- 事件数据可能存在短暂的处理延迟（通常在 5 分钟以内）。
- 漏斗定义按用户保存，不会跨账号共享。
- 热力图截图需要目标页面可被访问以进行捕获。
