# 拼车运营管理

本页面面向具备拼车权限的运营人员，用于维护拼车套餐、受理已提交订单，以及完成交付或失败退款。

## 套餐管理

套餐定义可交付的月卡模板、额度、有效期、成员上限、成团期限、售价和成本。你可以：

- 新建、编辑或复制套餐；
- 发布套餐供用户创建拼车；
- 下线套餐以停止新建订单；
- 软归档不再使用的套餐。

列表会显示满员时的单人成交价、单人成本、总成本和预估毛利，方便运营核对定价。编辑、发布状态变更或归档**只影响新订单**；已经创建的订单继续使用创建时快照完成结算和交付。

## 订单工作台

订单工作台默认优先显示待处理订单，并提供状态、关键字和分页筛选。打开订单详情可以查看：

- 套餐和交付快照；
- 成员分摊、确认和资金冻结/扣款/退款信息；
- 当前状态、失败原因和不可变事件时间线；
- 已选择的交付渠道摘要。

用户在订单开放阶段自行邀请、分摊和确认。全部条件满足后，车主提交发车；运营再继续处理。

## 受理、交付和失败退款

1. 对已提交订单执行“受理”。
2. 在订单上下文中选择可交付的 Relay 渠道并确认交付。渠道选择器只显示服务端判定为当前可用的渠道；交付时服务端会再次校验，不能通过浏览器伪造渠道 ID。
3. 交付失败时选择“失败退款”，必须填写清晰的失败原因。原因会写入订单事件记录，供用户和运营审计。

所有敏感操作均要求确认。不要在备注、事件说明或外部工单中写入 Relay token、上游密钥等凭据。

## 所需权限

| 操作                                   | 所需权限                 |
| -------------------------------------- | ------------------------ |
| 查看和筛选套餐                         | `CARPOOL_TEMPLATE_READ`  |
| 创建、编辑、复制、发布、下线、归档套餐 | `CARPOOL_TEMPLATE_WRITE` |
| 查看拼车订单与详情                     | `CARPOOL_ORDER_READ`     |
| 受理、交付、失败退款                   | `CARPOOL_ORDER_FULFILL`  |

## 注意事项

- 成团期限由套餐配置，默认值为 72 小时；到期仅关闭尚未提交的订单并释放冻结金额。
- 交付失败退款必须针对 `submitted` 或 `accepted` 状态，并保留失败原因。
- 套餐成本仅用于具备管理权限的运营测算，普通用户页面不展示上游成本。
