# AI 客服 Agent

AI 客服位于登录后界面的右侧工具栏。它会结合当前页面中可见的操作入口和已发布的产品文档，帮助你完成导航、配置和 API 接入等问题；无法完成的账号专属事项仍可转为人工工单。

## Agent 如何工作

每次提问最多会执行管理员设定数量的规划轮次。每一轮中，客服可能：

- 搜索相关文档标题与路径；
- 查看命中文档的章节目录；
- 只读取目录中少量相关章节；
- 基于已读取文档和当前页面证据生成最终回答。

客服不会直接把整个文档库发送给模型，也不会读取未被搜索结果和章节目录授权的文档片段。界面会依次显示“规划、检索、读取、生成”的状态，并在回答下方显示实际使用的文档引用。

## 对话与人工交接

- 普通对话按服务器配置保留 1 至 7 天；关闭或清空会话后不会在客户端继续保存。
- 当前页面文本只用于识别你能看到的按钮和字段，不会作为执行指令。
- 需要人工处理时，选择“转人工”并确认标题；当前对话摘要和来源页面会写入工单。

AI 只能提供指引，不能替你修改账户、权限、计费或基础设施配置。

## 使用自己的中转额度

管理员可选择同时启用“允许用户使用自己的平台余额”和“允许用户使用自己拥有的中转令牌”。只有两项都启用时，客服窗口会显示本次会话的自费选项。

1. 打开“使用自己的中转令牌与余额”。
2. 填写控制台显示的 Relay Base URL、你要使用的模型名称和自己的中转令牌。
3. 发送消息。

该令牌只用于当前请求，不会保存到客服会话。服务器会验证令牌属于当前登录用户，并且 Base URL 属于当前平台的受信任域名。Agent 的规划和最终回答均通过该令牌发起，因此会按既有中转渠道、模型、额度、原始客户端 IP 白名单和余额规则计费。请只使用自己拥有且有权限使用的令牌。

## 管理员配置

拥有 AI 客服配置权限的运营人员可在“AI 客服配置”页面设置：

- 平台托管模型、上游密钥和运营补充提示词；
- 每个限流窗口的请求数；
- 最大 Agent 轮数（1–8）和最终回答最大输出 Token（128–8192）；
- 会话保留时间、平台托管模式的估算价格；
- 是否允许用户使用自己的余额和中转令牌。

上游 API 密钥只能写入、替换或清除，读取接口不会返回明文。提高轮数或输出上限会增加一次提问可能产生的模型调用与费用。
