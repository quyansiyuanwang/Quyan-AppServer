# AI 客服 Agent

AI 客服位于登录后界面的右侧工具栏。它会结合当前页面中可见的操作入口和已发布的产品文档，帮助你完成导航、配置和 API 接入等问题；无法完成的账号专属事项仍可转为人工工单。

## 提问与查看回答

1. 打开需要帮助的业务页面，检查其中是否显示不希望发送给模型的信息。
2. 从右侧工具栏打开 AI 客服，说明你要完成的操作、遇到的问题和错误提示。
3. 点击输入框旁的确认按钮，或按 Enter 发送；Shift+Enter 换行。
4. 等待回答，按指引操作。回答附有文档引用时，可点击引用打开原文核对。

等待期间可能依次显示“规划、检索、读取、生成”等状态。一次提问可能需要多轮文档查询，轮数上限由管理员设置。

AI 只能提供指引，不能替你修改账户、权限、计费或基础设施配置。

## 会话记录与页面信息

- 对话在服务端按配置保留 1 至 7 天，保存消息时会重新计算保留时间。关闭窗口不会删除服务端记录，重新打开时可以加载；要删除记录，请选择“清空会话”。有相应权限的管理员也可以查看会话。
- 同一用户使用同一份客服会话，切换业务页面不会自动新建会话。清空前请保存需要保留的内容；清空后无法从客服窗口恢复。
- 发送问题时，页面会将当前页面标题、地址路径和最多 16,000 个字符的可见文本一同发送给客服，用作模型识别页面的上下文；其中可能包含页面上显示的业务信息，不限于按钮和字段。请先检查当前页面是否显示不希望分享的信息。页面文本不会作为执行指令。

## 转人工处理

1. 先发送问题，说明需要人工处理的事项；空白会话无法生成有效工单。
2. 选择**转人工**，填写或确认工单标题。
3. 确认提交后，打开[我的工单]({{DOCS_BASE_URL}}/zh-CN/my-tickets)，按标题查找工单并查看后续回复。客服窗口不会自动跳转到工单详情。

当前窗口中的用户和助手消息会作为工单描述提交，并记录来源页面；过长的描述会被截断。工单审核人员可以查看这些内容，请勿在对话中填写不必要的敏感信息。提交结果不确定时，先到“我的工单”核对，避免重复创建；无法查看时请联系管理员确认权限。

## 使用自己的中转额度

管理员可选择同时启用“允许用户使用自己的平台余额”和“允许用户使用自己拥有的中转令牌”。只有两项都启用时，客服窗口会显示本次会话的自费选项。

1. 展开“使用自己的中转令牌与余额”，打开“本次对话使用自己的令牌”。
2. 填写控制台显示的 Relay Base URL、你要使用的模型名称和自己的中转令牌。
3. 发送消息。

令牌不会保存到服务端客服会话；面板保持打开时，输入框中的令牌会保留，并用于自费模式下发送的后续消息。“清空会话”不会清空令牌输入框；如不再使用，请手动删除令牌。服务器会验证令牌属于当前登录用户，并且 Base URL 属于当前平台的受信任域名。Agent 的规划和最终回答均通过该令牌发起，因此会按既有中转渠道、模型、额度、原始客户端 IP 白名单和余额规则计费。请只使用自己拥有且有权限使用的令牌。

## 管理员配置

拥有 AI 客服配置权限的运营人员可在“AI 客服配置”页面设置：

- 平台托管模型、上游密钥和运营补充提示词；
- 每个限流窗口的请求数；
- 最大 Agent 轮数（1–8）和最终回答最大输出 Token（128–8192）；
- 会话保留时间、平台托管模式的估算价格；
- 是否允许用户使用自己的余额和中转令牌。

修改设置后点击**保存**。上游 API 密钥不会回显明文：留空密钥输入框且不勾选清除时保留原密钥，填写新密钥可替换，勾选**清除已配置密钥**则在保存时删除原密钥。请勿同时填写新密钥并勾选清除，清除操作会优先生效。保存成功后，密钥输入框会清空，可通过“密钥已配置，留空则保持不变”提示确认配置状态。

提高轮数或输出上限会增加一次提问可能产生的模型调用与费用。

启用 IAM 强制授权后，配置读取和更新分别需要 `quyan:support:GetConfig` 与 `quyan:support:UpdateConfig`，资源固定为 `acs:platform:*:platform:config/support-ai`。操作者还必须属于保留 AI 客服配置权限的有效全局管理组；账户内自建组或通配符策略不能取得平台管理资格。读取权限不自动授予更新权限，显式 Deny 优先。保存时所有设置一起提交，权限撤销、配置并发修改或角色会话失效会拒绝整次更新，不会留下部分新配置。密钥保持加密存储，审计仅记录发生变化的配置项名称。

## 服务容量与流式失败

客服 AI 与聊天、中转共享服务器资源预算；繁忙时可能返回 429，请稍后重试。输出容量或上游异常可能中断回答；界面会移除未完成的回答并显示错误，已发送的问题仍留在窗口中。用户自付中转仍按实际中转用量记录结算，不能把流式失败视为免费请求。

输入与会话上下文受服务器配置中的输入、消息条数和上下文字节预算控制。消息条数设为 0 可取消条数限制，字节预算仍生效。超过预算会明确拒绝，不会自动删除或截短旧消息；可主动清空客服会话后再试。Agent 的提示词与工具结果也计入上下文预算。
