# 远程终端

在远程终端工作区选择自己的在线设备和 Shell，建立交互式终端连接。工作区支持多标签、打开位置、快捷键和快捷命令。

## 连接前准备

1. 在[我的远程终端产品]({{DOCS_BASE_URL}}/zh-CN/my-remote-terminal-products)取得有效权益，并按该页说明安装、注册 Agent。设备配额用于绑定设备，终端配额用于并发会话，两者用途不同。
2. 确认 Agent 在线，当前身份有设备查看和会话创建权限。IAM 强制模式下，还需对新会话授予独立的连接权限。
3. 打开工作区并刷新。设备、会话摘要和用量分别加载；某一部分失败时显示该区不可用，不影响其他已授权部分。刷新会清除旧的列表数据，不会把旧授权结果继续显示；用量不可用时不显示虚假的零配额。

打开工作区不授予访问设备或执行命令的权限。设备列表只包含本人的有效权益下启用的绑定，IAM 强制模式还会逐设备过滤；个人产品页可见的过期或禁用权益不代表设备会出现在工作区。

## 建立连接

1. 点击目标设备卡片，核对主机名、平台、架构和在线状态。刷新会尝试探测设备，但探测失败不一定阻止列表读取，在线标记仍可能是此前状态。
2. 从下拉菜单选择设备上报的 Shell。选项由 Agent 提供；没有可用 Shell 时，先检查 Agent 版本及上报信息。
3. 如需指定启动目录，在“打开位置”中先设置并保存；默认使用 Agent 的默认位置。
4. 点击“连接”，等待状态变为终端就绪，再输入命令。“浏览器已连接”仅表示连接到网关，不等于远程 Shell 已准备好。
5. 结束操作后点击“断开”。停止、断开或重连不会撤回已经发给设备的命令，也不能保证结束命令另行启动的后台任务。

**切换设备前先断开当前会话。**当前页面点击另一张设备卡片或修改 Shell，只会改变后续连接的选择，不会替换已经建立的连接；标题和偏好可能已随选择变化，但终端输入仍可能发给原设备。需要并行操作时，新建标签并在新标签中连接。

连接按钮在未选中在线设备、正在建立连接或已知终端配额用完时不可用。配额信息不可用、按钮可点击或设备显示在线，都不代表服务端会接受连接；提交时仍检查权限、权益、设备状态和实际配额。

## 多标签、断开与重连

| 操作               | 实际结果                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| 新建标签           | 继承当前选择作为起点，不自动建立连接；可选择同一或另一设备后连接。切换标签本身保留其他标签的连接。         |
| 断开               | 结束当前标签连接并尝试停止对应终端，不解绑设备，也不卸载 Agent。                                           |
| 关闭终端标签       | 关闭该标签的浏览器连接并清除本地终端显示；网关收到断开后停止会话。最后一个标签不能通过关闭按钮移除。       |
| 离开或重新加载页面 | 本页连接和本地显示不会作为可恢复终端保存；不要依赖它们保留 Shell 状态。                                    |
| 重连               | 尝试停止当前连接，再创建新会话并清空该标签原终端显示。不会恢复原 Shell、运行中的前台程序、目录或滚动记录。 |

意外断开已经就绪的会话后，页面可按当前标签的重试设置尝试重新连接；首次连接未就绪便失败、正常退出或主动断开时，不应依赖自动重连。默认设置为3次、间隔5秒，可在页面调整为1–10次、间隔1–60秒；使用“取消重试”停止等待。每次重试仍需设备在线并通过服务端检查。

重连会创建新终端，请先确认上一次命令的执行结果，不要因断线就重复执行有副作用的命令。网络标签表示浏览器与网关的往返情况，不能单独证明设备到网关的连接或远程命令已经成功。

## 设置打开位置

1. 先选中在线设备，点击更改打开位置。
2. 在目录树中展开并选择目录，也可浏览当前目录、上级目录或根入口；这用于选择目录，不是文件上传下载工具。
3. 点击应用以写入该设备偏好。保存需要设备偏好写入权限，目录浏览需要独立的目录权限。
4. 下一次建立会话时使用已保存位置；修改设置不会向正在运行的 Shell 执行 `cd`。

弹窗“清空”只清除当前草稿，需继续点击应用才保存。页面“清除位置记忆”会立即尝试保存空位置；快捷键和快捷命令保留。路径是否存在、Agent 是否有权访问，以设备实际执行结果为准。

偏好按设备读取和保存，读取失败时可能仍显示缓存或默认内容。保存会一起提交打开位置、快捷键和快捷命令；没有确认当前设备原配置时，请先处理读取问题，避免覆盖需要保留的设置。

## 快捷键、快捷命令与剪贴板

- 在终端下方管理快捷键，可录制按键组合，或填写按行发送的序列。序列支持 `\r`、`\n`、`\t`、`\e`；保存需要在线设备及偏好写入权限。
- Ctrl、Alt、Shift、Meta 锁定会参与快捷键组合。使用后可清除修饰键锁定；“恢复默认快捷键”会保存默认快捷键并清除锁定，同时保留打开位置和快捷命令。
- 快捷命令需填写名称和命令内容；保存、编辑、删除都作用于所选设备偏好。**点击命令按钮会立即发送内容，通常补上回车并执行，没有二次确认。**含回车或以换行结尾的内容不再追加回车；多行内容可能依次执行多条命令。发送前核对实际连接的设备和标签。
- 右键时，有选中文本则复制；无选中文本则尝试读取剪贴板并直接发送到当前终端。剪贴板权限由浏览器控制；包含换行的粘贴可能执行命令。断开时不会把输入或粘贴排队留到重连后发送。

偏好保存超时或报错时，设备可能已经应用修改。重新读取并确认结果后再决定是否重试；撤销权限不会撤回设备已经执行的偏好更新。

## 复制链接与查看会话

“复制链接”生成带设备信息、自动连接标记和可能的会话 ID 的工作区地址。打开链接的人仍需登录并具有自己的设备与会话权限；链接不会共享设备访问权，也不提供接管原会话、终端回放或恢复原 Shell 的功能。

链接打开时可能自动发起新连接，请先核对目标。若指定设备不在当前可见列表，页面可能回退到其他可见设备，不能仅凭链接参数认定实际连接目标。

“最近会话”按创建时间倒序显示当前可读取的会话摘要，每页5条。它不包含命令输入输出，也不是完整、永久的历史记录；会话关闭后可能不再出现。需要核对最新状态时点击刷新。

## 理解配额

终端用量包括尚未关闭的 pending 和 connected 会话，不限于当前浏览器打开的标签。设备用量是有效权益下已启用的绑定数量，离线设备也可能计入；它不等于在线设备数。

配额来自本人当前启用且生效中的权益。IAM 列表策略隐藏的设备和会话仍可能占用配额，不能按可见卡片或表格行数推算剩余额度。配额变化后请刷新；若仍无可用终端配额，请检查其他窗口的连接，或购买、续期权益并联系管理员。

## 常见问题

| 现象                     | 排查方向                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| 没有设备或设备列表不可用 | 先成功刷新，检查当前身份、设备读取权限、权益有效期和绑定状态；在个人产品页核对注册情况。     |
| 设备离线                 | 检查目标设备上的 Agent、网络和平台连接，恢复后刷新。不要用反复购买替代连接排查。             |
| 已创建会话但无法进入终端 | 检查 WebSocket 是否可用，以及 IAM 的独立 ConnectSession 权限和条件。请管理员核对部署或授权。 |
| 配额满但列表行数很少     | 用量包含不可见会话及其他浏览器连接；刷新后检查并结束不需要的连接。                           |
| 更改目录后 Shell 未移动  | 设置仅用于新会话；需要时在当前终端自行切换目录，或结束后重新连接。                           |
| 断线后命令结果不明       | 重连会新建终端。先检查远程操作结果，再决定是否重试；不能从断线判断命令未执行。               |

## 按设备授权

启用 IAM 强制授权后，设备列表、探测、目录浏览和偏好操作由以下 Action 分别控制：

| 操作             | Action                                         | 资源       |
| ---------------- | ---------------------------------------------- | ---------- |
| 查看设备列表     | `quyan:remote_terminal:ListDevices`            | 逐设备过滤 |
| 探测设备在线状态 | `quyan:remote_terminal:ProbeDevices`           | 逐设备过滤 |
| 浏览目录         | `quyan:remote_terminal:BrowseDirectories`      | 选定设备   |
| 读取偏好         | `quyan:remote_terminal:GetAgentPreferences`    | 选定设备   |
| 保存偏好         | `quyan:remote_terminal:UpdateAgentPreferences` | 选定设备   |

设备 ARN 格式为 `acs:remote-terminal:*:<accountId>:device/<userId>/<deviceId>`。账号 ID、绑定用户和设备 ID 以服务端确认的归属为准。授权不会让你访问其他用户的设备，也不会延长套餐有效期。

以下策略仅允许查看一个设备及读取其目录和偏好。将示例占位符替换为实际 ID 后，可在 [RAM 管理]({{DOCS_BASE_URL}}/zh-CN/ram-management) 中校验、模拟并绑定；这份策略不授予修改偏好或创建终端会话的权限。

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "quyan:remote_terminal:ListDevices",
        "quyan:remote_terminal:BrowseDirectories",
        "quyan:remote_terminal:GetAgentPreferences"
      ],
      "Resource": "acs:remote-terminal:*:account-id:device/user-id/device-id"
    }
  ]
}
```

显式 Deny 覆盖 Allow；未获准的设备不出现在设备列表中。目录或偏好读取被拒绝时返回权限错误，设备不可用和策略详情不会通过该错误公开。读取期间权限被撤销或设备套餐失效，结果也不会返回。

仍使用兼容授权模式的部署保留原有权限行为；差异比较模式只记录 IAM 结果，不会为比较结果重复向设备发送请求。

设备探测只向获准的设备发送请求，并更新对应设备的在线状态。无匹配 Allow 的设备不会被探测，也不会因这次操作更新状态。设备归属、套餐或授权在探测期间变化时，受影响的状态写入会被拒绝。

修改偏好需要独立的写入 Action。服务端会在发送修改请求前复核权限；如果请求已发给设备后权限才被撤销，权限撤销不会撤回设备已经执行的修改。请先核对目标设备和修改内容，再提交保存。

## 会话可见范围与用量权限

`quyan:remote_terminal:ListSessions` 按 `acs:remote-terminal:*:<accountId>:session/<userId>/<sessionId>` 逐会话授权。列表仅包含当前认证用户自己的会话；显式 Deny 优先，缺少 Allow 的会话不显示。返回内容仅为公开摘要，不包含工作目录或浏览器连接 Token。会话资源也可以加入资源组，限定授权的生效范围。

`quyan:remote_terminal:GetUsageSummary` 需要用户资源 `acs:quyan:*:<accountId>:user/<userId>` 的权限。用量包含全部自有的活动会话和有效套餐绑定设备，包括列表策略隐藏的设备与会话。列表可见范围不会减少配额占用；设备列表和会话列表权限不会自动授予用量查询或创建会话权限。

这些独立 Action 在 IAM 强制授权模式下生效；兼容授权部署保留原有权限行为。

创建 pending 会话需要所选设备 ARN 上的 `quyan:remote_terminal:CreateSession` 权限；只有设备列表或用量查询权限不能创建会话。创建时会检查实际配额占用，包括列表中不可见的会话。重连仅替换该设备的旧 pending 会话，保留 connected 会话。创建完成前授权复核失败时，新 pending 会话会被清理，浏览器连接凭据不会返回。

## 连接会话与持续授权

启用 IAM 强制授权后，`quyan:remote_terminal:ConnectSession` 单独控制 `acs:remote-terminal:*:<accountId>:session/<userId>/<sessionId>`。创建 pending 会话不等于获得执行权限。需要使用自己创建的会话时，可在自己的会话资源模式上授予此 Action，或由有权限的管理员为指定会话绑定授权。

连接条件使用实际 WebSocket 连接的来源 IP、传输协议和 User-Agent；代理信息按服务端配置的信任范围解析，不会直接沿用创建请求的信息。服务端会在启动终端以及转发终端输入、输出前复核当前授权与凭据状态，空闲会话也会定期复核。撤权、凭据轮换、账号或套餐失效，以及无法读取授权数据，都会停止后续数据转发并关闭会话。撤权不会撤回已经发给设备的命令。

格式错误、试图操作其他会话或排队数据超过上限的消息会关闭发起连接。浏览器消息不能直接调用设备偏好或目录操作；这些操作需要对应 API 权限。
