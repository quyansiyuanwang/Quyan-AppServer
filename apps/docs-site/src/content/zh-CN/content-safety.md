# 内容安全

内容安全位于 AI 控制台的独立页面，不再嵌入转发设置。

## 用户策略

在“内容安全”页面可以维护请求和响应方向的策略、AI 审计开关、用户私有规则以及系统规则的个人启用例外。系统规则只能通过启用/关闭例外调整，用户私有规则支持完整编辑。

规则表支持多选批量编辑、批量启用和批量关闭。CSV 导入先生成预览，确认后才应用；覆盖模式按规则 ID 或 `类型 + 方向 + 内容` 更新匹配项，不会删除 CSV 外的规则。

## 系统策略

拥有系统配置权限的管理员可以在“系统内容安全”页面维护系统基线、AI 渠道、默认词库、系统规则和全量脱敏命中记录。系统修改仍需要现有的安全验证流程。

## 导出

用户和管理员都可以导出当前作用域的 JSON 策略或 CSV 规则。导出内容不包含 API Key、Token、命中原文或完整请求响应。
