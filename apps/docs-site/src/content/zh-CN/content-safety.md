# 内容安全

内容安全位于 AI 控制台的独立页面，不再嵌入转发设置。请求和响应方向分别配置，策略、规则和命中记录均支持服务端分页。

## 动作与继承

规则或 AI 命中后的动作分为“放行”“替换敏感内容（blackhole）”和“报错阻断（unreachable）”。“最大动作”是该方向允许执行的安全上限，实际动作不会超过它；系统、用户、令牌三层按 `allow < blackhole < unreachable` 取上限最低的值。用户和令牌选择“继承”可沿用上层上限；设置更低的上限会限制最终动作，设置更高的上限不能突破上层限制。例如系统上限为 `blackhole` 时，用户设置 `unreachable` 仍最多执行 `blackhole`；用户设置 `allow` 则命中后最多执行放行。

将规则批量设为“放行观察”后，命中仍会写入记录，但不会替换或阻断请求，适合先观察日常使用情况。系统规则只能通过启用/关闭个人例外调整，用户私有规则支持完整编辑；批量操作会跳过不可编辑的系统规则。

AI 审计会把文本发送到配置的模型，并按输入/输出 token 计费。启用前请确认上游地址、模型和费用设置。

## 通知与命中记录

系统管理员修改策略只产生审计日志，不发送内容安全邮件。只有用户订阅 `content_safety_blocked` 事件，且最终动作是 `unreachable` 时，通知服务才会按订阅、冷却时间和邮箱配置投递邮件；`allow` 和 `blackhole` 命中不会发邮件。

命中记录支持刷新、分页、筛选和排序，刷新会保留当前筛选条件和页码。表格显示匹配规则名称、类型、规则 ID/模式摘要；AI 命中显示 AI 来源。匹配上下文经过安全转义并高亮命中片段，不展示完整请求或响应原文。

## 规则与导出

规则表支持多选批量编辑、批量启用、批量关闭和批量设为放行。CSV 导入先生成预览，确认后才应用；覆盖模式按规则 ID 或 `类型 + 方向 + 内容` 更新匹配项，不会删除 CSV 外的规则。

导入预览列出潜在的新增和更新；勾选或取消“覆盖已有规则”不会刷新预览。确认导入时使用当前勾选状态：未勾选时，预览中匹配已有规则的更新不会应用。因此，预览中的更新数量不一定是最终执行数量。确认前请核对 CSV 内容和覆盖选项。

用户和管理员都可以导出当前作用域的 JSON 策略或 CSV 规则。导出内容不包含 API Key、Token、命中原文或完整请求响应。

## 系统策略

拥有系统配置权限的管理员可以在“系统内容安全”页面维护系统基线、AI 渠道、默认词库、系统规则和全量命中记录。系统修改仍需要现有的安全验证流程。

## 系统策略读取的资源权限

IAM 强制模式下，系统配置的读取与更新、规则列表和规则导出分别使用以下 Action：

| 操作         | Action                                    | 资源                                                   |
| ------------ | ----------------------------------------- | ------------------------------------------------------ |
| 读取系统配置 | `quyan:content_safety:GetSystemConfig`    | `acs:platform:*:platform:content-safety-config`        |
| 列出系统规则 | `quyan:content_safety:ListSystemRules`    | `acs:platform:*:platform:content-safety-rule/<ruleId>` |
| 导出系统规则 | `quyan:content_safety:ExportSystemRules`  | 同上，可指定规则或使用 `content-safety-rule/*`         |
| 更新系统配置 | `quyan:content_safety:UpdateSystemConfig` | `acs:platform:*:platform:content-safety-config`        |

配置更新为原子操作：授权变化或配置冲突会拒绝整次更新。省略 AI API Key 时保留已有值，替换时加密保存；同时提供替换值和清空选项时，清空优先。更新响应描述已保存的配置，仅返回密钥是否已配置的标记。

通用配置 API 访问这些字段时，也须取得对应的内容安全读取或更新 Action；内容安全资源上的 Deny 同样约束通用配置流程。

操作者仍须属于具有系统配置管理资格的有效全局组。账户策略不能自行赋予这种管理资格；角色会话使用角色本身的 Allow，匹配的显式 Deny 优先。

系统规则列表先检查每个资源，再分页；总数只包含获准规则。系统读取范围只包含系统规则，用户私有规则通过对应的用户规则流程查看。没有匹配 Allow 时列表可以为空，未获准规则的正文不会被读取或导出。

JSON 导出包含系统配置，因此还需独立的配置读取权限。CSV 只包含规则，不需要配置读取权限。配置响应和导出不会返回 API Key，只提供是否已配置的标记。读取期间策略、规则内容、资源归属或配置发生变化时，请求会被拒绝，避免返回混合状态的结果。

`legacy` 和 `shadow` 保留原系统配置权限检查和返回范围；shadow 比较新的资源检查，但不改变旧结果。添加一条指定资源的 Allow 不会自动移除已有的宽泛 Allow，限制范围时还需检查主体的其他策略和组权限。

## 系统规则写入与资源范围

IAM 强制模式将创建、更新、删除和批量更新分别映射为 `quyan:content_safety:` 下的 `CreateSystemRule`、`UpdateSystemRule`、`DeleteSystemRule` 和 `BatchUpdateSystemRules`。这些操作仍要求系统配置管理资格、二次验证和重放保护。

创建规则须同时获得 `acs:platform:*:platform:content-safety-rule-control` 和服务端生成的实际 `acs:platform:*:platform:content-safety-rule/<ruleId>` 的 Allow；仅允许控制资源不足以创建规则。更新和删除检查目标规则，批量更新逐个检查所有 ID，拒绝重复 ID。任何目标被拒绝、不存在或属于用户私有规则时，整批失败，不会部分修改。私有规则使用用户规则流程。

规则写入是原子操作。完成前身份、组归属、授权或目标内容发生变化时，操作被拒绝并回滚。删除会停用规则并将其移出有效规则集；优先级 `0` 为有效值。

系统与私有规则共用 500 条有效规则和 1 MiB 匹配内容预算。写入不能使某一维度新增超限；已有数据超限时，仍允许不恶化该维度的修复操作和删除。

## 导入授权

IAM 强制模式下，CSV 导入使用 `quyan:content_safety:ImportSystemRules`，默认词库导入使用 `quyan:content_safety:ImportDefaultSystemRules`。两者均须取得规则控制资源、使用的已有规则，以及应用时实际生成的每个规则 ID 的权限。

CSV 预览仅返回获准系统规则的旧值。显式指定的 ID 若属于私有规则、不存在或被拒绝，请求会被拒绝，不能用于探测其他规则。预览和含校验错误的导入不写入；关闭覆盖时已有规则保持不变，覆盖默认规则仍保留其默认来源。

应用为原子操作：目标或新资源被拒绝、规则集或授权变化，以及共用容量超限，均会回滚全部写入。默认导入可重复执行，并检查已有默认规则；用户私有副本不视为已安装的系统默认规则。legacy 和 shadow 保留一次旧流程导入，shadow 检查实际创建的 ID。

## 系统命中记录范围

IAM 强制模式下，`quyan:content_safety:ListSystemIncidents` 控制每个 `acs:platform:*:platform:content-safety-incident/<incidentId>`。先逐记录授权，再分页和计数；只有获准记录计入总数并返回匹配片段。原有筛选和排序仍可使用。操作者须保留系统配置管理资格，角色会话须具有自己的策略 Allow。

关联规则的名称与类型用于说明命中背景；读取有效系统规则的当前匹配内容，还须具备该规则的 `ListSystemRules` 权限。被拒绝、私有或已停用规则的匹配内容不返回，页面可显示规则 ID。Token 和渠道名称可作为背景信息显示，但不会返回凭据。读取期间相关记录正文、规则、背景名称或授权变化时，请求会被拒绝。

API 日期仍为 ISO 时间戳，命中记录费用为十进制字符串。legacy 和 shadow 保留原系统记录范围，shadow 比较 IAM 结果但不改变旧响应。

## 编程场景与规则更新

默认导入词库采用宽松开发基线：仅保留完整 PEM 私钥材料阻断，不因工具定义、系统提示词、常见代码、命令或配置路径本身阻断。示例、占位符、仅有私钥标记和省略正文的模板不会命中；仍需避免发送完整真实凭据。

升级不会自动停用已有规则。收敛历史词库时，在 CSV 中保留原规则 ID 并设置 enabled=false，先预览再覆盖导入；删除 CSV 行不会删除数据库规则。CSV 只包含规则，不包含 AI 审核开关；AI 审核仍可能独立阻断。

每次上游尝试使用开始时的策略和规则快照；修改从下一次请求、重试或渠道切换开始生效，运行中的长连接继续使用原规则。
