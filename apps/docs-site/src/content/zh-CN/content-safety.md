# 内容安全

内容安全位于 AI 控制台的独立页面，不再嵌入转发设置。请求和响应方向分别配置，策略、规则和命中记录均支持服务端分页。

## 动作与继承

规则或 AI 命中后的动作分为“放行”“替换敏感内容（blackhole）”和“报错阻断（unreachable）”。“最大动作”是该方向允许执行的安全上限，实际动作不会超过它；系统、用户、令牌三层按 `allow < blackhole < unreachable` 取最严格值。用户和令牌选择“继承”即可沿用上层设置，只能保持或进一步收紧上限。

将规则批量设为“放行观察”后，命中仍会写入记录，但不会替换或阻断请求，适合先观察日常使用情况。系统规则只能通过启用/关闭个人例外调整，用户私有规则支持完整编辑；批量操作会跳过不可编辑的系统规则。

AI 审计会把文本发送到配置的模型，并按输入/输出 token 计费。启用前请确认上游地址、模型和费用设置。

## 通知与命中记录

系统管理员修改策略只产生审计日志，不发送内容安全邮件。只有用户订阅 `content_safety_blocked` 事件，且最终动作是 `unreachable` 时，通知服务才会按订阅、冷却时间和邮箱配置投递邮件；`allow` 和 `blackhole` 命中不会发邮件。

命中记录支持刷新、分页、筛选和排序，刷新会保留当前筛选条件和页码。表格显示匹配规则名称、类型、规则 ID/模式摘要；AI 命中显示 AI 来源。匹配上下文经过安全转义并高亮命中片段，不展示完整请求或响应原文。

## 规则与导出

规则表支持多选批量编辑、批量启用、批量关闭和批量设为放行。CSV 导入先生成预览，确认后才应用；覆盖模式按规则 ID 或 `类型 + 方向 + 内容` 更新匹配项，不会删除 CSV 外的规则。

用户和管理员都可以导出当前作用域的 JSON 策略或 CSV 规则。导出内容不包含 API Key、Token、命中原文或完整请求响应。

## 系统策略

拥有系统配置权限的管理员可以在“系统内容安全”页面维护系统基线、AI 渠道、默认词库、系统规则和全量命中记录。系统修改仍需要现有的安全验证流程。
