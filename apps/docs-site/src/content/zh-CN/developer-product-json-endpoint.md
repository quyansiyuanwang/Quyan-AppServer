# JSON 端点

JSON 端点产品为每个产品实例提供一份可编辑的 JSON 内容，适合配置发布、轻量数据共享和程序读取。实例页面同时展示公开地址、实例状态和产品用量。

## 创建和编辑

在开发者产品控制台创建 JSON 端点实例后，打开实例编辑 JSON 内容；有更新权限时点击**保存**发布修改。新实例的内容初始为 `{}`，且默认公开；任何知道地址的人都可读取，保存前请确认内容不含机密。产品编辑器不提供访问保护设置；如需密码或签名保护，请使用有权限的 [JSON 端点管理]({{DOCS_BASE_URL}}/zh-CN/json-endpoint-management) 流程。产品实例权限、实例数量上限和每日配额以当前服务端配置为准。

## 访问方式

- 使用产品 API Key 调用 `GET /v1/products/json-endpoints` 读取、`PUT /v1/products/json-endpoints` 更新内容；更新请求体为 `{ "jsonContent": <JSON值> }`。`DELETE` 将内容清空为 `{}`，不会删除实例。写入操作还需要通过重放保护。
- 实例页面显示的公开 URL 可作为分享入口。配置密码或签名保护的方法和请求格式见 [JSON 端点管理]({{DOCS_BASE_URL}}/zh-CN/json-endpoint-management)。
- 管理端 `/content/json-endpoints` 继续用于管理员查看和管理全部旧端点及产品关联状态。

API Key 只显示必要的密钥前缀和权限信息；完整密钥仅在创建时返回，请妥善保存。读取、写入和管理权限可以分别授权，调用会计入产品配额和调用记录。

## 删除限制

删除产品实例会撤销其产品 API Key 并清理关联 JSON 端点。旧 JSON 端点不会自动转换为产品实例。
