# JSON 端点

JSON 端点产品为每个实例提供一份可编辑的 JSON 文档，适合发布配置和轻量共享数据。你可以在产品控制台编辑内容，由自己的服务端使用产品 Key 读写，或通过端点分享地址读取。

## 使用前提

先创建启用的 JSON 端点产品实例。实例名称为 1～100 个字符，标识为 3～80 个小写字母、数字或连字符；实例数量上限以当前账号授权为准。新实例内容为 `{}`，默认公开，普通分享地址包含所属用户名和实例标识。与已有 JSON 端点使用相同所属用户和标识时，创建可能发生冲突。

读取需要 `json_endpoint:read`，更新或通过产品 API 清空内容需要 `json_endpoint:update`，实例与 Key 管理使用 `json_endpoint:manage`。产品 Key 的动作授权和绑定身份的有效权限均须满足要求。创建和保存 Key 的方法见[开发者产品总览]({{DOCS_BASE_URL}}/zh-CN/developer-products-overview)。

新实例公开内容可被任何知道地址的人读取。请在首次保存前确认内容可以公开；需要保护时先通过 [JSON 端点管理]({{DOCS_BASE_URL}}/zh-CN/json-endpoint-management)设置密码或签名访问。产品编辑器只修改内容，不配置访问保护。

## 在控制台编辑和保存

1. 打开 JSON 端点产品控制台，进入目标实例详情。
2. 核对实例名称、分享路径及“公开”或“受保护”状态，编辑 JSON 内容。
3. 使用代码模式时，先移开文本框焦点，确认没有解析错误，再点击“保存”。
4. 成功后重新读取内容，或用正确的访问凭据请求分享地址，确认发布结果。

编辑器支持可视化和代码模式，建议使用对象或数组作为根值。已有字符串、数字等根值在编辑器中可能显示为 `{}`；此时先通过 API 核对实际内容，避免把编辑器显示当成已保存值。

代码解析错误不会阻止外层保存按钮提交，可能保存此前的有效草稿，而非当前无效文本。快速模板直接替换草稿，没有替换确认。关闭详情、切换实例或重新加载页面会丢弃未保存修改；需要保留时先复制草稿。

保存会整体替换 JSON，不是局部合并。多人同时编辑时，较晚保存的内容可能覆盖其他人的修改。保存超时或连接中断时，先保留草稿副本，再关闭并重新打开详情核对已保存内容。详情加载失败时请重新打开；页面顶部刷新只更新实例列表，不重读编辑器内容。

## 选择访问方式

| 入口                    | 认证与结果                                    | 用量                                            |
| ----------------------- | --------------------------------------------- | ----------------------------------------------- |
| 产品控制台              | 登录会话；查看和保存整份 JSON                 | 不经过产品 Key 计量接口                         |
| 产品 Key API            | 实例产品 Key；返回内容及实例、路径等信息      | 读取、更新、清空均计入产品用量                  |
| 分享地址 `/v1/json/...` | 公开、静态密码或 Ed25519 签名，取决于端点配置 | 不经过产品 Key 计量接口；访问计数与产品用量不同 |

分享地址使用当前部署的 API 服务地址加上页面显示的路径。受保护地址不能只靠浏览器打开来验证，需携带对应密码或签名请求头。普通分享响应的 JSON 内容位于统一响应的 `data.data`，产品 Key 读取响应的内容位于 `data.jsonContent`。

## 使用产品 Key API

在可信服务端保存 Key，并请求当前部署的 API 服务。登录令牌、AccessKey 或中转令牌不能替代产品 Key。

```http
GET /v1/products/json-endpoints
Authorization: Bearer <PRODUCT_API_KEY>
```

检查 HTTP 状态和响应业务码。成功响应的 `data` 包含 `jsonContent`、`instanceId`、`publicUrl`、`isPublic` 和 `lastUpdated` 等字段。`lastUpdated` 也可能随访问统计更新，不适合作为内容版本号。

| 操作     | 方法与请求体                                                                   | 结果                                                      |
| -------- | ------------------------------------------------------------------------------ | --------------------------------------------------------- |
| 读取     | `GET /v1/products/json-endpoints`                                              | 返回 JSON 内容及元数据                                    |
| 整体更新 | `PUT /v1/products/json-endpoints`，请求体为 `{"jsonContent":{"enabled":true}}` | 覆盖原内容，保持访问保护设置                              |
| 清空内容 | `DELETE /v1/products/json-endpoints`，不需要请求体                             | 内容变为 `{}`，返回 `data.success: true`；实例和 Key 保留 |

更新和清空还需要防重放签名，单独携带 Key 不足以完成写入。控制台会自动处理签名；自行集成时：

1. 调用同一 API 服务的 `GET /v1/auth/replay-signing-session`，读取响应 `data.sessionId` 和 `data.signingKey`，按返回的到期时间管理签名会话。
2. 每次请求生成新的 nonce 和当前 Unix 秒级时间戳。以签名密钥的原字符串作为 HMAC-SHA256 密钥，对 `nonce + timestamp + pathname + body` 拼接结果计算十六进制签名，不添加分隔符。`pathname` 是实际 API 路径；`body` 为请求 JSON 对象经 `JSON.stringify` 的字符串，无请求体时为空字符串。
3. 除产品 Key 外，携带 `X-Replay-Session-Id`、`X-Nonce`、`X-Timestamp` 和 `X-Sign`。签名会话申请和业务请求应使用一致的客户端指纹；签名会话过期时重新申请，每次重试都使用新 nonce。

时间戳允许正负 5 分钟偏差，签名服务依赖 Redis；服务不可用时写入会被拒绝。这是产品写入的 HMAC 防重放机制，与分享读取使用的 Ed25519 签名不同。

## 用量、停用与删除

同一账号的 JSON 端点产品实例共享每日配额，按服务端日历日期统计。免费额度、超额开关和单价以当前产品配置为准；单价为零时仍可累计请求数。计量执行失败会进入额度退回流程，恢复可能延迟。产品 Key 请求计数、分享访问计数和产品计费次数不是同一指标。

停用实例会阻止产品 Key 调用及产品控制台内容管理，但分享地址不会随实例停用而关闭。需要撤回公开内容时，应通过 JSON 端点管理设置访问保护或删除端点，再实际请求原地址验证。已经被调用方下载或缓存的数据不会被收回。

删除产品实例会撤销其 Key 并清理关联端点，控制台没有恢复功能。产品 API 的 `DELETE` 只清空内容，两者后果不同。直接在 JSON 端点管理中删除关联端点也会使产品内容不可用，但不会替你删除产品实例；需要同时清理时请返回产品控制台处理。旧端点不会自动转换为产品实例。

## 常见问题

| 现象                     | 处理方法                                                               |
| ------------------------ | ---------------------------------------------------------------------- |
| 保存成功但内容与文本不同 | 检查代码模式是否有解析错误；移开焦点、修正后保存，并重新读取核对       |
| 实例已停用但分享仍可访问 | 停用只限制产品入口；改用端点访问保护或删除端点                         |
| 写入提示缺少防重放请求头 | 产品 Key 不免除防重放要求；使用控制台或完成签名会话流程                |
| 分享内容读取不到         | 核对 API 地址、用户名路径或根路径，以及密码或签名配置                  |
| 详情加载失败但实例还在   | 关联端点可能已被删除，或实例停用、权限不足；核对管理状态，避免反复保存 |
