# OJ 价格管理

此页面用于维护 OJ 提交器使用的供应商与模型价格。

## 页面用途

- 新增价格记录。
- 编辑已有的供应商或模型费率。
- 删除过时价格项。
- 维护 Token 成本计算所需倍率。

## 你会看到什么

### 价格列表

- 供应商。
- 模型。
- 输入与输出价格。
- 倍率参数。
- 缓存创建与缓存读取倍率。

### 管理动作

- 新增模型价格。
- 编辑价格。
- 删除价格。

## 常见操作

1. 为新供应商或新模型增加价格项。
2. 保存前仔细核对所有费率字段。
3. 计费逻辑调整时同步修改倍率。
4. 删除前确认旧价格项不再需要。删除后不能直接为同一模型重新创建价格记录；如果只是调整价格，请编辑现有记录。

## 倍率参数说明

每条价格记录在基础输入/输出单价之上，还有三个倍率参数：

- **倍率（Multiplier）** — 同时作用于输入和输出 Token 成本的整体调整系数（默认 `1.0`，即不调整）。用于对某个模型整体加价或降价。
- **缓存创建倍率（Cache-creation multiplier）** — 作用于首次写入供应商提示缓存的 Token（默认 `1.25`，即比普通输入 Token 贵 25%）。首次创建缓存条目的成本略高于普通请求。
- **缓存读取倍率（Cache-read multiplier）** — 作用于从已有提示缓存中读取的 Token（默认 `0.1`，即比普通输入 Token 便宜 90%）。复用缓存内容会按大幅折扣计费。

输入与输出价格按 **曲 / 百万 Token** 参与服务端计算（页面上的单价单位标签目前显示为曲/token）。单次费用为：

```text
(输入 Token 数 × 输入价格 × 倍率
 + 输出 Token 数 × 输出价格 × 倍率
 + 缓存创建 Token 数 × 输入价格 × 缓存创建倍率
 + 缓存读取 Token 数 × 输入价格 × 缓存读取倍率) / 1,000,000
```

结果向下保留四位小数。缓存部分使用各自的缓存倍率，不再乘整体倍率；实际缓存 Token 数取决于上游返回的用量。

## IAM 定价读取权限

IAM 强制模式下，管理读取需要真实部署全局组中的 `OJ_PRICING_READ` 资格。列表使用 `quyan:oj:ListPricing`，详情使用 `quyan:oj:GetPricing`。资源为 `acs:platform:*:platform:oj-pricing/<记录 ID>`，ID 来自实际定价记录。模型名及其提供商前缀只用于查找记录，不作为 ARN 标识。

列表先逐记录授权，再加载展示价格，匹配的 Deny 优先于 Allow。强制模式下，不存在、已删除或未获授权的详情记录返回 403。读取期间价格、资格、策略或角色会话变化时，结果不会返回。AssumeRole 使用角色自身的授权。内部计费计算保留现有定价查找流程。

## IAM 定价写入权限

新增、更新和删除需要真实全局组中的 `OJ_PRICING_UPDATE` 资格，并分别使用 `quyan:oj:CreatePricing`、`quyan:oj:UpdatePricing`、`quyan:oj:DeletePricing`。新增同时检查 `acs:platform:*:platform:oj-pricing-control/default` 和实际新记录 ARN；更新、删除检查实际记录 ARN。模型名仅用于查找，不能改变授权范围。

匹配的 Deny 会阻止整个操作。保存前身份、资格、策略、角色会话或目标价格变化时，操作失败，价格变更不会部分保存。已删除模型不能直接重新创建；缺少或未授权的修改目标在 IAM 强制模式下返回 403。重放保护继续适用于三个写入接口。

## 说明

- 编辑价格时，将供应商留空保存会保留原供应商，不能通过此表单清除；保存后请核对列表显示。
- 价格变更影响后续请求的费用计算；已保存的用量记录保留当时的费用，不会按新价格重新计算。
- 大范围价格调整后，建议回看用量统计确认结果是否合理。
- 权限设置可能限制谁能新增或编辑价格。
