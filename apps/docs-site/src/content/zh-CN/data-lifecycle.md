# 数据归档与清理

数据归档页面用于管理臃肿表的热数据保留期，并查看已上传和校验的 OSS 归档文件。

## 使用前提

- 需要数据生命周期管理权限。
- 修改策略、手动执行归档和下载文件需要完成 2FA 升级认证。
- 服务端必须配置阿里云 OSS；未配置时不会执行删除。

## 默认策略

API 日志和通知日志保留 90 天；业务日志、调用用量和月卡用量保留 180 天；埋点和热图保留 30 天。归档文件保留 1 年。

余额流水不纳入自动归档或删除。

## 执行规则

1. 先预览候选记录数量。
2. 服务端将候选记录写入 gzip NDJSON 并上传 OSS。
3. 上传对象的大小和 SHA-256 校验通过后，才分批删除热表记录。
4. 运行记录会显示候选、归档和删除数量；失败时保留源数据并可重试。

归档明细首版通过管理员下载文件访问，不在应用内全文检索。归档文件到期后会自动从 OSS 删除。
