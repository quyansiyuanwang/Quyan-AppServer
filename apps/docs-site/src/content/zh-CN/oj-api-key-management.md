# OJ API Key 管理

此页面用于维护 OJ 提交器工作流所需的 API Key。

## 页面用途

- 创建和管理 OJ 提交器 API Key。
- 查看绑定渠道与用量。
- 在需要更换凭据时创建新 Key 并删除旧 Key。

## 你会看到什么

### Key 列表

- Key 名称。
- 掩码显示的密钥；仅在接口返回凭据时可复制。
- 绑定渠道。
- 请求次数与累计 Token。
- 最后使用时间与到期时间。

### 管理动作

- 新建 Key。
- 编辑 Key。
- 复制 Key。
- 删除 Key。

## 常见操作

1. 为提交器或具体场景创建易识别名称的 Key。
2. 创建后立即复制并妥善保存。
3. 排查请求失败前先检查绑定渠道和到期时间。
4. 更换凭据时，创建并保存新 Key，更新提交器配置，确认新 Key 可用后删除旧 Key。删除需要二次验证；删除后旧 Key 不再可用。

## 说明

- IAM 强制模式下，读取 Key 信息与披露凭据是独立权限；没有对应 `quyan:oj:RevealApiKey` 授权时，创建或列表响应可能不返回密钥，页面也无法复制。具有披露权限时，列表可以再次返回凭据，请严格控制访问。
- OJ API Key 与普通账号访问密钥是分开的。
- 用量异常时，配合用量统计页更容易定位问题。
