# 远程终端管理

管理员通过套餐模板、用户权益和设备绑定三个独立管理页面，提供远程终端套餐、分配或调整用户配额，并回收设备绑定。用户自行购买和安装请参阅[我的远程终端产品]({{DOCS_BASE_URL}}/zh-CN/my-remote-terminal-products)。

## 开始前

管理页面和按钮按权限开放，能读取记录不代表能修改。IAM 强制模式下，还需满足部署管理员配置的全局管理组资格以及目标资源授权；账号自己的策略或用户组不能自行取得平台管理资格。

| 管理任务                           | 兼容权限及页面能力                         |
| ---------------------------------- | ------------------------------------------ |
| 读取套餐                           | `REMOTE_TERMINAL_PRODUCT_READ`             |
| 创建、编辑、发布、下架、删除套餐   | `REMOTE_TERMINAL_PRODUCT_WRITE`            |
| 读取用户权益                       | `REMOTE_TERMINAL_ASSIGNMENT_READ`          |
| 分配、编辑、删除权益及重置解绑计数 | `REMOTE_TERMINAL_ASSIGNMENT_WRITE`         |
| 轮换注册令牌                       | `REMOTE_TERMINAL_REGISTRATION_TOKEN_WRITE` |
| 读取管理端设备绑定                 | `REMOTE_TERMINAL_DEVICE_MANAGE_READ`       |
| 撤销设备绑定                       | `REMOTE_TERMINAL_DEVICE_WRITE`             |

启用2FA的操作者执行管理写操作时，可能需要完成二次验证；是否可使用已有受信任窗口，以当前安全规则为准。可见按钮不能替代服务端检查。

## 查询记录

- 套餐页按名称关键词和管理状态筛选；权益页按用户、套餐和状态筛选；设备页按用户、权益和绑定状态筛选。发布状态与启用状态是不同条件，设备绑定状态也不等于在线状态。
- 三个列表均在服务端分页，默认每页20条，可选20、50、100条。筛选变化回到第一页；写操作后刷新当前页，页码失效时重新请求最后一个有效页。
- 用户、套餐和权益选择器独立搜索或分页。设备页的权益候选随所选用户缩小；看不到用户不代表用户不存在，用户选择器还需用户目录读取权限。
- 加载或失败时清空旧记录，失败后刷新重试；身份或权限变化会清空列表、候选和已打开的对话框。IAM 强制模式的总数只统计获准记录，空字段也可能是关联资源无权读取，不要用旧候选信息补全判断。

## 创建和发布套餐

1. 打开套餐管理，点击创建，填写名称、说明、计费单位和价格。
2. 设备价格对应购买的设备名额，终端价格对应购买的并发终端配额；不是按实时在线设备或实际使用次数扣款。至少提供一种计费项目，留空表示不提供，填0表示免费。
3. 设置最低和最高购买单位数、最低和最高设备/终端数量。最低购买单位数为正整数，最高值不能低于最低值；检查所填配额范围是否符合预期。
4. 如需限购，同时填写“每用户数量”和“窗口天数”，或同时清空。该限制按窗口内新建的同模板权益数量统计；新购和基于模板的管理员分配会受其影响。
5. 保存后核对记录，再点击发布。只有启用的套餐可发布，只有启用且已发布、用户获准访问的套餐才在个人购买页显示。

1周为7天，1月为30天。价格最多4位小数，后续购买、续期和升级按提交时的套餐价格计算，具体估价差异见个人购买文档。

发布和下架点击后直接提交；删除需要确认。下架停止新的自助购买和续期，删除也会移除购买入口，但都不会自动删除已有用户权益。已有权益的有效期和配额需在权益管理中单独处理。编辑套餐不会直接批量修改已有权益。

当前套餐编辑表单不提供启用/禁用开关；若记录被禁用，发布会被拒绝，请由有权管理员通过支持的管理接口处理。编辑时清空说明不会删除原说明；可选价格、限购和数量上限清空后则按表单提交结果移除，请保存后核对。

## 分配用户权益

1. 打开权益管理，点击分配，选择目标用户；可选择模板，也可不选。
2. 填写生效和到期时间，到期必须晚于生效。设备和终端配额为0–999999的整数，至少一项大于0。设备配额为0时不能注册设备。
3. 不选模板时必须填写名称；选模板且名称留空时沿用模板名称。可填写说明和备注。
4. 提交后刷新，核对接收用户、模板、有效期和配额。管理员分配不扣用户余额，不能将分配成功当作付费购买流水。
5. 让用户在“我的远程终端产品”中完成令牌和安装步骤。IAM 强制模式下，分配不会创建注册令牌，需由获授权的本人或管理员另行轮换创建。

模板用于关联套餐和复制部分信息，**选择模板不会自动替用户填写配额和有效期**，分配也不要求模板已发布；请核对实际填写值。模板限购仍会检查。

**当前表单限制：**新分配时，“最大设备数/最大终端数”字段虽然可填，但不会随分配请求保存。若需要这些字段，请创建后通过编辑或调整限制保存，并重新读取确认。

## 修改、调整和删除权益

在权益行点击编辑，可修改名称、说明、有效期、配额、最大数量和备注；“调整限制”提供配额及最大数量的快捷编辑入口。

- **编辑不会转移用户或更换模板。**当前表单仍显示这两个选择器，但保存时不提交它们。需要给另一用户提供权益时，请单独分配，再按实际业务决定是否删除旧权益。
- 设备配额不能低于当前尚未解绑的设备数量，其中包括禁用绑定。先核对并处理不需要的绑定，再降低名额。配额至少一项为正，不能通过同时设0回收全部能力。
- 管理员调整不是用户付费续期或升级，不会扣用户余额；当前编辑也不修改历次累计实付。请先与用户确认生效时间和配额变化。
- 清空名称、说明或备注不会通过当前页面清除原值；清空可选最大数量则会提交清除。完整编辑中把时间留空会保留已有时间。
- 删除需要确认，会使该权益不再提供有效配额和设备访问；不会自动退款或卸载 Agent。删除前核对用户和权益，保存或删除后刷新确认。

增加设备配额不等于拿到安装凭据；IAM 强制模式下不会自动创建注册令牌，请使用独立的令牌操作。

## 轮换注册令牌

权益列表只显示获准的令牌标签和到期等元数据，不提供找回旧明文的操作。有设备配额且具备令牌写入权限时，可点击轮换。

1. 核对用户与权益，填写令牌标签和到期时间；空标签、空到期会分别清除现有标签和到期限制。关联元数据不可读时表单也可能为空，提交前确认期望值。
2. 确认后会生成新令牌，旧令牌立即不能用于新的注册。这会影响仍保存旧令牌的安装脚本或配置，操作前请与用户协调。
3. **当前管理页面不会展示或复制轮换响应中的新明文。**不要把刷新后的列表当作令牌交付入口。需要用户取得明文时，应让获授权的用户在个人产品页再次轮换并安全保存最新令牌，再获取安装命令。

服务端明确拒绝时原令牌保留；超时或连接中断时不能据此判断轮换失败。先协调由有权用户取得最新凭据，避免继续使用不确定的旧令牌。不要通过公开消息转发令牌。

## 撤销绑定与重置解绑计数

在设备管理中按用户或权益定位设备，核对主机名、客户端设备ID和绑定状态，点击撤销并确认。绑定状态表示启用、禁用或已撤销，不是在线/离线指示；最后在线时间也不证明当前仍在线。

管理员撤销不检查个人解绑窗口次数，仍受管理资格、资源授权、二次验证和服务端请求规则限制，不能理解为可不受限制撤销任意用户设备。它会撤销平台绑定，不会卸载设备 Agent；设备重新绑定仍需满足冷却、权益和令牌条件。

在权益的“调整限制”对话框中，点击“重置解绑计数”并确认，会单独执行重置，**无需先保存配额，关闭对话框也不会撤销已完成的重置**。尚未提交的配额编辑不因此保存。

重置只改变该权益的解绑计数起算点，不会修改全局解绑开关、最大次数或设备重新绑定冷却时间；已有解绑记录和已撤销绑定仍保留。全局最大次数为0时，重置后用户仍不能自行解绑。

## 常见问题

| 现象                       | 处理方法                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------- |
| 管理列表或候选为空         | 检查加载错误、筛选和页码，以及全局管理资格、资源策略和用户目录权限；成功刷新后再判断。 |
| 保存成功但列表未显示新结果 | 随后的读取可能失败或资源不可见。成功刷新并核对目标后再决定是否重试，避免重复分配。     |
| 分配或修改请求超时         | 先按用户和权益刷新，核对有效期、配额及记录，再决定下一步。超时不等于事务未提交。       |
| 无法降低设备数             | 核对当前未解绑数量，包括禁用绑定；处理相应绑定后再调整。                               |
| 轮换成功却找不到令牌       | 当前管理页不展示新明文，请按上面的个人轮换流程取得最新凭据。                           |
| 重置后仍无法重新绑定       | 重置解绑次数不解除设备冷却，也不恢复过期权益、缺失令牌或设备名额。                     |

## IAM 权限与资源范围

启用 IAM 强制授权后，套餐管理列表使用 `quyan:remote_terminal:ListTemplates`，逐条检查 `acs:platform:*:platform:remote-terminal-template/<templateId>`。分页记录和总数只包含获准查看的模板；未匹配 Allow 或匹配 Deny 的模板不会返回。模板属于部署共享资源，除了 IAM 策略，还必须保留部署管理员配置的全局管理组权限上限，账号自己的策略或用户组不能自行取得这项管理资格。这一读取权限不会授予创建、修改或发布模板的权限。

权益筛选和分配对话框中的套餐选择器支持服务端搜索与分页。启用 IAM 强制模式后，`quyan:remote_terminal:ListTemplateOptions` 按套餐 ARN 分别控制可选范围，仅返回获准套餐的名称、发布状态和启用状态，不授予价格或完整套餐详情的读取权限。选项总数只计算获准套餐；未获得授权或命中显式 Deny 的套餐不会出现在选择器中。切换搜索、翻页或刷新失败时会清空旧选项。

启用 IAM 强制模式后，套餐写操作分别使用 `quyan:remote_terminal` 服务下的 `CreateTemplate`、`UpdateTemplate`、`PublishTemplate`、`UnpublishTemplate` 和 `DeleteTemplate`。通过更新接口将套餐改为删除状态也需要 `DeleteTemplate`。创建操作需要同时获得对 `acs:platform:*:platform:remote-terminal-template-control` 和新生成套餐 ARN 的 `CreateTemplate` 授权；未来套餐可使用 `acs:platform:*:platform:remote-terminal-template/*` 匹配。这些授权仍受部署管理员配置的全局管理用户组范围限制。操作完成前若权限或套餐数据发生变化，写入会被拒绝并回滚。

管理端权益列表仅展示注册令牌的元数据，不返回完整令牌。个人安装令牌和长期令牌轮换采用各自独立的授权流程。

启用 IAM 强制模式后，权益管理列表使用 `quyan:remote_terminal:ListEntitlements`，检查 `acs:platform:*:platform:remote-terminal-entitlement/<userId>/<entitlementId>`。总数只包含获准权益。相同 Action 还分别控制关联的 `user/<userId>`、`remote-terminal-template/<templateId>`、`remote-terminal-registration-token/<userId>/<entitlementId>/<tokenId>` 和 `remote-terminal-device-binding/<userId>/<bindingId>` 平台资源。未获准的用户名、套餐名称或令牌元数据会省略；只要一个设备绑定不可读，就会省略设备总数，而不会显示零或部分数量。管理列表中的令牌始终完全遮罩，不返回明文。个人安装和令牌轮换保持各自的授权流程。此操作仍要求部署管理员配置的全局权益读取权限上限。

套餐、权益和设备管理表格均使用服务端分页，可调整每页条数并查看当前查询的总数；IAM 强制模式下，已经完成资源授权迁移的列表只统计获准记录。更改筛选条件会回到第一页，写操作后刷新当前页；删除或授权范围缩小时，若当前页已不存在，会重新请求最后一个有效页。设备筛选中的权益选择器单独分页，并按所选用户限制候选范围。加载和失败时清空旧记录，失败后可点击刷新重试；切换身份或权限时会清空列表、选择器和已打开的管理对话框。

启用 IAM 强制模式后，设备管理列表使用 `quyan:remote_terminal:ListDeviceBindings`，逐条检查 `acs:platform:*:platform:remote-terminal-device-binding/<userId>/<bindingId>`。相同 Action 分别控制关联的 `acs:platform:*:platform:user/<userId>` 和 `acs:platform:*:platform:remote-terminal-entitlement/<userId>/<entitlementId>`；没有获准关联资源时，用户名或权益名称会省略。分页和总数只包含获准设备，响应仅提供公开设备字段与可用 shell 名称，不返回心跳凭据或完整设备快照。管理资格仍由部署管理员配置的全局设备管理读取权限限制。此 Action 不授予终端会话、目录访问或设备撤销权限；个人终端的 `ListDevices` 授权保持独立。

权益和设备筛选、权益分配对话框中的用户选择器支持服务端搜索与独立分页。候选用户及其总数由用户列表接口的权限决定，不会因拥有设备或权益管理权限而自动获得用户目录访问。可翻页浏览搜索结果；失败后可刷新重试，切换身份或权限会清空候选。编辑已有权益时，已选用户可保留当前获准记录中的显示名称。设备表格显示主机名、客户端设备 ID 和实际绑定状态；关联用户或权益名称被拒绝时不会从旧候选缓存补回。

启用 IAM 强制模式后，管理写操作也按目标资源限制：`quyan:remote_terminal:RevokeDeviceBinding` 控制 `acs:platform:*:platform:remote-terminal-device-binding/<userId>/<bindingId>`；`quyan:remote_terminal:DeleteEntitlement` 和 `quyan:remote_terminal:ResetUnbindCount` 控制 `acs:platform:*:platform:remote-terminal-entitlement/<userId>/<entitlementId>`。资源中的用户 ID 由服务端确认。操作人员仍须属于具有对应管理资格的全局组；已启用 2FA 时可能需要完成二次验证。具体资源被拒绝或操作期间授权发生变化时，操作失败。管理员解绑不受个人解绑次数检查限制，重置次数只影响所选权益。

注册令牌轮换使用 `quyan:remote_terminal:RotateRegistrationToken`。该 Action 同时控制权益资源 `acs:platform:*:platform:remote-terminal-entitlement/<userId>/<entitlementId>` 和令牌资源 `acs:platform:*:platform:remote-terminal-registration-token/<userId>/<entitlementId>/<tokenId>`；首次创建可使用当前权益下的令牌通配范围。仅有权益管理权限不足以轮换指定令牌，还须具备全局组配置的注册令牌管理资格。轮换成功后返回新令牌；授权检查失败时保留原令牌，界面不会得到新凭据。

IAM 强制模式下，修改权益使用 `quyan:remote_terminal:UpdateEntitlement`，资源为 `acs:platform:*:platform:remote-terminal-entitlement/<userId>/<entitlementId>`；将状态设为删除还需要 `quyan:remote_terminal:DeleteEntitlement`。修改结果仅返回权益字段，不返回注册凭据或关联资源详情。增加设备额度不会自动签发注册令牌，获取凭据需使用具有独立授权的注册令牌轮换操作。权益、归属用户、已注册设备或授权在修改期间发生变化时，本次修改不会提交。

分配权益使用 `quyan:remote_terminal:AssignEntitlement`，同时检查目标平台用户、选用的远程终端模板和新建权益。策略中的用户与权益资源范围必须覆盖接收者；使用模板分配时还需包含该模板的资源。模板限购在分配事务中检查，新建权益命中 Deny 时整个分配回滚。管理员分配不扣取用户余额，也不签发注册令牌；获取凭据需另行使用令牌轮换操作。
