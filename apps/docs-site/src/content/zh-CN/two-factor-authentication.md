# 两步验证与通行密钥

两步验证（2FA）为您的账户增加额外安全层。启用后，登录时可能需要额外的验证；受信任设备和通行密钥策略会影响验证要求。通行密钥（Passkey）支持使用生物识别或设备 PIN 进行无密码登录。

## 两步验证概览

系统支持基于 TOTP 的 2FA，可使用任何验证器应用（Google Authenticator、Authy、1Password 等）。验证码周期默认为 30 秒，具体以服务端配置为准。

### 启用 2FA

1. 打开**设置 → 账户安全**，找到两步验证区域。
2. 点击启用按钮，系统将展示二维码和设置密钥。
3. 使用验证器应用扫描二维码；无法扫码时，可在验证器中手动输入设置密钥。请勿将二维码或密钥分享给他人。
4. 输入应用显示的 6 位验证码以确认。
5. 在恢复代码弹窗关闭前，将显示的代码保存在安全的地方。可使用“复制”，复制失败时可手动记录。关闭弹窗后按页面提示处理重新登录。

### 恢复代码

启用 2FA 时会生成一组恢复代码（默认 10 个，数量以服务端配置为准）。丢失验证器设备时，可用恢复代码完成二次验证，每个代码仅可使用**一次**。

- 离线保存恢复代码（打印或手写记录）。
- 不要将恢复代码与验证器应用放在同一设备上。
- 当前设置页面没有重新生成恢复代码的入口。具备相应权限的 API 调用方可使用 `POST /v1/users/me/2fa/recovery-codes/regenerate`，并提供有效的动态码或恢复码；请求还需满足重放保护要求。重新生成会替换旧恢复码，请立即安全保存新的一组。

### 禁用 2FA

1. 在**设置 → 账户安全**的两步验证区域点击关闭按钮。
2. 在验证界面输入有效的 TOTP 动态码，或切换为恢复码并输入一个未使用的代码。此操作不接受邮箱验证码。
3. 提交成功后，按页面提示重新登录。

关闭后，原验证器配置和恢复代码失效，受信任设备记录会被清除，现有登录会话也会被撤销。系统会触发状态变更通知；是否收到邮件或其他推送取决于通知设置及渠道可用性。以后重新启用时，需要重新绑定验证器并保存新恢复代码。

## 通行密钥

通行密钥允许您使用设备的生物识别传感器（指纹、面部扫描）或 PIN 进行无密码登录。相比密码更安全且能抵御钓鱼攻击。

### 通行密钥要求

- **2FA 要求**: 如已启用 2FA，使用通行密钥登录时可能仍需二次验证，取决于账户的通行密钥策略。
- **设备支持**: 通行密钥需要兼容的浏览器和设备（大多数现代浏览器在 Windows、macOS、iOS 和 Android 上均支持）。
- **同步通行密钥**: 可通过平台的凭证管理器（iCloud 钥匙串、Google 密码管理器）跨设备同步。

### 管理通行密钥

1. 在**设置 → 账户安全**打开通行密钥管理，查看已有凭据。
2. 点击**注册**进入认证站，再按提示注册新通行密钥；完成后返回账户安全页。
3. 删除不再使用的通行密钥。删除前确认仍有可用的登录方式。
4. 已启用 2FA 的账户可在两步验证区域调整通行密钥登录是否仍需 2FA。保存成功后，按提示重新登录。

该开关只调整通行密钥登录的二次验证策略，不会注册或删除通行密钥，也不会关闭账户的 2FA。即使开启，信任窗口内的设备仍可能跳过常规登录验证；高危操作仍按自身规则要求验证。

完整字段说明与已备份通行密钥的说明参见[通行密钥管理]({{DOCS_BASE_URL}}/zh-CN/passkey-management)。

## 受信任设备

完成 2FA 登录后，系统可将当前浏览器记录为受信任设备。在配置的信任窗口内（默认 24 小时），该设备上的常规操作将跳过 2FA 验证。

### 受信任设备适用范围

| 操作类型                                          | 是否接受受信任设备？             |
| ------------------------------------------------- | -------------------------------- |
| 普通登录                                          | 是                               |
| 标准二次验证（如修改邮箱）                        | 是                               |
| 高危操作（删除访问密钥、删除 RAM 用户、解绑策略） | **否** — 启用 2FA 后要求重新验证 |
| 禁用 2FA                                          | 否 — 需要验证码或恢复代码        |

### 管理受信任设备

1. 进入账户设置 → 安全 → 受信任设备。
2. 查看当前在信任窗口内的设备列表。
3. 移除任何不认识的设备。
4. 如怀疑账户被盗用，检查所有分页并逐个移除可疑设备。

完整设备列表字段及信任窗口与高危操作的交互说明参见[受信任设备管理]({{DOCS_BASE_URL}}/zh-CN/trusted-device-management)。

## 安全说明

- 2FA 验证码基于 TOTP 且依赖时间同步，请确保设备时钟准确。
- 恢复代码为一次性使用，使用后立即失效。
- 修改密码**不会**禁用 2FA。
- 2FA 状态变更会触发通知事件，请保持通知设置为最新。

## 所需权限

管理账户安全设置需要登录；具体操作还受账户的权限策略约束。如果操作被拒绝，请联系账户管理员检查授权。
