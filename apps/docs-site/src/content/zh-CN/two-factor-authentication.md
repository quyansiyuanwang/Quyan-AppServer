# 两步验证与通行密钥

两步验证（2FA）为您的账户增加额外安全层。启用后，登录需要同时提供密码和基于时间的一次性验证码。通行密钥（Passkey）支持使用生物识别或设备 PIN 进行无密码登录。

## 两步验证概览

系统支持基于 TOTP 的 2FA，可使用任何验证器应用（Google Authenticator、Authy、1Password 等）。每个验证码有效期为 30 秒。

### 启用 2FA

1. 进入账户设置 → 安全 → 两步验证。
2. 点击"启用"，系统将展示二维码和设置密钥。
3. 使用验证器应用扫描二维码。
4. 输入应用显示的 6 位验证码以确认。
5. 将恢复代码保存在安全的地方。

### 恢复代码

启用 2FA 时会生成 10 个恢复代码，每个代码仅可使用**一次**来绕过 2FA（如丢失验证器设备时）。

- 离线保存恢复代码（打印或手写记录）。
- 不要将恢复代码与验证器应用放在同一设备上。
- 可从 2FA 设置页面重新生成恢复代码（需验证当前 2FA）。

### 禁用 2FA

禁用 2FA 需要提供有效的 TOTP 验证码或恢复代码。系统会发送通知确认状态变更。

## 通行密钥

通行密钥允许您使用设备的生物识别传感器（指纹、面部扫描）或 PIN 进行无密码登录。相比密码更安全且能抵御钓鱼攻击。

### 通行密钥要求

- **2FA 要求**: 如已启用 2FA，使用通行密钥登录时可能仍需 TOTP 验证码，取决于账户的通行密钥策略。
- **设备支持**: 通行密钥需要兼容的浏览器和设备（大多数现代浏览器在 Windows、macOS、iOS 和 Android 上均支持）。
- **同步通行密钥**: 可通过平台的凭证管理器（iCloud 钥匙串、Google 密码管理器）跨设备同步。

### 管理通行密钥

1. 进入账户设置 → 安全 → 通行密钥。
2. 查看所有已注册的通行密钥（含创建时间和最后使用时间）。
3. 按浏览器提示添加新通行密钥。
4. 移除不再使用的通行密钥。
5. 可选择开启"即使使用通行密钥登陆仍需要 2FA"以增强安全性。

## 受信任设备

使用 2FA 成功登录后，可将当前浏览器标记为受信任。在配置的信任窗口内（默认 24 小时），该设备上的常规操作将跳过 2FA 验证。

### 受信任设备适用范围

| 操作类型 | 是否接受受信任设备？ |
|---------|------------------|
| 普通登录 | 是 |
| 标准二次验证（修改邮箱、资料编辑） | 是 |
| 高危操作（删除访问密钥、删除 RAM 用户、解绑策略） | **否** — 始终要求重新验证 |
| 禁用 2FA | 否 — 需要验证码或恢复代码 |

### 管理受信任设备

1. 进入账户设置 → 安全 → 受信任设备。
2. 查看当前在信任窗口内的设备列表。
3. 移除任何不认识的设备。
4. 如怀疑账户被盗用，清除所有受信任设备。

## 安全说明

- 2FA 验证码基于 TOTP 且依赖时间同步，请确保设备时钟准确。
- 恢复代码为一次性使用，使用后立即失效。
- 修改密码**不会**禁用 2FA。
- 2FA 状态变更会触发通知事件，请保持通知设置为最新。

## 所需权限

| 操作 | 所需权限 |
|------|---------|
| 管理自己的 2FA | 无（所有用户均可） |
| 管理自己的通行密钥 | 无（所有用户均可） |
| 管理受信任设备 | 无（所有用户均可） |
