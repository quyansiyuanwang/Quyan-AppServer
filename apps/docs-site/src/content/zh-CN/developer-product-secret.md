# 密钥托管

密钥托管用于保存第三方 API Key、Webhook Secret 等部署期凭据。每个别名在实例内唯一，值只写不可读：创建和轮换后控制台只显示别名、版本、更新时间和最后使用时间，永远不会回传明文。

## 使用方式

别名必须以大写字母开始，之后只能包含大写字母、数字和下划线，例如 `OPENAI_KEY`。在支持的 API 转发出站请求中，可在请求头或 JSON 字符串值中使用 `{{OPENAI_KEY}}`。替换只发生在请求离开平台前，日志和错误信息只保留别名。

未定义别名、格式错误的嵌套占位符或替换后超出请求限制都会阻止请求。不要把占位符用于 URL、路径、查询参数或 JSON 对象键；这些位置不属于首期替换范围。

## 生命周期与权限

新增或轮换需要密钥写入权限，删除需要密钥管理权限，查看元数据需要密钥读取权限。删除是不可恢复的；若下游仍引用该别名，后续调用会被明确拒绝。平台使用独立主密钥以加密方式保存密文、IV 和认证标签。
