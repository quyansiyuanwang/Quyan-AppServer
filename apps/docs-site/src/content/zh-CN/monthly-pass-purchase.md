# 月卡购买

在“我的月卡”的 **月卡购买中心** 标签页选择已发布的方案，使用余额兑换月卡。购买后可在 **查看我的月卡** 标签页查看生效时间、额度和可用范围。

## 购买前确认

- 模板处于启用、已发布状态，并允许余额兑换。
- 查看价格、有效期、总额度和额度窗口，以及可用渠道和模型。月卡不能保证覆盖所有请求，未覆盖部分仍可能从余额扣费，详见[我的月卡]({{DOCS_BASE_URL}}/zh-CN/my-monthly-passes)。
- 账户余额足够，且未超过模板配置的用户购买次数限制。
- 价格换算与购买限制以服务端当前规则为准；模板规则变更时可能需要重新确认。

## 购买步骤

1. 打开“我的月卡”，选择 **月卡购买中心**，然后选择需要的方案。
2. 阅读确认框中的扣款信息并确认购买。
3. 购买成功后，查看实际扣款金额。
4. 重新加载页面后，在 **查看我的月卡** 标签页检查新月卡；到余额记录检查对应账单。

扣款、账单和新月卡一起完成。授权失败、报价变化或购买限额检查失败时，本次操作不会留下扣款或新月卡。免费方案仍受购买次数限制。

## IAM 权限

启用 IAM 强制授权时，购买使用 `quyan:monthly_pass:ClaimPublishedTemplate`，同时检查以下资源：

| 资源               | ARN                                                             |
| ------------------ | --------------------------------------------------------------- |
| 当前用户           | `acs:quyan:*:<accountId>:user/<userId>`                         |
| 当前用户的模板视图 | `acs:monthly-pass:*:<accountId>:template/<userId>/<templateId>` |
| 新建月卡           | `acs:monthly-pass:*:<accountId>:assignment/<userId>/<passId>`   |

自己的购买资源具有默认自助授权；显式 Deny 仍优先。可以通过模板 ARN 限制某个用户购买特定方案，或通过 `assignment/<userId>/*` 限制新建月卡。模板 ARN 只表示与该身份关联的模板视图，不授予管理共享模板的权限。

API 请求为 `POST /v1/monthly-passes/me/claim`，请求体只需 `{ "templateId": "<templateId>" }`。用户和账号从当前登录身份确定。

查看方案列表使用 `quyan:monthly_pass:ListPublishedTemplates`，逐一检查 `acs:monthly-pass:*:<accountId>:template/<userId>/<templateId>`。自己的已发布方案视图具有默认自助授权，显式 Deny 的模板不会出现在列表中。查看与购买分别授权：能看到方案不代表可以购买，拒绝购买也不会自动隐藏方案。

## 常见问题

- 请求超时或连接中断：结果可能尚未确认。重新加载页面并检查“查看我的月卡”和余额记录，再决定是否重试。月卡列表仅加载前 100 条，且可能受权限过滤；没有看到新月卡不能证明购买失败。免费方案也可能没有扣款可供核对。如仍不确定，请联系管理员核查，避免重复购买。
- 余额不足：先检查余额和实际换算后的价格。
- 达到次数上限：等待配置的购买窗口结束，或联系管理员确认限制。
- 提示无权限：请管理员检查当前身份、模板和新月卡的策略，以及显式 Deny。
- 方案在确认期间变化：重新加载整个页面，再查看购买中心显示的价格和条件。顶部的刷新按钮更新页头余额和方案数据，但不会刷新购买中心当前显示的方案卡片。
