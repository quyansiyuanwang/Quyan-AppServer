# OJ 用量统计

OJ 用量统计用于核对当前登录用户的提交器请求记录、Token 用量和已结算费用。它不汇总同一账号下其他用户的用量，也不提供按用户切换查询。

## 使用前提

进入 OJ 用量统计页面需要 `OJ_USAGE_READ`。查询使用登录身份；OJ API Key 用于提交问题，不能替代登录凭据读取此页。

IAM 强制模式还需要 `quyan:ojqa:GetUsage` 对当前用户资源 `acs:quyan:*:<账号 ID>:user/<当前用户 ID>` 的授权。账号 ID 是所属主账号的 ID。页面入口可见不代表查询一定获准，匹配的 Deny 或角色会话限制仍会影响结果。

## 查询时间范围

1. 打开页面，等待查询完成并确认没有加载错误。初始查询没有日期限制。
2. 选择开始和结束日期。日期变更后立即查询。
3. 核对顶部汇总，再查看明细。需要清除日期并回到第一页时，单击重置。

时间按浏览器本地日期选择，发送查询时转换为标准时间。桌面端结束日期通常为当天 00:00；如需包含目标日的全天记录，可选次日为结束日期，并注意次日零点记录也可能包含。移动端结束日期扩展至当天 23:59:59.999。

更改日期会保留当前页。若明细为空，可先重置，再重新选择时间。页面没有自动刷新；需要更新时可重新选择日期、重置或重新进入页面。切换设备布局后，建议先重置再设置日期，避免保留原布局的筛选。

## 理解汇总指标

汇总覆盖当前用户在所选时间内的全部有效用量记录，不限于当前页。

| 指标       | 含义                                              |
| ---------- | ------------------------------------------------- |
| 请求数     | 已保存的用量记录数量，不是所有调用尝试次数        |
| 总 Token   | 输入 Token 与输出 Token 之和                      |
| 总费用     | 记录中已保存费用的合计，显示四位小数              |
| 平均 Token | 总 Token 除以请求数，四舍五入为整数；无记录时为 0 |

上游失败、请求校验失败或结算未完成的调用不会形成对应的用量记录，因此请求数不能用于计算所有尝试的成功率。调用可能已在上游执行后才发生结算失败，不能仅凭这里没有记录断定请求从未发送。

缓存创建和读取 Token 不单列在此页，也不计入这里的总 Token，但可能产生费用。历史记录保留当次结算金额，修改模型价格不会重新计算历史费用。费用核对请参见 [OJ 价格管理]({{DOCS_BASE_URL}}/zh-CN/oj-pricing-management)。

## 查看明细和详情

列表按记录时间从新到旧排列，展示模型、题目、输入与输出 Token、总 Token、费用和本地时间。初始每页请求 20 条；桌面端提供 10、20、50 条选项。

**当前查询接口未返回总记录数，页面分页总数可能显示 0，后续页也可能无法通过分页控件访问。** 这不代表顶部汇总或已显示记录为零。需要继续核对时，可缩小日期范围；有集成需求时，使用有权限的登录身份调用 `GET /v1/products/oj-submitter/usage`，显式指定 `page` 和 `pageSize`。页码从 1 开始，每页最多 200 条；响应也不包含总数，不能据此承诺一次取得全部记录。

单击查看详情可核对已加载记录的模型、时间、Token 和费用，并阅读完整题目与回答。打开详情不会重新查询记录，需要获取新数据时应先重新查询列表。分享记录前请检查题目和回答是否包含敏感内容。

页面没有模型、题目或 API Key 筛选，也没有导出、图表或按 Key 归因。单条返回记录不含 Key 标识；每个 Key 的累计请求数和 Token 请到 [OJ API Key 管理]({{DOCS_BASE_URL}}/zh-CN/oj-api-key-management)查看。

## 常见问题

| 现象                         | 处理方法                                             |
| ---------------------------- | ---------------------------------------------------- |
| 顶部有请求数，分页总数却为 0 | 当前接口未返回分页总数，按汇总口径核对并缩小日期范围 |
| 结束日的记录少于预期         | 检查桌面端结束时间是否为当天零点，以及本地时区       |
| 日期变更后明细为空           | 重置回到第一页，再重新选择日期                       |
| 查询失败后仍有旧汇总或明细   | 旧结果不会自动清除，成功重查后再据此判断             |
| 初始汇总为 0 且提示加载失败  | 先解决认证、授权或网络错误，不能当作无用量           |
| 费用与总 Token 不成比例      | 核对请求模型、当次价格以及独立的缓存费用             |
| 删除 Key 后历史用量仍在      | 删除凭据不等于删除已结算的用量记录                   |
