# OJ 用量统计

此页面用于查看当前登录用户的 OJ 提交器请求量、Token 用量和费用明细。

## 页面用途

- 分析 OJ 提交器在一段时间内的使用情况。
- 比较请求、Token 和费用总量。
- 查看详细使用记录。

## 你会看到什么

### 筛选与汇总

- 时间范围筛选。
- 请求数、Token、费用、平均 Token 等汇总指标。

### 用量列表

- 表格或卡片列表。
- 模型、题目、Token、费用等字段。
- 分页控件；当前接口未返回总记录数，页面分页可能无法访问后续记录。

### 详情视图

- 完整题目内容。
- 完整回答内容。

## 常见操作

1. 先设置要查看的时间范围。
2. 先观察顶部汇总，再进入明细。
3. 在返回的明细中查看模型和题目内容；页面不提供模型或题目筛选。
4. 需要完整上下文时打开详情记录。

## 说明

- 初始没有日期限制；点击**重置**可清除日期筛选。桌面端日期范围按选择器返回的时间查询，结束日期通常为当天 00:00；移动端结束日期会扩展至当天 23:59:59.999。要在桌面端包含目标日期的全天记录，可将结束日期选为次日，并留意次日零点的记录也可能包含在内。
- 更改日期会立即查询并保留当前页；如明细为空，可点击“重置”回到第一页后重新设置日期。查询失败时可能保留上次结果，请检查错误提示并重试后再核对汇总和明细。
- 详情中可能包含敏感题目或回答内容。
- 费用突变更适合结合价格配置一起解释。
- 明细不显示 API Key 标识，不能通过此页面将单条请求归因到某个 Key。Key 管理页提供各 Key 的累计请求数和 Token 用量。
- 汇总 Token 数为输入和输出 Token 数之和；缓存创建和读取 Token 不单独显示在此页面。
