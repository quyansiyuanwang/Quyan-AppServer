# 服务端配置

此页面供部署管理员维护注册、计费、邮件、安全校验和资源容量等全局设置。修改可能影响所有用户；请先读取当前值，再按区块保存，并在对应业务中验证结果。

## 开始前

- 使用具有 `SYSTEM_CONFIG` 管理资格的账户；启用 IAM 强制授权的部署还需相应配置键的读取和更新授权，具体见下文。
- 已启用 2FA 的操作者保存时可能需要二次验证，有效受信任窗口按当前规则处理。保存还需通过重放保护。
- 先记录需要恢复的原值。密钥存在标记不是可用于恢复的密钥原文；请在原有安全保管渠道保留凭据。

## 选择配置区块

| 区块                            | 主要参数                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------ |
| **注册**                        | 是否开放注册、每邮箱最大账号数、默认群组、验证码有效期（秒）                   |
| **计费**                        | 充值比率、赠送码与直接转账开关、两类手续费率、赠送码取消手续费返还比例         |
| **SMTP**                        | 主机、端口、TLS、发件人账号与名称                                              |
| **验证码**                      | 提供商（`recaptcha` / `turnstile` 等）、备用提供商、最低分值、信任窗口（分钟） |
| **心跳**                        | 检测间隔秒数、超时秒数                                                         |
| **IP 封禁、错误衰减、错误权重** | 分别设置三级阈值与封禁时长、衰减参数、HTTP 状态码及业务错误码权重              |
| **站点**                        | 后端公网地址，用于通知邮件的阅读跟踪图片链接                                   |
| **社交登录**                    | 登录结果前端地址、扫码登录开关与时效、GitHub 和微信登录凭据                    |
| **远程终端解绑**                | 个人解绑次数、统计窗口、重新绑定冷却时间                                       |
| **中继上游代理**                | 代理开关与 HTTP/HTTPS/SOCKS 地址；仅对渠道开关开启的请求生效                   |
| **通知**                        | 默认订阅事件列表、余额告警阈值                                                 |
| **AI 资源保护**                 | 并发、排队、内存、正文、流解析、连接池和审计等容量参数                         |

此页面没有中继上游密钥或自动代理池的独立编辑区块；这类设置请到对应管理入口或使用已授权接口，勿将“中继上游代理”误认为上游模型服务地址。

### 公开只读端点

- `GET /v1/config/public/registration` — 前端用于判断是否显示注册入口。
- `GET /v1/config/public/captcha` — 前端用于获取当前 Captcha 提供商及是否启用。
- `GET /v1/config/public/social-auth` — 登录入口所需的公开社交登录设置，不包含 Client Secret。

## 读取、修改与确认保存

1. 展开目标区块，等待读取完成并确认没有错误。多数区块首次成功读取后会缓存，折叠再展开不会刷新；需要重新读取时先记录草稿，再刷新页面。注册区块还需读取用户组，通知区块还需读取事件目录，任一请求失败都不能认为表单已加载。
2. 修改目标值并核对整个区块。保存提交该区块的整份设置，不只提交改动字段；只改一个字段也需要本次实际提交键的授权。加载失败时表单可能保留初始值或旧草稿，不能据此保存。
3. 点击该区块的保存并完成安全验证。其他区块的草稿不会一并保存，也没有全页统一保存。
4. 成功后重新读取，检查生效值，再验证对应业务。普通区块不会在成功后自动重新读取；刷新页面会丢弃其他未保存草稿。超时不代表一定未写入，应先核对结果再重试。

旧表单不保证检测到从打开页面以来的所有变更，可能覆盖另一位管理员已提交的值。协作修改时先重新读取并协调提交范围；请求处理到提交期间发生的配置或授权变化仍可能使整次保存被拒绝。失败后不要反复提交旧草稿。

### 保留、更换或清除密钥

启用 IAM 强制授权时，已有 SMTP 密码、社交登录密钥及带认证信息的地址会显示 `[configured]`。保留标记表示保留原值；输入完整新值表示替换；明确提交空字符串表示清除。标记不能复制为其他服务可用的密钥。保存后应重新读取确认状态，不能用浏览器里仍显示的输入值判断服务端是否保存。

### 注册、计费与邮件

- 注册配置控制是否开放注册、每邮箱账号上限、默认用户组和验证码时效。下拉框只包含当前可读取的用户组，未显示目标组时先核对组权限和可见范围。关闭注册不等于注销现有用户。
- 计费区块会一起保存充值比率、两种转出开关及手续费规则。比例最多 4 位小数，充值比率必须大于 0，百分比为 0–100；修改不应被当作重新计算既有订单或自动退款。交易按对应业务规则确认金额。
- SMTP 主机填写主机名或 IPv4 地址，不填写带协议的 URL；核对端口、TLS、认证账号、密码、发件人名称和有效发件邮箱。保存不发送测试邮件，也不能证明连通；请通过实际通知或验证码流程检查投递。站点后端公网地址用于邮件中的阅读跟踪图片链接，不会修改服务器监听地址或 DNS。

### 验证码与社交登录

- Captcha 主、备用提供商支持 `none`、`recaptcha`、`turnstile`。主提供商为 `none` 时备用也须为 `none`，主备不能相同。最低分值范围为 0–1，适用于 reCAPTCHA；可信窗口为 0–1440 分钟，0 表示不复用通过验证的窗口。它不替代登录或 2FA；程序化请求不使用浏览器的信任 Cookie。
- 选择提供商不会自动配置其服务端密钥与前端站点 Key；需先由部署管理员配齐相关配置，再测试登录等实际入口。
- 社交登录保存会先读取当前配置，保留页面未提供编辑的供应商端点、scope 和回调路径，再提交页面字段。读取失败会中止保存；仍需核对供应商登记的回调与当前部署匹配。
- 表单允许输入的时效范围可能宽于服务器接受范围：授权 state 为 60–3600 秒，扫码会话为 60–1800 秒，轮询为 1–30 秒。启用 GitHub 或微信前须填齐对应凭据；保存成功不等于供应商授权已联通。

### 通知、在线状态与解绑

- 通知默认事件和阈值用于初始化用户通知偏好，不会批量覆盖已有偏好。全选和清空只改草稿，保存后才生效。保存还会带上已读取、但此处未提供编辑的工单分配规则，因此也可能需要工单分配权限；处理规则请到 [工单审核]({{DOCS_BASE_URL}}/zh-CN/ticket-management)。
- 心跳间隔为 5–3600 秒，超时为 10–86400 秒；读取时实际超时至少为间隔加 5 秒。保存后重新读取核对，不要只依据尚未刷新的输入框判断。这里调整在线判定，不会直接强制下线用户。
- 远程终端个人解绑次数为 0 时表示关闭个人解绑，**不是不限次数**。次数按同一权益下的解绑记录共享统计；统计窗口为 1–8760 小时，重新绑定冷却为 0–525600 分钟。调整规则不等于清空历史次数，也不会卸载 Agent。

### IP 封禁与错误计分

三级阈值与时长、错误衰减、错误权重分别保存。第三级时长可选永久封禁（`-1`）；调整规则不等于手动解除已有封禁，请在 [IP 监控面板]({{DOCS_BASE_URL}}/zh-CN/ip-monitoring-dashboard)核对。错误权重保存会替换两张表的全部映射；避免空错误码或重复错误码，同码重复行只保留最后一行的权重。删除行不会在点击时立即修改服务器。

错误衰减与权重通过通用配置列表读取，只会取得当前已授权的键；缺失键可能显示默认草稿。因此只看到表单不代表已读取完整配置，应确认相应键的读取范围后再保存。

## 资源级配置权限

部署管理员组的 `SYSTEM_CONFIG` 权限是管理全局配置的前提。在启用 IAM 强制授权的部署中，还需要 `quyan:system:ListConfigurations`（读取）或 `quyan:system:UpdateConfigurations`（保存），资源格式为 `acs:platform:*:platform:config-item/<配置键>`。普通账户所有者及账户内策略不能自行取得部署级管理资格。

注册、SMTP、站点、计费、通知、心跳、远程终端解绑、中继、上游代理、自动代理池、IP 封禁、验证码和社交登录的专用读取接口会检查该配置集合的全部键；任一键被拒绝时，整个读取失败。通用列表只展示已授权键。一次保存中任一键未获授权、请求处理期间配置发生变化或身份在提交前失效，整次保存失败，不会留下部分修改。公开接口仅返回各入口所需的公开设置，不返回登录与验证码密钥。

IAM 强制授权下，SMTP 密码、中继 API Key、社交登录 Client Secret / App Secret，以及含用户名或密码的上游或代理 URL 显示为 `[configured]`。保留该占位符会保留对应原值；输入新值会替换配置，提交空字符串会清除对应值。占位符不会作为配置值写入。自动代理池保存同样需要二次验证和重放保护，样本数范围为 1–1000，统计窗口范围为 1–8760 小时。

强制模式下，通用配置接口读取或更新 `notification.ticketAssignmentRules` 时，还需要有效全局组的 `TICKET_REVIEW_UPDATE` 资格，以及对应的 `quyan:ticket:GetAssignmentRules` 或 `quyan:ticket:UpdateAssignmentRules` 授权。专用操作的 Deny 同样限制通用配置入口。缺少这些权限时，通用列表隐藏该键，包含该键的通知区块读取或批量保存会被拒绝。

## 说明

- 此处的小改动可能影响注册、计费、邮件发送、Captcha 验证和防滥用策略。
- SMTP 配置错误往往在通知或找回密码流程中暴露；修改后建议发送测试邮件确认。
- 中继上游代理默认关闭。先在此处启用并填写代理地址，再在中转渠道编辑器中开启“使用代理”；未开启渠道仍直连。
- 代理地址可包含认证信息，应按敏感配置管理；系统其他出站请求不会因为此设置自动改走代理。
- IP 封禁和衰减调整应结合 IP 监控数据进行。
- 验证码信任窗口（`trustWindowMinutes`）表示通过 Captcha 后多长时间内无需再次验证。

## AI 资源保护（高级配置）

面板按准入与内存、流解析与转换、聊天与客服、审计、连接池、图片与探针、编译规则缓存分组，显示服务端建议值、单位和合法范围。保存整份配置沿用系统配置权限、二次验证和重放保护，不需要重启。

“恢复默认值”仅将整份草稿改为服务端建议值，仍需保存才生效；“重新加载”会以当前生效值替换草稿。保存会提交 AI 资源保护的所有分组，成功后自动重新读取；若后续读取失败，应核对实际状态，不要重复盲目保存。

运行中的请求继续使用其内容预算；降低并发不终止请求。其他进程正常每 5 秒尝试同步，读取失败时保留旧值，不能保证 5 秒内全部生效。上下文条数 0 为不限条数，正文容量和数据库上限仍执行。检测到旧环境变量时，首次保存后管理配置优先。

超大的请求正文会在调用上游前返回 413，不计费，也不会为容量错误切换渠道重试。非流式文本和图片响应先完成大小检查，再返回成功；图片开始返回的时间因此可能晚于上游首字节。

普通同协议流不会仅因累计转发字节超过文本保留容量而中断；单帧解析、协议转换、内容审核和聊天存储仍受各自容量约束。响应开始前发现超限时返回 413。SSE 已开始后，HTTP 状态无法改写，客户端必须检查 `error` / `response.failed` 事件：运行中触发本站容量保护时发送明确错误，不发送成功完成标记，也不向用户扣费；已产生的聊天消息保留为失败状态。上游故障或客户端主动停止的部分输出仍沿用原有结算规则。
