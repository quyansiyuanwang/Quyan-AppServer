# 调试页

调试页提供构建信息和排障工具，主要供有调试权限的人员使用。查看后端构建信息需要 `DEBUG_ACCESS`。操作前请确认当前环境和账号。

## 查看信息与认证状态

- 构建信息显示前后端的版本、分支、提交和构建时间，便于核对部署版本。
- 认证测试会重新获取当前用户信息；加载权限会刷新当前用户的权限，显示权限会打开当前已加载的权限列表。清理权限只清除浏览器中的权限状态，不会修改服务端授权。
- **清理受信任窗口**仅在开发模式显示，会清除当前二次验证受信任窗口和相关设备 Cookie；后续敏感操作可能需要重新验证。
- OpenAPI 按钮使用页面中的后端地址和文档路径打开接口文档或 JSON 描述。

## 测试转发请求

填写兼容的 Base URL、API Key、模型和消息后，测试按钮会从浏览器向 `Base URL + /chat/completions` 发送真实请求，并展示响应或错误。请求会把 Key 作为 Bearer 凭据发给填写的目标，可能消耗额度或产生费用；请确认目标可信，并避免发送敏感内容。浏览器的跨域限制也可能导致请求失败。

## April 预览

预览按钮会在本地启用预览并打开首页；模拟按钮触发预览序列；关闭按钮关闭本地预览开关。这些按钮可用于非四月期间的界面检查。
