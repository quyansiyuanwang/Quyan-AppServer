# 系统统计

此页面用于监控运行健康度、资源占用和服务摘要信息。

## 管理权限

系统统计是部署级报告。启用 IAM 强制授权时，需要实际部署管理员组中的 `SYSTEM_STATS_READ`，并允许 `quyan:system:GetStatistics` 操作 `acs:platform:*:platform:system/stats`。构建信息单独要求 `DEBUG_ACCESS` 与 `quyan:system:GetBuildInfo`，资源为 `acs:platform:*:platform:system/build-info`。普通账户所有者和账户内策略不能自行取得部署级管理资格。

服务端在加载数据前和返回数据前检查授权。显式 Deny、管理员组权限被移除、账户被禁用或角色会话被撤销都会拒绝返回报告。

## 页面用途

- 查看当前服务状态。
- 观察运行时长和时间指标。
- 检查内存、CPU 与基础设施摘要。
- 手动刷新或自动刷新指标。

## 你会看到什么

### 核心指标

- 服务时间与运行时长。
- 应用级计数。
- 服务进程的内存使用情况。
- 服务进程在用户态和内核态消耗的累计 CPU 时间。

### 环境摘要

- 运行时信息。
- Redis 或基础设施状态。
- 配置摘要。

### 控制项

- 全部刷新按钮。
- 自动刷新时间间隔输入。
- 自动刷新状态提示。

## 常见操作

1. 使用“全部刷新”获取当前数据。
2. 需要持续观察时，输入自动刷新间隔（单位为秒，范围为 0–3600）；默认值为 0，表示关闭。离开页面后自动刷新停止。
3. 排查资源问题时，记录不同时间的内存和 CPU 数据，并查看基础设施摘要。

## 说明

- CPU 数值是进程启动以来消耗的累计时间，不是 CPU 利用率；数值持续增长本身不代表负载异常。内存指标也是服务进程的使用情况，运行时信息中另有操作系统内存数据。多进程部署时，不同请求可能由不同进程处理，比较数据时请留意进程 ID。
- 自动刷新失败时页面可能保留上一次的数据，自动刷新状态并不代表数据已成功更新。如需确认，请手动刷新并留意错误提示。
- 移动端展示的信息少于桌面端。
- 运行时长正常并不代表所有子系统都完全健康。
- 深度排查时建议结合日志页和消耗统计页一起看。
