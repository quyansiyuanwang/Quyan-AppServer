# 通行密钥管理

通行密钥（Passkey）允许您无需输入密码即可登录，使用设备的生物识别传感器（指纹、面部扫描）或 PIN 完成验证。账户安全页用于查看和删除已有通行密钥；新增通行密钥会安全跳转到认证站完成浏览器验证，再返回账户安全页。

## 页面用途

- 从认证站为当前设备或浏览器注册新的通行密钥。
- 查看当前身份获准访问的账户通行密钥。
- 移除不再使用或不认识的通行密钥。

## 你会看到什么

### 通行密钥列表

以表格（移动端为卡片列表）形式展示已注册的通行密钥，包含：

- **名称** — 注册时自定义的标签（未填写时显示为"未命名"）。
- **设备类型** — 由浏览器/平台上报（例如平台内置认证器、外部安全密钥）。
- **是否已备份** — 认证器报告的备份状态。能否在其他设备使用取决于凭证管理器的备份和同步设置。
- **创建时间** — 通行密钥的注册时间。

### 操作

- **注册** — 从账户安全页进入认证站注册；认证站会在设备或浏览器不支持通行密钥时显示提示。
- **删除** — 确认后移除该通行密钥。

## 常见操作

1. 在账户安全页的列表中点击**注册**，系统会打开认证站。
2. 可输入名称，然后确认并按浏览器提示完成设备验证。
3. 返回账户安全页后，定期检查列表，删除已不再持有对应设备的通行密钥。
4. 如浏览器提示"不支持"，可改用密码 + 2FA 方式登录，或更换支持 WebAuthn 的浏览器。

## 说明

- 查看、注册和删除通行密钥需要登录，并受账户权限策略约束；注册和删除还需要 `passkey:manage` 权限。操作被拒绝时，请联系账户管理员检查授权。
- 若账户已启用 2FA，使用通行密钥登录时仍可能要求完成二次验证，取决于账户的通行密钥验证策略及当前设备是否处于[受信任设备]({{DOCS_BASE_URL}}/zh-CN/trusted-device-management)窗口期内。启用 2FA 后，部分高危操作仍要求重新验证。
- 删除最后一个通行密钥不会自动禁用 2FA（若仍配置了 TOTP 或恢复代码）——通行密钥只是多种验证方式之一，并非 2FA 的替代品。
- 如注册过程被取消或失败，请刷新列表并检查结果。启用 IAM 强制授权时，列表只显示获准查看的凭据；没有看到新记录也可能是读取权限不足。确认权限后再决定是否重新注册。
