# 通行密钥管理

通行密钥（Passkey）允许您无需输入密码即可登录，使用设备的生物识别传感器（指纹、面部扫描）或 PIN 完成验证。账户安全页用于查看和删除已有通行密钥；新增通行密钥会安全跳转到认证站完成浏览器验证，再返回账户安全页。

## 使用前提

- 已登录账户，并具备相应的查看、注册或删除权限。
- 注册时需要支持通行密钥的浏览器、设备或凭证管理器，按浏览器提示完成验证。
- 在**设置 → 账户安全**打开通行密钥管理。列表只展示当前身份获准查看的凭据。

## 检查已有通行密钥

以表格（移动端为卡片列表）形式展示已注册的通行密钥，包含：

- **名称** — 注册时自定义的标签（未填写时显示为"未命名"）。
- **设备类型** — 认证器报告的凭据类型，不代表具体设备型号。
- **是否已备份** — 认证器报告的备份状态。能否在其他设备使用取决于凭证管理器的备份和同步设置。
- **创建时间** — 通行密钥的注册时间。

## 注册通行密钥

1. 在账户安全页的列表中点击**注册**，系统会打开认证站。
2. 在认证站再次点击**注册**，可输入一个便于识别的名称，然后确认并按浏览器提示完成设备验证。
3. 注册成功后返回账户安全页，重新打开列表检查结果。需要时点击**刷新**。

## 删除通行密钥

1. 在列表中核对名称、创建时间和备份状态，确认要删除的凭据，并确认仍有其他可用的登录方式。
2. 点击该项的**删除**并确认，等待成功提示和列表刷新。

删除后，该凭据无法再用于登录。删除只移除平台上的记录，不会自动删除设备或密码管理器中保存的凭据。需要移除本地或同步副本时，请在对应设备或密码管理器中另行删除。

## 说明

- 查看、注册和删除的授权分别检查。传统权限模式使用 `passkey:manage`；启用 IAM 强制授权时，以对应操作和凭据的策略为准。能打开列表不代表能注册或删除。操作被拒绝时，请联系账户管理员检查授权。
- 若账户已启用 2FA，使用通行密钥登录时仍可能要求完成二次验证，取决于账户的通行密钥验证策略及当前设备是否处于[受信任设备]({{DOCS_BASE_URL}}/zh-CN/trusted-device-management)窗口期内。启用 2FA 后，部分高危操作仍要求重新验证。
- 删除最后一个通行密钥不会自动禁用 2FA（若仍配置了 TOTP 或恢复代码）——通行密钥只是多种验证方式之一，并非 2FA 的替代品。

## 常见问题

| 现象                         | 处理方式                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 认证站提示浏览器不支持       | 更换支持通行密钥的浏览器或设备；也可使用账户已有的其他登录方式。                                                    |
| 取消注册或提示挑战已过期     | 先刷新列表检查结果；确认未注册成功后，重新点击注册开始新的流程。                                                    |
| 提示注册成功但列表中没有记录 | 先刷新列表，再检查读取权限。启用 IAM 强制授权时，新凭据也可能不在当前身份的可读范围内，不要仅因列表为空就反复注册。 |
| 已删除但密码管理器仍显示凭据 | 平台和密码管理器中的记录需分别删除；平台记录删除后，即使仍显示本地凭据，也不能再用它登录。                          |
