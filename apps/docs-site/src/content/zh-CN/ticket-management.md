# 工单管理

此页面供管理员查看、处理和回复用户提交的工单，例如建议和 Bug 报告。

## 页面用途

- 浏览所有用户工单。
- 按类型、状态、优先级、负责人和时间范围筛选。
- 更新工单状态和优先级。
- 添加内部审核评论。
- 删除不合适的工单条目。
- 维护新工单的自动分配规则。

## 你会看到什么

### 工单列表

- 工单标题、类型（建议 / Bug / 其他）和提交用户。
- 工作流状态：`pending`（待处理）、`processing`（处理中）、`accepted`（已采纳）、`rejected`（已拒绝）、`completed`（已完成）。
- 优先级：`low` / `medium` / `high` / `urgent`。
- 负责人和提交时间。
- 时间范围筛选（`startTime` / `endTime`）。

### 工单详情

- 用户提交的原始内容。
- 用户跟进评论。
- 审核人员公开回复与内部备注。

### 分配规则抽屉

- 按工单类型、优先级设置匹配条件。
- 配置自动轮转分配的处理人池。
- 保存前展示未完成规则的校验摘要。

## 常见操作

1. 按状态 `pending` 筛选，找出尚未处理的新工单。
2. 打开详情，阅读工单内容后更新优先级和状态。
3. 记录审核备注，或补充公开回复。
4. 将工单分配给负责人，或调整自动分配规则。
5. 处理完毕后将状态更新为 `completed`。

## 权限要求

| 操作                     | 所需权限               |
| ------------------------ | ---------------------- |
| 查看工单列表 / 详情      | `TICKET_REVIEW_READ`   |
| 更新状态 / 优先级 / 评论 | `TICKET_REVIEW_UPDATE` |
| 删除工单                 | `TICKET_REVIEW_UPDATE` |
| 管理分配规则             | `TICKET_REVIEW_UPDATE` |

## 说明

- 用户只能看到自己的工单及公开状态更新，无法查看内部审核备注。
- 删除操作不可恢复，请谨慎使用。
