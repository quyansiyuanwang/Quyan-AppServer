# 404 未找到

当访问的页面路径不存在，或当前域名未被站点识别时，可能看到此页面。

## 如何处理

1. 检查地址中的域名和路径是否正确；使用旧书签时，可从菜单或文档重新打开页面。
2. 点击 **返回上页** 回到浏览历史中的页面。如果没有上一页，系统会转到公共站点首页。
3. 也可以点击 **返回首页**，直接打开公共站点首页。
4. 如果从有效菜单进入仍反复出现此页面，或页面提示域名未被识别，请联系管理员检查站点配置和链接。
