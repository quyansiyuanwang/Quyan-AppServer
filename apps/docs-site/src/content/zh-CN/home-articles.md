# 首页 / 文章

文章阅读页用于浏览站内已发布的内容。未登录时显示可公开访问的文章；登录后可见范围取决于账号权限及文章的访问条件。

## 阅读文章

1. 打开文章阅读页。页面会尝试显示默认文章；如果没有可用的默认文章，则尝试打开列表中的第一篇。
2. 在文章列表中输入关键词，按标题、分类或摘要筛选已加载的列表。
3. 选择文章标题，阅读正文、作者、日期和浏览量；分类以标签显示。
4. 使用文章目录跳转到正文中的章节。

搜索只过滤列表，不会自动切换或隐藏当前正文。切换列表中的文章不会生成该文章的专属直链。

## 无法找到或打开文章

| 现象                       | 处理方法                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| 列表中没有目标文章         | 清空搜索条件，确认登录状态；仍不可见时，请管理员检查文章是否已发布及其访问条件。             |
| 首次打开时列表或正文为空   | 检查页面错误提示和网络，重新加载页面；仍无法查看时联系管理员。                               |
| 点击其他标题后正文没有变化 | 切换失败时会保留原正文。检查正文标题及错误提示，重新选择；必要时请管理员确认文章是否可访问。 |
