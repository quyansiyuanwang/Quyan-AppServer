# 首页 / 文章

文章阅读页用于浏览站内已发布的内容。未登录时显示可公开访问的文章；登录后可见范围取决于账号权限及文章的访问条件。

## 阅读文章

1. 打开文章阅读页。页面会尝试显示默认文章；如果没有可用的默认文章，则尝试打开列表中的第一篇。
2. 在文章列表中输入关键词，按标题、分类或摘要筛选已加载的列表。
3. 选择文章标题，阅读正文、作者、日期和浏览量；分类以标签显示。
4. 使用文章目录跳转到正文中的章节。

搜索只过滤列表，不会自动切换或隐藏当前正文。如果列表为空，请检查搜索条件、登录状态和文章访问权限。初次加载失败也可能显示空列表或空正文；请重新加载页面并检查网络，仍无法查看时联系管理员。切换文章失败时页面会继续显示原来的文章；请检查错误提示和正文标题，重新选择或联系管理员确认目标文章是否仍可访问。切换列表中的文章不会生成该文章的专属直链。
