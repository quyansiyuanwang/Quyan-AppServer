# 聊天

本节说明桌面端和移动端如何使用会话。

## 本节包含的页面

- `ChatView.vue`

## 会话列表

### 主要用途

- 切换会话并管理历史记录。

### 用户可以做什么

- 新建会话。
- 重命名或删除会话。
- 在列表或移动端抽屉中选择会话。

## 消息区域

### 主要用途

- 发送消息并查看回复。

### 用户可以做什么

- 选择模型或 Token 后发送消息。
- 编辑、重新发送、重新生成或删除消息。
- 在没有会话时从空状态开始。

### 选择模型与计费

- 先选择一个转发 Token，可选模型列表会根据该 Token 的"允许模型"配置自动筛选——不同 Token 可访问的模型范围可能不同。
- 切换 Token 后，若当前选中的模型不在新 Token 的允许列表内，系统会自动切换到该 Token 允许的第一个模型。
- 发送消息产生的用量会按所选 Token 的定价规则计费并计入该 Token 的额度，与在[转发 Token 管理](/docs/relay-token-management)页面看到的用量统计是同一份数据。
- 上次选择的 Token 和模型会保存在浏览器本地，下次打开聊天页面时自动恢复。

## 移动端说明

- 小屏幕下列表会收进抽屉。
- 顶部栏提供快捷新建与导航入口。
