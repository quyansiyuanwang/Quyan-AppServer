# 聊天

聊天页用于选择转发 Token 和模型、发送消息并管理会话。Agent 入口可配置机器和工作区；当前版本尚不能通过该入口完成远程任务。

## 开始前

登录后，需要相应的会话查看、创建、发送和消息管理权限；各项操作分别授权，能打开页面不代表可以执行所有操作。

请先在[转发 Token 管理]({{DOCS_BASE_URL}}/zh-CN/relay-token-management)中准备自己的 Token，并确认它有可用模型。模型列表由服务端根据 Token、渠道和模型配置计算；如果没有可选模型，请检查 Token 的模型限制和渠道配置，必要时联系管理员。

## 开始聊天

1. 新建会话并输入名称，或从会话列表选择已有会话。
2. 选择转发 Token 和模型，输入消息后点击**发送**。按 Enter 也可发送，Shift+Enter 换行。
3. 等待回复逐步显示。需要提前结束时，点击**停止**。

## 会话列表

- 从列表中选择会话，也可以新建、重命名或删除会话。小屏幕下先打开顶部的列表按钮，在抽屉中选择会话；顶部的加号可新建会话。
- 如果列表底部显示“加载更多”，点击它查看更多会话；未加载的会话不会出现在当前列表中。
- 删除会话需确认，删除后无法再通过聊天列表访问该会话及其消息；请先保存需要保留的内容。

## 修改或删除消息

- 编辑或重新发送用户消息会保留其之前的消息，移除其后的消息并请求新的回复。编辑内容后按 Enter 提交；按 Esc 取消编辑。
- 重新生成助手回复会重新发送紧邻该回复之前的用户消息，移除该用户消息之后的记录并生成新回复；前一条消息必须是用户消息。
- 删除消息会同时移除所选消息及其后的所有消息。操作前请先保存需要保留的内容。
- 编辑、重新发送和重新生成会使用**当前选中的 Token 和模型**发起新的普通聊天请求，可能产生新的用量和费用。它们不会固定使用原回复的选择；即使已开启 Agent 模式，这些消息操作也不会创建远程 Agent 任务。

## 选择模型与计费

- 先选择一个转发 Token，再从该 Token 当前可用的模型中选择。不同 Token 可访问的模型范围可能不同。
- 切换 Token 后，若当前模型不在新 Token 的模型列表内，系统会选择列表中的第一个模型；列表为空时无法发送，请检查 Token 的模型配置。
- 普通聊天产生的用量会按所选 Token 的定价规则计费并计入该 Token 的额度，与在[转发 Token 管理]({{DOCS_BASE_URL}}/zh-CN/relay-token-management)页面看到的用量统计是同一份数据。
- 上次选择的 Token 和模型保存在浏览器本地；如果它们已不可用，页面会选择当前可用项。

## 停止输出或处理失败

普通聊天中，点击**停止**、切换到其他会话或离开聊天页，都会中断当前页面的请求。重新打开原会话可查看服务端已保存的消息；不会自动续接未完成的输出。

回复中断后，先重新打开会话核对已保存内容，再决定是否重新生成或发送。发送后输入框会清空；请求失败时不会自动恢复原输入。停止或上游故障仍可能按已产生的用量结算，可到[消费记录]({{DOCS_BASE_URL}}/zh-CN/consumption-records)核对费用。

## Agent 模式

**当前可用范围：可以注册远程机器和创建工作区，但聊天任务尚不能完成远程执行。** 当前版本提交 Agent 任务后会显示“Remote Agent runtime is not connected”。机器在线或工作区已就绪，也不代表聊天任务执行能力已可用；遇到此提示请关闭 Agent 模式使用普通聊天，并联系管理员确认功能可用情况，不要反复重建机器或提交任务。

如需提前配置机器和工作区：

1. 在消息输入区开启**Agent 模式**，通过设置按钮进入**AI Agent 机器**。
2. 选择**添加机器**并填写名称（最多 120 字符）。创建后立即保存注册令牌；关闭弹窗后无法再次从列表查看。自动复制失败时，可手动复制输入框内容。
3. 在你控制的远程机器上准备远程 Agent 程序，再按弹窗中的环境变量和命令连接。启动命令依赖远程 Agent 已安装，不会自动下载程序；将机器 ID 占位符换成唯一标识，连接地址以部署管理员提供的可用地址为准。令牌用于连接机器，请妥善保管。
4. 在机器页选择**创建工作区**，输入名称（最多 120 字符）并选择绑定机器。核对机器连接状态、最近心跳和工作区状态；创建成功不代表工作区已经就绪，`provisioning` 表示仍在准备或等待连接，`failed` 表示准备失败。

查看和创建机器、工作区，以及移除机器，都需要相应权限；运行任务与读取任务输出还需要独立授权。删除机器需确认，会撤销该机器的后续连接；页面没有恢复入口，删除前确认不再需要该连接。此操作不会替你卸载远程机器上的程序。

回到聊天页后，工作区列表在进入页面时加载；新增工作区未显示时重新进入聊天页。输入区的**创建工作区**快捷操作仅在没有工作区时出现：恰好有一台可见机器时可直接创建，否则转到机器页选择配置。

发送前请确认已选中工作区。未选工作区时，发送按钮仍可能可点击，输入框会被清空，但不会创建任务。当前失败任务在页面显示的消息草稿不会作为普通聊天消息保存；需要保留时请先复制，不要依赖重新打开会话恢复。

Agent 模式下点击**停止**只停止当前页面接收输出，不会发起任务取消请求。切换会话或离开页面也会停止接收当前输出，不能据此判断任务已取消。当前聊天界面也没有任务审批入口。

## 长对话与容量限制

聊天会检查单条输入、上下文消息数、正文总大小及回答容量。具体上限由服务器配置及存储容量决定。

- 输入或上下文超限时，系统会拒绝请求，不会自动丢弃旧消息。请缩短输入或新建会话后重试。
- 普通聊天的回答因容量上限被中断时，可能保留部分消息，但不会显示成功完成；该次请求不收取聊天用量费用。请与主动停止或上游故障的结算情况区分。
- 资源繁忙时，请稍后重试。
