# 聊天

聊天页用于选择转发 Token 和模型、发送消息并管理会话，也支持通过远程机器运行 Agent 任务。

## 开始前

请先在[转发 Token 管理]({{DOCS_BASE_URL}}/zh-CN/relay-token-management)中准备自己的 Token，并确认它有可用模型。模型列表由服务端根据 Token、渠道和模型配置计算；如果没有可选模型，请检查 Token 的模型限制和渠道配置，必要时联系管理员。

## 开始聊天

1. 新建会话并输入名称，或从会话列表选择已有会话。
2. 选择转发 Token 和模型，输入消息后点击**发送**。按 Enter 也可发送，Shift+Enter 换行。
3. 等待回复逐步显示。需要提前结束时，点击**停止**。

## 会话列表

- 从列表中选择会话，也可以新建、重命名或删除会话。小屏幕下先打开顶部的列表按钮，在抽屉中选择会话；顶部的加号可新建会话。
- 如果列表底部显示“加载更多”，点击它查看更多会话；未加载的会话不会出现在当前列表中。
- 删除会话需确认，删除后无法再通过聊天列表访问该会话及其消息；请先保存需要保留的内容。

## 修改或删除消息

- 编辑或重新发送用户消息会使用该消息作为新的对话起点，移除其后的消息并请求新的回复。编辑内容后按 Enter 提交；按 Esc 取消编辑。
- 重新生成助手回复会重新发送该回复前的用户消息，移除该用户消息之后的记录并生成新回复；需要该回复前存在用户消息。
- 删除消息会同时移除所选消息及其后的所有消息。操作前请先保存需要保留的内容。
- 编辑、重新发送和重新生成会使用**当前选中的 Token 和模型**发起新的普通聊天请求，可能产生新的用量和费用。它们不会固定使用原回复的选择；即使已开启 Agent 模式，这些消息操作也不会创建远程 Agent 任务。

## 选择模型与计费

- 先选择一个转发 Token，再从该 Token 当前可用的模型中选择。不同 Token 可访问的模型范围可能不同。
- 切换 Token 后，若当前模型不在新 Token 的模型列表内，系统会选择列表中的第一个模型；列表为空时无法发送，请检查 Token 的模型配置。
- 发送消息产生的用量会按所选 Token 的定价规则计费并计入该 Token 的额度，与在[转发 Token 管理]({{DOCS_BASE_URL}}/zh-CN/relay-token-management)页面看到的用量统计是同一份数据。
- 上次选择的 Token 和模型保存在浏览器本地；如果它们已不可用，页面会选择当前可用项。

## 停止输出或处理失败

普通聊天中，点击**停止**、切换到其他会话或离开聊天页，都会中断当前页面的请求。重新打开原会话可查看服务端已保存的消息；不会自动续接未完成的输出。

回复中断后，先重新打开会话核对已保存内容，再决定是否重新生成或发送。发送后输入框会清空；请求失败时不会自动恢复原输入。停止或上游故障仍可能按已产生的用量结算，可到[消费记录]({{DOCS_BASE_URL}}/zh-CN/consumption-records)核对费用。

## Agent 模式

Agent 模式使用远程机器和工作区处理会话任务。使用前需要有可用的转发 Token、模型和工作区；相关操作的可用性取决于账户权限与部署配置。

1. 在消息输入区开启“Agent 模式”，通过设置按钮进入“AI Agent 机器”。
2. 添加机器并按页面提供的环境变量和启动命令连接远程 Agent。注册令牌仅在创建后显示，请立即妥善保存，不要分享给其他人。
3. 在机器页面创建工作区并选择绑定的机器。回到聊天页，选择工作区、转发 Token 和模型后发送消息。
4. 如果任务失败，查看聊天中的错误信息，并在机器页面检查机器连接状态和最近心跳。

发送前请确认已选中工作区。未选工作区时，发送按钮仍可能可点击，输入框会被清空，但不会创建任务；请先创建或选择工作区，再重新输入消息。

Agent 模式下点击“停止”会停止当前页面接收输出，但不保证远程任务已取消。切换会话或离开页面也会停止接收当前输出；请勿据此判断远程任务已经结束。

## 长对话与容量限制

聊天会检查单条输入、上下文消息数、正文总大小及回答容量。具体上限由服务器配置及存储容量决定。

- 输入或上下文超限时，系统会拒绝请求，不会自动丢弃旧消息。请缩短输入或新建会话后重试。
- 普通聊天的回答因容量上限被中断时，可能保留部分消息，但不会显示成功完成；该次请求不收取聊天用量费用。请与主动停止或上游故障的结算情况区分。
- 资源繁忙时，请稍后重试。
