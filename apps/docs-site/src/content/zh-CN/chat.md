# 聊天

本节说明桌面端和移动端如何使用会话。

## 开始聊天

1. 新建会话并输入名称，或从会话列表选择已有会话。
2. 选择可用的转发 Token 和模型，输入消息后发送。
3. 回复生成时可点击停止；会话列表支持重命名和删除。

## 会话列表

### 主要用途

- 切换会话并管理历史记录。

### 用户可以做什么

- 新建会话。
- 重命名或删除会话。
- 在列表或移动端抽屉中选择会话。

## 消息区域

### 主要用途

- 发送消息并查看回复。

### 用户可以做什么

- 选择模型或 Token 后发送消息。
- 编辑、重新发送、重新生成或删除消息。
- 在没有会话时从空状态开始。

### 选择模型与计费

- 先选择一个转发 Token，可选模型列表会根据该 Token 的"允许模型"配置自动筛选——不同 Token 可访问的模型范围可能不同。
- 切换 Token 后，若当前模型不在新 Token 的模型列表内，系统会选择列表中的第一个模型；列表为空时无法发送，请检查 Token 的模型配置。
- 发送消息产生的用量会按所选 Token 的定价规则计费并计入该 Token 的额度，与在[转发 Token 管理]({{DOCS_BASE_URL}}/zh-CN/relay-token-management)页面看到的用量统计是同一份数据。
- 上次选择的 Token 和模型保存在浏览器本地；如果它们已不可用，页面会选择当前可用项。

## 移动端说明

- 小屏幕下列表会收进抽屉。
- 顶部栏提供快捷新建与导航入口。

## 长对话与容量限制

聊天会检查单条输入、上下文消息数、正文总大小及回答容量。超限会明确报错，不会自动丢弃旧上下文。输入超限时不开始流式回答；回答超限会停止输出，不发送成功完成标记。部分回答仍可能保存为失败或已停止状态并结算已产生的用量。具体上限由服务器配置及存储容量决定。资源繁忙时请稍后重试。
