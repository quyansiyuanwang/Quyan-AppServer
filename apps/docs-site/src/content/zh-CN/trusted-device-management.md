# 受信任设备管理

受信任设备是指在成功完成两步验证后，系统在一段时间窗口内记住的浏览器/设备，期间该设备上的常规操作可跳过重复验证。在**设置 → 账户安全**的两步验证区域，打开受信任设备管理，即可查看或删除这些记录。

## 使用前提

- 已登录账户；账户安全页在启用 2FA 后显示此管理入口。
- 查看和删除受信任设备分别受账户授权策略约束，能查看不代表能删除。操作被拒绝时请联系管理员检查授权。

## 检查设备记录

以卡片形式展示每个受信任设备，包含：

- **设备标识** — 优先显示 IP 地址，其次显示浏览器 User-Agent，二者都不可用时显示缩略的设备 ID。
- **IP 地址** — 该设备被标记为受信任时使用的来源 IP。
- **浏览器 / User-Agent** — 用于辅助识别设备。
- **信任建立时间** — 设备被标记为受信任的时间。
- **最后使用时间** — 最近命中该设备信任校验的时间；高危操作即使命中信任记录，也可能继续要求 2FA，不代表该次操作已成功。
- **剩余有效期** — 加载列表时距离信任状态过期的时间（以天/时/分/秒展示，最多显示两级单位）；点击刷新获取最新值。

点击顶部**刷新**会返回第一页并重新获取数据，需要检查其他设备时请再次翻页。列表每次最多读取 200 条记录，分页只覆盖本次读取结果；设备较多时，翻完所有页也不一定包含全部设备。

## 删除不再信任的设备

1. 核对设备标识、IP、浏览器信息和时间，定位不再使用或不认识的设备。
2. 点击该项的**删除**，在确认窗口中再次核对后确认。
3. 等待列表重新加载，检查该项是否已移除。若删除的是当前浏览器，其信任 Cookie 也会清除。

删除只撤销跳过重复验证的资格，不会退出该设备上的现有登录会话。若怀疑账户被盗用，请检查各分页并逐个删除可疑记录，立即修改密码，并联系管理员进一步排查。删除后可刷新并继续检查；重新验证后是否建立新的信任记录取决于验证流程。

## 常见问题

| 现象                     | 处理方式                                                                                           |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| 列表为空                 | 信任记录可能已过期，设备存储不可用时也可能返回空列表。空列表不能作为账户没有受信任设备的保证。     |
| 加载失败但仍显示设备     | 页面可能保留上次成功加载的结果。使用错误提示旁的刷新按钮重试当前页，或顶部刷新按钮返回第一页重试。 |
| 提示删除成功但列表未更新 | 列表刷新可能失败。点击顶部刷新，检查结果后再决定是否重试删除。                                     |
| 删除后设备仍处于登录状态 | 这是预期行为；设备在下一次需要验证时不能再依靠原信任记录跳过。撤销信任不等同于退出登录。           |
| 最后使用时间不符合预期   | 结合设备、浏览器和 IP 检查。无法确认是本人活动时，删除该记录并检查账户安全设置。                   |

## 说明

- 受信任设备的信任窗口期由服务端配置决定（默认 24 小时），并非用户可自行调整的选项。
- 启用 2FA 后，删除访问密钥、删除 RAM 用户、解绑策略等高危操作不接受长期受信任状态，需要重新验证；禁用 2FA 也需要验证。
- 清除受信任设备不会影响已登录的会话本身，只是让该设备下一次触发验证时无法再跳过。
- 此功能依赖浏览器 Cookie 保存的设备令牌；清除浏览器 Cookie 或使用隐私模式访问会导致该设备无法被识别为"受信任"，即使之前已标记过。
