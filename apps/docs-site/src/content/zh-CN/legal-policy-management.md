# 法律政策管理

法律政策管理用于维护服务协议和隐私政策，供用户注册、登录时阅读并确认。这些政策在整个部署中共用，创建人和更新人用于记录操作者，不表示政策仅对其账户生效。

## 使用前提

进入管理站的法律政策管理页面。查看、新建、编辑、删除和发布分别需要以下权限；能够查看列表不代表可以读取正文或修改版本。

| 操作                   | 所需权限               |
| ---------------------- | ---------------------- |
| 查看版本列表、读取正文 | `LEGAL_POLICY_READ`    |
| 新建草稿               | `LEGAL_POLICY_CREATE`  |
| 修改草稿               | `LEGAL_POLICY_UPDATE`  |
| 删除草稿               | `LEGAL_POLICY_DELETE`  |
| 发布、取消发布         | `LEGAL_POLICY_PUBLISH` |

## 查看类型与版本状态

页面默认显示服务协议，可切换到隐私政策；移动端的 TOS、PP 分别对应这两种类型。类型切换只筛选已加载的列表，不会重新获取数据。列表显示标题、版本号、摘要、更新人、更新时间和发布状态，桌面端另有发布时间。

| 状态                   | 含义                   | 可执行的内容操作                                 |
| ---------------------- | ---------------------- | ------------------------------------------------ |
| 草稿                   | 尚未发布，或已取消发布 | 编辑、发布、删除                                 |
| 已发布，无当前标记     | 保留的历史发布版本     | 取消发布后才能编辑或删除                         |
| 已发布，有当前生效标记 | 当前向用户提供的文本   | 发布其他草稿来替换，或在有可用历史版本时取消发布 |

**同一类型最多只有一个当前生效版本，可以同时保留多个已发布历史版本。** 判断生效文本时，请查看当前标记，不要只看版本号或“已发布”状态。页面没有搜索、分页、导出或自动刷新。

## 新建与编辑草稿

1. 选择政策类型，单击新建。
2. 确认类型，填写标题、可选摘要和 Markdown 正文。新建表单为空，不会复制当前版本。
3. 预览内容。桌面端默认分栏显示编辑器和预览，可切换单栏；移动端使用编辑、预览标签页。
4. 提交保存。新建结果为草稿，尚未替换当前生效文本。

标题去除首尾空格后为 1～200 个字符，摘要最多 2000 个字符，正文不能为空。版本号由系统按类型递增分配，不能手工指定；删除草稿也不会让后续版本复用该编号。

同一类型已有未删除的草稿时，不能再新建草稿，应先处理现有草稿。编辑时不能更改类型。已发布版本即使显示编辑或删除按钮，提交仍会被拒绝；通常应新建一个版本来修订已生效内容。

编辑已有摘要时，直接清空摘要再保存会保留旧摘要。确需清除时，可由具备更新权限的集成通过更新接口显式提交空字符串，并重新读取结果确认。

提交失败时，表单会保留输入；关闭或取消会清空输入，页面没有自动保存、内容差异比较或恢复历史正文的功能。打开编辑框后若详情加载失败，空白表单不代表原正文为空，请关闭后重试，避免覆盖原内容。

## 发布并核对生效文本

1. 检查目标草稿的政策类型、版本、标题和完整正文。
2. 单击发布并确认。
3. 检查该版本显示为已发布且带有当前生效标记。
4. 分别核对服务协议和隐私政策，确认两类均有当前生效文本。

发布会立即替换同一类型的当前版本；原版本保留已发布状态，仅移除当前标记。发布另一类型不会替换本类型的文本。请在确认弹窗前完成内容审核，页面不提供独立审批流程。

注册及同时加载两类政策需要两类均已发布；缺少任何一类可能导致注册或协议加载失败。不能据此认定所有已有用户的登录都会被阻止。

## 取消发布与删除

单击取消发布并确认后，目标版本变回草稿，发布时间被清空。

- 取消历史版本的发布，不会更换当前生效文本。
- 取消当前版本的发布时，系统会选择剩余已发布版本中版本号最高的一个作为当前版本，保留回退版本原有的发布时间。
- 没有可回退的已发布版本时，不能取消当前版本的发布。
- 回退由系统选择，确认前请核对历史版本内容。取消发布也可能使同一类型出现多个草稿；此时仍不能新建草稿。

删除需要确认，且只适用于草稿；页面没有删除后的恢复入口。已发布的历史版本如需删除，必须先取消发布。需要保留发布记录时，应保留历史版本。

## 用户何时需要重新同意

当两类当前政策可用时，登录完成前会检查用户是否已同意这两个具体版本。尚未同意任一当前版本时，用户需按登录页提示阅读协议、勾选同意并继续；协议在登录页弹窗中展示。关闭弹窗或不确认同意，不能完成本次登录。

发布不会统一退出已登录用户，也不是每次业务操作都会重新检查。系统按具体版本的同意记录判断，并非简单比较版本号大小；回退到用户曾同意的版本时，可能无需再次确认。

协议确认会话有效期为 10 分钟。提示过期或无效时，请重新登录；确认提交失败后若无法继续，也应重新开始登录。集成使用的确认接口为 `POST /v1/auth/accept-policy-consent`，需提交有效的 `challengeToken` 和 `agreedToLegalPolicies: true`，并遵循接口要求的重放保护。

## IAM 授权范围

IAM 强制模式下，管理操作除下表中的动作授权外，还需要真实部署全局组中的对应管理资格。版本资源统一为 `acs:platform:*:platform:legal-policy/<版本 ID>`。

| 操作     | IAM 动作                              | 授权范围                           |
| -------- | ------------------------------------- | ---------------------------------- |
| 列表     | `quyan:legal_policy:ListVersions`     | 列表中的实际版本                   |
| 正文详情 | `quyan:legal_policy:GetVersion`       | 目标版本                           |
| 新建     | `quyan:legal_policy:CreateVersion`    | 类型控制资源及新版本               |
| 编辑     | `quyan:legal_policy:UpdateVersion`    | 目标草稿                           |
| 删除     | `quyan:legal_policy:DeleteVersion`    | 目标草稿                           |
| 发布     | `quyan:legal_policy:PublishVersion`   | 目标版本和被替换的当前版本         |
| 取消发布 | `quyan:legal_policy:UnpublishVersion` | 目标版本，以及需要切换到的回退版本 |

新建的类型控制资源为 `acs:platform:*:platform:legal-policy-control/<协议类型>`，类型取 `terms_of_service` 或 `privacy_policy`。

列表只返回已授权版本的摘要，列表可见并不授予正文读取权限。详情不存在、已删除或未授权时，在强制模式下均可能返回 403。管理接口不接受 OAuth 访问令牌；使用角色会话时按角色自身授权，匹配的 Deny 优先。

发布或取消发布必须获准操作全部受影响版本。指定回退版本被拒绝时，操作整体失败，不会跳过它选择更旧版本。权限失效、版本状态或并发变化也可能使操作失败；请刷新核对后再试。管理写入要求重放保护，公开政策读取和用户同意流程另按各自接口规则执行。

## 常见问题

| 现象                             | 处理方法                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------ |
| 操作成功后又提示列表加载失败     | 操作可能已经完成，重新进入页面核对状态，避免直接重复提交                       |
| 列表加载失败后仍显示旧记录       | 旧列表可能保留，重新加载后再决定发布、取消发布或删除                           |
| 新建提示已有草稿                 | 检查当前类型下的草稿；权限过滤可能隐藏其他草稿，可联系具备相应读取权限的管理员 |
| 能看到版本但不能打开、编辑或发布 | 检查正文、变更动作及全部受影响版本的授权，不要仅依据列表可见性判断             |
| 取消发布当前版本失败             | 检查是否有已发布回退版本，以及是否获准对其执行取消发布动作                     |
