# 登录 / 注册

此页面用于登录已有账号，或创建一个新账号。

登录、注册、找回密码、外部登录回调、两步验证和通行密钥验证都在认证站完成。从产品站访问受保护页面时，系统会进入认证站；有效的返回流程会在登录完成后带您回到原页面，流程已失效时可能进入账户页面。系统不会将登录令牌放入地址栏。

## 使用用户名和密码登录

1. 选择 **登录**，输入用户名和密码。
2. 阅读并同意页面显示的政策，提交登录。
3. 如系统要求人机验证或二次验证，按照提示完成。

登录使用用户名，不是昵称或邮箱。忘记密码时，进入[找回密码]({{DOCS_BASE_URL}}/zh-CN/forgot-password)，不要重复注册账号。**重置**按钮只清空当前表单，不会修改账户密码。

## 使用通行密钥登录

1. 确认当前浏览器或凭证管理器可以使用已为该账户注册的通行密钥。
2. 阅读并同意页面显示的政策，选择通行密钥登录按钮，无需先填写用户名和密码。
3. 按浏览器提示选择凭据并完成设备验证；如仍要求 2FA，继续完成验证。

按钮根据浏览器能力显示，不代表当前设备一定保存了可用凭据。取消浏览器验证不会完成登录，可重新尝试或改用账户已有的其他方式。注册新凭据请参见[通行密钥管理]({{DOCS_BASE_URL}}/zh-CN/passkey-management)。

## 使用外部账号登录

如果登录页显示 GitHub 或微信入口，可选择相应提供方，在外部平台完成授权，再按提示完成政策同意或 2FA。

外部账号需要与本站账号建立绑定。提示尚未绑定时，请先用本站已有方式登录，在**设置 → 账户安全**完成绑定，之后再使用外部账号登录。外部平台授权成功不代表本站登录已经完成。

## 扫码登录

如果部署启用了扫码登录，可用已登录账号的另一台设备确认登录请求：

1. 在登录页选择**扫码登录**，使用另一台设备扫描显示的二维码。
2. 如果确认设备尚未登录，请先登录要使用的账号，返回确认页面。
3. 核对请求设备摘要、IP 和大致位置；确认是自己发起的请求后，选择**允许本次登录**。不认识的请求请选择**拒绝本次登录**。
4. 返回原登录页，按提示完成可能出现的政策同意或二次验证。二维码过期时，在原登录页点击**刷新**重新生成。

## 注册账号

1. 选择 **注册**。如果注册不可用，请联系管理员确认服务是否开放注册。
2. 填写用户名、昵称和邮箱，点击发送验证码，并输入邮件中的六位验证码。
3. 输入密码及确认密码，阅读并同意页面显示的政策，然后提交。
4. 通常注册成功后页面会切换回登录；如系统要求额外验证，请先按照提示完成。

| 字段           | 要求                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| 用户名         | 3–20 位字母、数字或下划线，不能与已有用户名重复。                                  |
| 昵称           | 网页要求填写 1–30 位中文、字母、数字或空格，首尾不能有空格。昵称不是登录用户名。   |
| 邮箱与验证码   | 使用能收信的邮箱及发送到该地址的六位验证码。更换邮箱输入值后需重新获取对应验证码。 |
| 密码与确认密码 | 密码为 6–50 个字符，两次输入必须一致。                                             |

发送验证码成功后有 60 秒倒计时，服务端还可能有独立的发送频率限制。每个邮箱可注册的账号数和是否开放注册，以当前服务端配置为准。

## 说明

- 注册需要可访问的邮箱和有效的邮箱验证码。验证码过期或未收到时可重新发送；如邮件仍未到达，请检查垃圾邮件或联系管理员。
- 切换登录与注册模式会重置表单，请先确认是否还需要当前输入内容。
- 认证完成后，其他产品站会通过各自的受保护会话恢复登录状态；不要把浏览器存储中的登录信息当作跨站登录方式。

## 常见问题

| 现象                         | 处理方式                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| 提示用户名或密码错误         | 确认输入的是用户名；忘记密码时使用找回密码流程。                                   |
| 提示账户已禁用或没有访问权限 | 联系管理员检查账户状态和目标页面权限，清理缓存不能恢复授权。                       |
| 提示邮箱注册数量已达上限     | 使用已有账号登录，或联系管理员了解当前限制。收到验证码并不保证该邮箱仍有注册名额。 |
| 注册失败后重试提示验证码无效 | 检查填写的邮箱，并重新获取验证码；之前提交的验证码可能已被使用。                   |
| 外部平台回调报错             | 返回登录页重新发起授权，不要反复刷新同一个回调地址；外部授权码只能使用一次。       |
| 登录成功后没有回到原页面     | 从产品站重新打开目标页面。返回流程可能已过期，目标页面也仍需相应访问权限。         |

## 无法登录：检查与修复

登录页的 **无法登录？检查与修复** 会打开独立修复页。主页面无法正常打开时，可使用加载页面底部的修复入口，或访问当前站点的 `/repair.html`。

1. 先选择 **检查浏览器环境**。它会检查存储读写、已知登录数据格式、数据库及后端连接，不上传本地内容。检查正常不代表能排除全部登录问题；页面不能读取 HttpOnly Cookie。
2. 优先选择 **重置登录状态**。确认后清理本机登录残留，保留主题、语言和业务缓存。验证码信任和受信任设备 Cookie 会重置，可能需要重新完成验证码或二次验证，但不会删除账号的 Passkey 或二次验证配置。
3. 仍无法登录时，可选择 **清除本站应用数据**。两次确认后，清除当前站点可识别的应用存储、偏好和数据库。请先保存未同步草稿；服务端账户和业务数据不受影响。
4. 阅读逐项结果，再选择 **返回登录**。如果部分失败，可以重试；后端不可达时本地部分仍会继续清理，不能据此认为登录 Cookie 已清除。

**清理边界与故障处理：**

- 清理只覆盖当前站点可识别的数据；其他子域的 LocalStorage 和 IndexedDB 需要分别访问对应站点处理。共享 Cookie 可能影响同一部署的其他站点。
- 数据库删除受阻时，关闭本站其他标签页后重试。浏览器不支持数据库枚举时，会明确提示覆盖不完整。
- 浏览器禁止存储或自动清理未成功时，可在浏览器设置中搜索“站点数据”，选择本站清除，再重新打开登录页。不要误选“清除所有网站数据”。
- 重置不会修复错误密码、账号权限、网络故障或服务端故障；这类问题应依据登录页提示继续处理。
