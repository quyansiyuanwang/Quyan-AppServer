# OAuth 应用审核

平台审核人员在此查找普通 OAuth 应用、审核待处理申请，或删除不再允许使用的应用。维护自己的应用请使用 [OAuth 应用管理](/zh-CN/oauth-app-management)。本页不管理系统 OAuth 应用。

## 使用前提

- 页面入口及列表读取需要 `oauth:client:review:read`；通过、拒绝和审核端删除需要 `oauth:client:review:update`。
- 使用 IAM 策略的部署中，读取要求用户属于实际的平台全局管理组，且组包含读取权限；审核及删除要求该组包含更新权限。账户内创建的组、附加权限或账户策略不能代替平台组资格。
- 在上述资格之外，列表、审核与删除还分别检查 `quyan:oauth:ListClientReviews`、`quyan:oauth:ReviewClient`、`quyan:oauth:DeleteReviewedClient`。资源为 `acs:platform:*:platform:oauth-review-client/<应用记录 ID>`；这里的记录 ID 不是公开 Client ID。显式拒绝和角色会话限制仍生效。
- 列表条目及总数限于当前有权查看的应用。能看到记录不代表能审核或删除；OAuth 访问令牌不能用于本页审核接口。

## 查找待审核应用

1. 选择 `pending` 状态，定位待处理申请；也可选择其他状态查看历史或草稿记录。
2. 输入应用名称、Client ID 或所有者用户名关键字，单击搜索或按 Enter。仅输入文字不会自动查询。
3. 核对名称、所有者、Client ID、回调地址摘要、提交时间和审核时间。

搜索、清空关键字及改变状态会回到第一页。默认每页 20 条，可选择 10、20、50 或 100 条；改变每页数量也会回到第一页。刷新保留当前页，列表不会自动轮询。结果按提交时间升序排列，再按创建时间降序排列。

列表最多显示前两个回调地址，其余只显示数量。审核弹窗只显示本次决策和意见输入框，不提供完整资料、Scope 或完整回调地址列表。审核前请向所有者核对这些资料，确认回调地址归属、环境及实际申请范围；不要把摘要当成完整申请。

## 通过或拒绝申请

1. 对 `pending` 应用单击通过或拒绝。
2. 在弹窗核对本次决策，填写审核意见。意见可选，最多 2,000 个字符；拒绝时建议写明具体修改项，例如需要移除哪个测试回调地址。
3. 提交后确认成功提示和刷新后的状态。所有者可在应用管理中查看审核意见。

| 状态       | 本页可执行的审核操作 | 对应用的影响                         |
| ---------- | -------------------- | ------------------------------------ |
| `draft`    | 不能通过或拒绝       | 尚未提交，不能授权或兑换令牌         |
| `pending`  | 通过或拒绝           | 通过前不能授权或兑换令牌             |
| `approved` | 不能再次直接审核     | 满足其他条件时可授权、兑换及刷新令牌 |
| `rejected` | 不能再次直接审核     | 所有者整改并重新提交后才可再审核     |

通过审核不替代用户同意、Scope 校验或资源授权。保存已通过或已拒绝的应用资料会使其回到草稿，并清除原审核意见和审核信息；即使所有者未实际改动字段也会如此。待审核应用保存后仍保持 `pending`，审核前应确认最新资料。

如提示应用状态已变化，刷新后重新核对，不要重复提交旧决策。审核成功后列表保持当前页；若筛选条件不再匹配，该记录会从结果中消失。

## 删除应用

删除会移除应用本身，不是删除一条审核历史。各审核状态都可能显示删除操作，执行前请核对应用名称和 Client ID，并与所有者确认影响。

1. 单击删除并阅读确认提示。
2. 确认后，应用从所有者列表和审核列表移除，不能再发起授权或兑换令牌。本页没有恢复入口。
3. 刷新后确认结果；若删除了当前最后一页的最后一条，请返回前一页查看。

**删除不等于撤销已签发的访问令牌。** 已有令牌仍可能有效至过期或撤销。需要终止现有令牌时，应先协调接入方处理令牌撤销，再删除应用；不要以列表中已无该应用作为访问令牌全部失效的证明。

## 常见问题

| 现象                         | 处理方法                                                |
| ---------------------------- | ------------------------------------------------------- |
| 有入口但列表无权读取         | 请平台管理员核对全局组资格、读取权限及资源策略          |
| 能看记录但不能审核或删除     | 核对更新权限及对应动作授权；列表读取权限不能代替它们    |
| 通过或拒绝按钮没有显示       | 仅 `pending` 可审核；其他状态需等待所有者提交或重新提交 |
| 查询失败后仍有列表内容       | 可能是上次结果，先排除错误并重新刷新再做决策            |
| 提交后报错，不确定是否成功   | 刷新并核对状态与审核时间，再决定是否需要重试            |
| 需要检查完整回调地址或 Scope | 联系所有者核对，审核弹窗没有完整资料查看功能            |
