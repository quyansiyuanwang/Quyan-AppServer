# 权限管理

访问控制按职责拆为概览、身份管理和权限管理。权限管理页面用于查看用户最终生效的权限，并调整用户级覆盖项。

## 页面用途

- 查看某个用户的权限来源。
- 区分群组权限、额外权限和移除权限。
- 对特定用户进行细粒度权限调整。

## 你会看到什么

### 用户列表

- 用户名和所属群组。
- 刷新入口。
- 分页列表。

### 授权

- 仅处理用户级额外授予和移除项。
- 需要 `PERMISSION_ADD` 或 `PERMISSION_REMOVE` 才能编辑。

### 权限策略

- 生效权限。
- 来自群组的权限。
- 单独增加的权限。
- 单独移除的权限。

### 权限诊断

- 使用与权限策略相同的真实数据，按权限来源连续展示。
- 用于判断最终权限是来自群组、用户级授予，还是被用户级移除。

### 编辑动作

- 打开用户权限编辑窗口。
- 分类查看权限。
- 按分类或关键字查找权限项。

## 常见操作

1. 先找到目标用户。
2. 在权限策略或权限诊断中确认权限是从哪里来的。
3. 如需特殊授权，再使用用户级增加权限。
4. 如需限制某项能力，再使用用户级移除权限。

## 所需权限

| 操作                 | 所需权限                                         |
| -------------------- | ------------------------------------------------ |
| 查看群组权限         | `PERMISSION_VIEW`                                |
| 为用户或群组添加权限 | `PERMISSION_ADD`                                 |
| 移除用户的权限       | `PERMISSION_REMOVE`                              |
| 清空用户的权限覆盖项 | 同时需要 `PERMISSION_REMOVE` 和 `PERMISSION_ADD` |

修改群组权限集合还需要重新完成一次 2FA 二次验证，与受信任设备状态无关。

## 说明

- 最终权限通常是群组权限与用户级覆盖项共同决定的。
- 排查"看得到但不能用"或"本不该看到却看到了"的问题时，此页非常关键。
- 建议与群组管理页配合使用，避免在用户级做过多长期例外。
