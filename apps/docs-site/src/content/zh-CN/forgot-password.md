# 找回密码

当你还能确认账号身份，但无法再使用旧密码登录时，请使用此页面。

## 页面用途

- 验证账号归属。
- 向绑定邮箱发送找回验证码。
- 安全设置新密码。

## 你会看到什么

### 账号信息区

- 用户名输入框。
- 邮箱输入框。
- 发送验证码按钮。

### 重置区

- 分段式验证码输入框。
- 新密码与确认密码字段。
- 重置与返回登录按钮。

## 常见操作

1. 输入用户名和正确的邮箱地址。
2. 请求发送验证码。
3. 检查邮箱并填写收到的六位验证码。
4. 输入 6–50 个字符的新密码，并再次输入相同密码确认。
5. 提交重置请求；成功后页面会自动跳转到登录页。

## 说明

- 验证码有效期以邮件和服务端配置为准。无效或过期时，请重新请求验证码；发送后页面有 60 秒倒计时，服务端也可能施加额外限制或要求人机验证。
- 提交后若重置失败，验证码可能已被使用。请根据页面提示重新获取验证码，再提交新密码；如发送按钮仍在倒计时，请等待倒计时结束。
- 如果未收到邮件，请检查垃圾邮件文件夹，并确认填写的是绑定邮箱；仍无法收到时联系管理员检查邮件服务。无法访问绑定邮箱时，请联系管理员处理。
- 用户名与邮箱必须属于同一个账号。
- 页面上的“重置”按钮用于清空表单，提交新密码需使用提交按钮。
- 重置成功后，请使用新密码重新登录。
