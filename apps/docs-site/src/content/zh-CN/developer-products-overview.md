# 开发者产品

开发者产品包括 KV 存储、短链接、密钥托管、状态监控、验证码、IP 定位、推送聚合和 JSON 端点。先选择产品、创建实例，再按对应指南管理资源或调用 API。

| 入口       | 适用任务                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 产品控制台 | 管理本账号实例、资源和产品 API Key；部分产品提供用量、调用记录或在线测试 |
| 运营管理   | 管理主账号在单个产品内的免费额度、超额扣费和实例上限                     |
| 产品配置   | 设置该产品的平台服务开关、默认额度、价格和默认实例上限                   |

运营记录用于额度和用量管理，不代替 RAM 授权。能看到产品入口不表示拥有所有资源操作权限；具体前提见各产品指南。

## 创建实例

1. 打开目标产品的控制台，点击“创建实例”。需要该产品的实例管理权限；只有读取、发送等权限时可能只能查看已有实例。
2. 填写 1～100 个字符的名称，以及 3～80 个字符的标识。标识只允许小写字母、数字和连字符，在本账号的同一产品内不能重复。JSON 端点还受该账号下端点标识的唯一性限制。
3. 创建后打开实例详情，配置该产品的资源。需要外部调用时再创建产品 Key。

当前实例界面不提供名称、标识编辑。停用但未删除的实例仍占实例数量；达到上限时联系管理员调整账号的实例上限，或确认数据已备份后删除不再使用的实例。

控制台顶部的额度和实例上限来自产品默认配置，不一定是本账号实际额度，也不表示剩余调用次数。实际账号额度以用量信息或运营设置为准。列表没有分页或自动轮询，点击顶部刷新可重新加载实例和 Key；资源区域的刷新方式见各产品指南。

## 创建、保存与撤销产品 Key

1. 在实例详情点击“创建 Key”，填写 1～100 个字符的名称。
2. 选择调用主体和至少一个动作。主账号可选择本账号内具备产品权限的主体；RAM 子用户只能绑定自己。切换主体后重新检查动作选择。
3. 按需设置到期时间；留空表示不设置到期时间。应选择未来时间，过去时间可能创建出立即不可用的 Key。
4. 创建后复制完整 Key，保存到部署环境的密钥管理系统，再点击“已保存 Key”。完整值只在这次窗口显示，之后无法回读。若响应丢失或未保存完整值，请重新加载列表、撤销不再使用的 Key，再创建替代 Key。
5. 从可信服务端使用 `Authorization: Bearer <PRODUCT_API_KEY>` 请求部署的 API 服务。具体路径、字段及额外签名要求见产品指南。

新 Key 使用 `sk-dpk-` 前缀，已有的 `dpk_` 凭据仍兼容。登录令牌、AccessKey 和中转令牌不能代替产品 Key。不要将它写进公开仓库、前端代码或移动端安装包。控制台在线测试需要在浏览器输入 Key，请仅在可信设备使用。

每把 Key 只绑定一个实例和一个主体。调用同时受 Key 已选动作及主体当前有效权限约束；收回主体权限会影响后续调用，不必重新签发 Key。实例管理权限不自动包含该产品的读取、写入或发送权限，运营设置也不会授予这些权限。

已有 Key 不提供动作、主体或到期时间修改。轮换时先创建并部署替代 Key，验证调用后，在原列表点击“撤销”并确认。撤销不可恢复；已进入处理的请求可能完成，公开访问和后台任务也不依赖这把 Key。列表仍可能显示未撤销但已过期的 Key，应核对到期时间。

## 停用或删除实例

| 操作     | 结果与后续处理                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------- |
| 停用实例 | 立即提交，无二次确认；新的产品 Key 调用被拒绝，数据和 Key 保留，可恢复实例                     |
| 恢复实例 | 重新允许符合产品开关、Key 有效性和权限条件的新调用；不会恢复已撤销或过期的 Key                 |
| 删除实例 | 确认后永久删除实例及其产品资源、相关资源历史和 Key，控制台不能恢复；账号级累计用量不会因此清零 |

停用实例不是统一的公开访问撤回开关。公开 JSON 地址仍可能访问，需单独调整端点访问保护或删除端点；推送已经排队的重试也可能继续，需先停用渠道。状态页、短链接和其他入口的行为请查看对应指南。正在执行的请求可能完成。

## 额度、费用与调用记录

同一账号的所有实例共享该产品的每日调用额度，RAM 子用户也不会获得额外独立额度。日期按服务端日历计算；跨日会使用新一天的计数，不代表历史日志删除。

| 设置                 | 实际含义                                                                   |
| -------------------- | -------------------------------------------------------------------------- |
| 使用产品默认额度     | 账号未指定覆盖值时使用产品当前默认额度，后续修改默认值会影响这类账号       |
| 指定账号每日免费额度 | 覆盖产品默认值；产品和 RAM 权限仍需单独满足                                |
| 超额单价为 0         | 不因每日产品额度拒绝调用，仍累计计量次数；资源容量、速率、输入限制等仍适用 |
| 超额单价大于 0       | 超出免费额度后，需要允许超额扣费且主账号余额充足，按当前单价逐次扣费       |

计量范围依产品和入口而异。控制台资源管理不等同于产品 Key 调用，公开短链接等入口也可能计量。推送接口正常返回但所有渠道失败仍计量；验证码验证不等于发送计量。不要把 HTTP 成功、Key 请求数、业务投递次数和计费次数混为一谈。

计量后执行抛错会进入用量和费用退回流程，退回可能延迟；已发生的外部请求或资源变更不因此回滚。配额或余额检查前就失败的请求也不保证出现在产品调用记录中。结果不确定时先核对资源、接收端和日志，再决定是否重复操作。

提供用量面板的产品显示账号在该产品的当日汇总及最近最多 200 条调用记录，按时间倒序，没有完整历史分页、导出或自动轮询。记录成功表示该调用正常完成，不代表消息已被阅读。加载失败可能保留旧数据；先按错误提示重试。JSON 产品控制台没有这块用量面板，可由有权限的管理员在运营管理查看。

## 管理账号额度与实例上限

1. 打开目标产品的“运营管理”，按用户名、显示名或账号 ID 搜索，按回车或搜索按钮执行；列表默认每页 20 条，可选 10、20、50、100 条。
2. 点击目标主账号的“管理用户”，核对用户名和账号 ID。尚无该产品运营记录的账号也可能出现在目录中，可保存其额度设置。
3. 选择使用产品默认额度，或填写 0～10000000 的整数；设置是否“允许超额扣费”及 1～1000 的实例上限，点击保存。
4. 已有产品记录时，可在抽屉查看实例、当日用量和最近调用审计。这里的实例表用于查看，不提供资源编辑或 Key 明文回读。

修改额度不会重置当日已用次数；调低实例上限不会自动删除已有实例，只影响后续创建。保存运营设置不会修改 RAM 产品权限。开启超额扣费可能使该账号后续调用扣减主账号余额，请先确认授权和当前价格。

顶部刷新重新加载账号目录，不会自动更新已打开抽屉的全部详情。重新打开详情或在错误提示中重试；重试会重新应用已保存的运营设置，未保存的输入可能丢失。实例、用量或审计任一读取失败时，详情可能保留旧内容；加载成功并核对账号后再判断。

## 配置产品默认值与价格

1. 打开该产品的“产品配置”，确认加载成功，核对产品名称与现有值。
2. 调整服务开关、默认每日免费额度、超额单价和默认实例上限，点击保存。开关切换后也需要保存才生效。
3. 修改后重新加载核对结果；变更影响后续调用，不重新结算历史调用。

默认额度范围为 0～10000000，默认实例上限为 1～1000；超额单价服务端允许 0～1000000，界面最多输入六位小数。单价为 0 时额度显示为无限，额度输入框隐藏；之后调为正价时重新确认实际额度。

默认实例上限只用于初始化新账号的产品记录；已有记录使用其保存的账号上限，不会全部随默认值改变。默认额度则由未覆盖该额度的账号实时使用。产品开关阻止新的相关产品调用，不删除数据，也不保证停止公开 JSON 访问或已排队的推送重试。

没有获准读取配置时，页面可能保留默认值或先前加载值，不能据此判断产品已关闭。先解决加载失败或缺少目标配置的问题，避免直接保存覆盖现有设置。当前页面不提供资源容量策略、通用设置或数据保留期的编辑；不要将这些 API 字段视为已生效的产品容量或清理承诺。

## 管理项目配额覆盖

“开发者服务管理”的额度覆盖用于项目方式调用的验证码、IP 定位和推送额度，与上述产品账户额度分开；不会增加产品 Key 的账号级免费额度。

1. 点击“新增额度覆盖”，选择用户或项目，填写实际 ID。
2. 选择验证码、IP 定位、推送投递或全部服务，填写 0～10000000 的每日免费额度。
3. 可设置未来失效时间；留空表示不设到期时间，清空后保存也会去掉原到期时间。
4. 保存后核对对象、服务范围、额度和失效时间。删除规则需确认，删除或到期后会回落到下一优先级。

适用优先级依次为：项目服务级、项目全服务、用户服务级、用户全服务、项目默认额度。用户级规则按项目所属用户匹配。相同对象类型、ID 和服务再次保存会更新已有规则；编辑时改变对象类型或服务范围可能写入另一规则，不会自动删除旧规则。需要迁移范围时请核对并清理旧规则。

列表包含尚未删除的过期覆盖，显示不表示生效。列表不分页、不轮询，加载失败可能保留旧记录。额度覆盖只调整免费次数，不授予权限，也不自动开启超额扣费。

## IAM 授权参考

以下为 IAM 强制模式规则。普通用户的产品目录、实例列表、主体目录、用量和调用记录分别需要 `GetProductCatalog`、`ListProductInstances`、`ListProductSubjects`、`GetProductUsage`、`ListProductCallLogs`；创建实例需要 `CreateProductInstance`，这些动作均使用 `quyan:developer:` 前缀，在账号资源上授权。修改、删除实例及列出、创建、撤销 Key，则分别使用 `UpdateProductInstance`、`DeleteProductInstance`、`ListProductInstanceKeys`、`CreateProductInstanceKey`、`RevokeProductInstanceKey`，在实例关联项目资源上授权。列表与写入相互独立；产品 Key 的动作范围仍需另外选择。

平台管理还要求真实全局组中的对应管理资格：运营管理使用 `DEVELOPER_PRODUCT_ENTITLEMENT_MANAGE`，产品配置使用 `DEVELOPER_PRODUCT_CONFIG_MANAGE`，配额覆盖使用 `DEVELOPER_QUOTA_MANAGE`。运营页面同时读取配置，因此还需配置读取资格和授权。OAuth 应用访问令牌不能用于这些平台管理接口。AssumeRole 只使用角色自身授权，匹配的 Deny 优先。

下表动作均加 `quyan:developer:`，资源路径均加 `acs:platform:*:platform:`；ID 必须使用真实记录 ID，不能把主账号 ID 当作产品账户记录 ID。

| 任务               | 动作                          | 资源路径                                                                                                                              |
| ------------------ | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 读取管理配置       | `ListProductConfigurations`   | `developer-product-config/<配置ID>`                                                                                                   |
| 保存配置           | `UpsertProductConfiguration`  | 同时授权 `developer-product-config-control/<productCode>` 和实际配置记录                                                              |
| 列出已保存产品账户 | `ListProductAccounts`         | `developer-product-account/<产品账户记录ID>`                                                                                          |
| 分页搜索主账号     | `ListProductAccountOwners`    | `developer-product-account-scope/<主账号ID>/<productCode>`；已有产品记录时还需该动作在实际记录上的授权                                |
| 保存账号额度       | `UpsertProductAccount`        | 同时授权上述账号产品范围和实际产品账户记录                                                                                            |
| 查看账号产品用量   | `GetProductAccountUsage`      | 实际产品账户记录                                                                                                                      |
| 查看账号产品实例   | `ListProductAccountInstances` | `developer-product-instance/<实例ID>`                                                                                                 |
| 查看账号调用记录   | `ListProductAccountCalls`     | `developer-product-call-log/<日志ID>`                                                                                                 |
| 读取配额覆盖       | `ListQuotaOverrides`          | `developer-quota-override/<覆盖记录ID>`                                                                                               |
| 保存配额覆盖       | `UpsertQuotaOverride`         | 同时授权 `developer-quota-subject/<user或project>/<主体ID>/<服务>` 和实际覆盖记录；服务为 `ip`、`verification`、`push` 或通用的 `all` |
| 删除配额覆盖       | `DeleteQuotaOverride`         | 实际覆盖记录                                                                                                                          |

管理列表按授权过滤；主账号目录的总数只计算可见账号，调用记录最多返回最近 200 条允许读取的记录。配置列表只列出已保存且可读的配置，按产品代码排序；保存一个产品不会自动初始化其他产品。账号产品列表按最近更新时间排序，禁用或过期但未删除的记录仍可能用于管理清理。管理员列出的实例须关联有效的同账号项目，停用实例仍可查看。

管理读取不自动创建目标账号产品记录或重置计数，按用户查询也不会绕过实际产品记录的授权。用量、配置和显示信息在相应资源授权后读取；调用元数据不含详细请求正文或凭据。首次保存也检查新记录，恢复已删除配置、账号记录或覆盖规则保留原 ID。资源、归属或权限并发变化可能使本次读写被拒绝；重新加载后再提交，不要凭旧页面反复重试。相关规则见 [RAM 管理]({{DOCS_BASE_URL}}/zh-CN/ram-management)。

## 常见问题

| 现象                     | 处理方法                                                                                        |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| 没有创建实例或 Key 按钮  | 检查实例管理资格及相关 IAM 动作；读取或发送权限不包含实例管理                                   |
| 主体或动作列表为空       | 核对同账号归属、主体当前产品权限和主体目录读取授权                                              |
| Key 返回 401 或 403      | 核对凭据类型、到期时间、撤销状态、实例和产品开关，以及 Key 动作和主体当前权限；以响应业务码为准 |
| 顶部额度与运营设置不同   | 顶部为产品默认值，实际账号覆盖值、当日用量和免费不限量状态需分别核对                            |
| 已保存但页面其他区域仍旧 | 资源、目录和详情不是统一自动刷新；按对应入口重新加载，保存成功也不保证后续刷新成功              |
| 停用实例后仍有访问或投递 | 检查公开 JSON 的访问保护和推送渠道重试，按产品指南撤回对应入口                                  |
