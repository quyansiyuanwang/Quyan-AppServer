# 余额管理

此页面用于管理员按用户维度查看和调整余额。

## 页面用途

- 搜索指定用户的余额信息。
- 手动加减余额。
- 查看交易记录。
- 处理充值、补偿或扣减类问题。

## 你会看到什么

### 查询区域

- 用户 ID 搜索框。
- 余额列表。
- 分页控件。

### 余额信息

- 当前余额。
- 关联用户。
- 历史变动入口。

### 管理动作

- 调整余额。
- 打开交易记录。

## 常见操作

1. 先按用户 ID 搜索目标账户。
2. 核对当前余额是否符合预期。
3. 打开调整窗口，填写变动金额或目标余额；两者会按当前显示的余额联动。正数增加余额，负数扣减余额，变动金额不能为零。
4. 检查“计入统计”开关和调整原因，再提交。开关默认开启：增加计入总充值，扣减计入总花销；关闭后不计入这些统计。
5. 调整成功后页面会重新加载当前列表。确认目标账户的实际余额，并查看交易记录。

## 所需权限

| 操作                | 所需权限           |
| ------------------- | ------------------ |
| 查看余额 / 交易记录 | `BALANCE_READ`     |
| 调整余额（充值）    | `BALANCE_RECHARGE` |

## 说明

- 余额调整应保留清晰原因，便于后续审计。未填写原因时，页面会使用默认的充值或扣减说明。
- 目标余额根据打开窗口时显示的余额计算，提交的是变动金额；如余额可能同时发生变化，请以提交后的实际余额为准。
- 列表的“刷新”会清空用户 ID 筛选并返回第一页；若要保留筛选条件重新查询，请点击“搜索”。
- 打开交易记录时默认加载最近 7 天。可切换到最近 1 天、30 天或全部记录；加载全部需要确认。记录中的“刷新”只追加上次加载以来的新记录，不会重新计算或裁剪当前时间范围；要重新按范围加载，请再次选择该范围。
- 若问题与自动消费有关，可进一步查看消耗统计和系统日志。
- 用户自助查看余额时，通常对应的是 [账户余额与转出]({{DOCS_BASE_URL}}/zh-CN/balance-history) 页面。
