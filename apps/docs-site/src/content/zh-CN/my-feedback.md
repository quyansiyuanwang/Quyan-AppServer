# 我的反馈

此页面用于提交建议、报告 Bug，并追踪反馈的处理进度。

## 页面用途

- 提交新的反馈、建议或 Bug 报告。
- 通过筛选和搜索浏览已提交的反馈。
- 查看完整详情，包括管理员回复与评论时间线。
- 编辑仍在处理中的反馈内容。

## 你会看到什么

### 反馈表单

- 类型选择：建议、Bug 或其他。
- 联系方式（可选），便于后续沟通。
- 标题与描述（必填）。
- 来源页面 — 标注反馈来自哪个页面。
- 复现步骤 — 描述问题如何复现。

### 反馈列表

- 支持关键词搜索。
- 可按处理状态（待处理、处理中、已采纳、已拒绝、已完成）与类型筛选。
- 每条显示标题、类型标签、状态标签、优先级和最后回复时间。
- 点击**查看详情**打开详情抽屉。

### 反馈详情抽屉

- 完整元数据：类型、状态、优先级、提交者、处理人、时间戳。
- 完整描述与复现步骤。
- 评论时间线，展示管理员与用户回复。
- 回复编辑器，允许在非终态反馈中添加评论。

## 常见操作

1. 填写表单并提交新的反馈或 Bug 报告。
2. 搜索或筛选列表以定位特定条目。
3. 点击反馈项查看完整详情与回复记录。
4. 编辑反馈内容以补充更多信息。
5. 发表评论与审核人员沟通。

## 说明

- 已**拒绝**或**已完成**状态的反馈不可再编辑。
- 评论内容对反馈线程公开 — 请勿包含隐私信息。
- 工作区建议页面（`/workspace/suggestions`）共享同一组件，可嵌入其他页面供游客使用。
