# 错误中心

错误中心将浏览器运行时错误、Vue 组件错误、未处理 Promise 和服务端非预期错误聚合到一起，便于按错误指纹排查。

## 使用前提

- 需要错误报告查看权限才能打开页面。
- 错误上报会自动脱敏密码、令牌、Cookie、授权头和密钥。
- 错误详情保留 90 天，过期后自动删除。

## 页面内容

- 错误来源、最近发生时间、路由、错误信息、发生次数和影响用户数。
- 错误状态：`open`、`acknowledged`、`resolved`、`ignored`。
- 错误指纹下的堆栈、请求 ID、浏览器版本和受限上下文。

## 排查流程

1. 使用来源、状态或关键字筛选错误。
2. 打开错误详情，先查看最近发生记录和请求 ID。
3. 在系统日志中用请求 ID继续检查完整请求链路。
4. 确认处理结果后更新错误状态。

错误上报接口是后台受限的匿名入口，达到频率限制时会丢弃后续上报；这不会影响原始页面操作。
