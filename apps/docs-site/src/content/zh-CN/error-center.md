# 错误中心

错误中心按指纹聚合前端和后端的非预期错误。你可以查找近期发生的错误、检查堆栈和上下文，并记录处理状态。处理状态只用于跟进问题，不会修复故障或停止采集。

## 使用前提

- 在核心管理站点打开**错误中心**，需要错误报告读取权限。
- 查看错误组、查看发生记录和修改状态分别授权。能打开列表或看到状态按钮，不代表拥有后续操作权限。
- 错误信息可能包含业务数据。浏览器上报会处理部分常见敏感字段和文本，服务端也会处理上下文中的部分敏感字段；脱敏不能识别所有敏感内容。分享前仍需检查错误信息、堆栈和上下文。

## 查找错误组

1. 根据需要选择**来源**和**状态**。更改或清空其中一项会立即查询并返回第一页。
2. 输入搜索词后按 Enter。搜索会匹配错误信息、错误类型、路由或指纹中的文本，不会搜索发生记录的堆栈和上下文。
3. 按最近发生时间从新到旧查看结果，再单击目标错误组的查看按钮。

首次进入时不限制来源和状态，默认每页 20 组。时间使用浏览器本地格式显示。页面没有日期范围筛选，也不会自动刷新。

清空搜索框本身不会立即重新查询，请按 Enter 或单击**刷新**。顶部**刷新**使用表单当前值加载当前页，不会更新已打开详情中的发生记录。**清除筛选**清空搜索词、状态和来源并返回第一页。

列表加载失败时会显示失败提示并清空结果，不能将此时的零条记录理解为没有错误。使用页面提供的重试操作重新加载。

## 查看详情和发生记录

1. 打开错误组，确认详情加载成功。
2. 查看错误类型、来源、状态、路由、指纹和错误信息。
3. 展开最近的发生记录，检查可用的堆栈和上下文。记录按发生时间从新到旧排列，时间使用浏览器本地格式显示。
4. 如果从上下文或其他渠道获得请求 ID，在[系统日志]({{DOCS_BASE_URL}}/zh-CN/system-logs)中按该 ID 查找关联记录。

一个错误组可以包含多次相似错误。聚合时会归一化错误文本中的部分数字和标识，因此同一指纹不保证所有发生记录具有完全相同的错误文本或根因。组内错误信息保留首次记录的摘要，不一定是最近一次发生时的原始信息。

详情最多显示该组最近 **50 条**发生记录，页面不提供更早记录的翻页入口。累计发生次数可以大于当前显示条数。请求 ID、用户 ID、HTTP 状态和客户端版本没有单独的展示字段；某次记录也可能没有堆栈或上下文。

如果错误组详情请求失败，抽屉可能仍显示列表中的摘要，并且不会继续加载发生记录。不要将摘要或空记录区视为详情加载成功。关闭后重新打开；发生记录单独加载失败时也使用此方式重试，并检查对应读取权限。

## 更新处理状态

在详情中单击目标状态按钮，操作会立即提交，无需再次保存或确认。成功后列表重新加载；若当前状态筛选不再匹配，该组会从列表中消失。

| 状态                     | 跟进用途                                       |
| ------------------------ | ---------------------------------------------- |
| 待处理（`open`）         | 新错误的初始状态，也可手动切回此状态继续处理。 |
| 已确认（`acknowledged`） | 表示已经看到问题，正在排查或安排处理。         |
| 已解决（`resolved`）     | 表示处理人认为问题已解决。                     |
| 已忽略（`ignored`）      | 表示暂时不跟进该组。                           |

这些状态之间可以直接切换，没有必须逐级执行的流程。**已解决或已忽略的错误再次发生时，状态不会自动恢复为待处理**，但最近发生时间和次数仍会更新。排查复发时请选择全部状态并检查最新发生时间。

状态更新不会删除记录、关闭上报、重试失败请求或回滚业务操作。列表刷新也不会重新加载抽屉中的发生记录；需要最新详情时，请关闭并重新打开。

## 采集范围和保留期限

错误中心收集已接入上报的浏览器运行时错误、Vue 组件错误、未处理的 Promise 拒绝及服务端非预期异常。它不是全部请求或全部失败操作的清单。

- 浏览器会对相似上报做短时间去重，并批量延迟发送。网络中断、页面退出、浏览器存储限制、队列容量、上报大小限制或服务端限流都可能造成延迟或缺失。
- 服务端错误保存也可能失败。列表中没有记录，不能证明故障没有发生。
- 发生次数统计已保存的上报，不等于实际故障次数、失败请求数或受影响用户数。相同指纹也可能合并不同参数下的错误。
- 文本和上下文有长度、深度及条目数限制；显示内容可能已截断或脱敏，无法据此还原完整请求。

生命周期调度成功执行时，会删除**最近一次发生时间已超过 90 天的整个错误组及其发生记录**。这不是按每条发生记录分别保留 90 天；持续发生的错误组可能保留更早的记录。待处理、已解决等状态不改变该规则。清理依赖调度启用和成功运行，不保证到期立即删除，页面也不提供删除或恢复入口。

## IAM 授权说明

启用 IAM 强制授权时，以下操作独立授权，资源为所选错误组 `acs:platform:*:platform:error-group/<groupId>`。

| 任务           | 所需操作                                                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 浏览错误组     | `quyan:system:error_report:ListErrorGroups`，逐组评估。                                                                            |
| 读取错误组摘要 | `quyan:system:error_report:GetErrorGroup`。                                                                                        |
| 查看发生记录   | `quyan:system:error_report:ListErrorOccurrences`，以所属错误组为授权资源。                                                         |
| 修改处理状态   | `quyan:system:error_report:UpdateErrorGroupStatus`，并在同一资源上具有 `quyan:system:error_report:GetErrorGroup`，以读取更新结果。 |

浏览列表不会自动获得详情或发生记录权限。页面先读取组摘要再加载发生记录，因此排查详情需要同时具备这两项读取授权。状态更新的读取依赖也不会因为授予更新操作而自动满足；操作目录通过 `requiredActions` 列出此依赖。

操作员还需由平台全局用户组提供错误报告读取资格；更新状态时需同时具备读取和更新资格。账户所有者、账户私有组、用户附加权限或单独的通配符策略都不能替代这项资格。角色会话使用角色策略，不继承用户组的 Allow 授权；这些管理操作不接受 OAuth 访问令牌。

列表先过滤后分页，总数只包含已授权的有效错误组。发生记录总数只包含所属组的有效记录。权限撤销、角色会话过期或撤销、错误组失效或查询期间数据变化都可能使请求失败，请刷新后重试。超出本次查询初始范围的新错误组在下一次查询中展示。

状态更新还需满足重放保护要求，提交前授权复核失败会撤销本次状态变更。legacy 和 shadow 模式沿用既有权限和响应行为。

## 常见问题

| 现象                               | 处理方法                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------- |
| 列表有错误，详情或发生记录无法读取 | 分别检查组摘要和发生记录权限，关闭抽屉后重新打开。                         |
| 修复后看不到新发生的错误           | 清除状态筛选并刷新；已解决的组复发后仍保持已解决状态。                     |
| 次数增加，详情记录没有变化         | 关闭详情后重新打开；顶部刷新只更新列表。                                   |
| 修改状态后请求报错                 | 重新打开详情确认当前状态；检查更新和摘要读取权限，必要时重新登录后再操作。 |
| 找不到更早的发生记录               | 详情仅展示最近 50 条；若整个组已因超期被清理，页面无法恢复。               |
