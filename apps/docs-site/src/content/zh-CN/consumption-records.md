# 消费记录

此页面用于查看 API、对话和月卡抵扣相关的使用情况。账户余额、兑换和资金转出请前往“账户余额”页面。

## 页面概览

页面顶部汇总展示：

- 已使用额度与总额度。
- 总请求次数。
- 平均 TPM（每分钟 Token 数）。
- 平均 RPM（每分钟请求数）。

下方消费列表仅展示消费类记录，不显示兑换、转账或其他账户资金流水。顶部额度汇总单独获取，不随列表筛选或加载范围改变；请求次数、平均 TPM 和平均 RPM 基于当前加载范围内的 API 使用记录，不随类型、令牌、渠道、模型或日期筛选改变。

## 筛选消费记录

可通过以下条件缩小结果范围：

- 消费类型：对话、API 调用或月卡抵扣。
- 令牌、渠道和模型。
- 起止日期。
- 加载范围：1 天、7 天、30 天或全部记录。

加载范围默认是最近 1 天。日期、类型等筛选只作用于当前加载范围内的消费记录及图表；令牌和渠道选项也来自已加载记录。查看更早的数据时，请先扩大加载范围并等待后台加载，再设置筛选条件。首次选择“全部”时，页面可能要求确认。页面可能先展示缓存；加载或刷新失败时，记录、筛选选项和统计可能不完整。可切换到较短范围后重新扩大范围重试；仍有疑问时请联系管理员核对。

使用“清除筛选”可清除类型、令牌、渠道、模型和日期条件；加载范围需单独调整。

## 查看明细

列表支持表格和图表视图。展开记录可查看模型、Token、计费、渠道和请求标识等可用明细。不同记录的可见字段取决于请求类型和当时的计费信息。

## 注意事项

- 请求次数、TPM 和 RPM 的统计量来自已加载的 API 使用记录，排除零费用上游错误；TPM 只累加输入和输出 Token。平均值的时间跨度取所有已加载 API 使用记录的首末时间（包括这些零费用错误），最短按 1 分钟计算。这些平均值不是服务端限流配置。
- 若需核对余额充值、转出或退款，请前往“账户余额”。
- 记录加载范围越大，初次加载所需时间可能越长。
