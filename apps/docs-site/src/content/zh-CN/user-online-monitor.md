# 用户在线监控

用户在线监控用于查询会话、查看单个用户的会话时间线、导出记录，并在需要时强制下线。在线状态来自心跳，不代表用户此刻正在操作，也不是全部登录行为的审计记录。

## 使用前提

- 在核心管理站点打开**用户在线监控**，需要 `user_online_monitor:read`。强制下线另需 `user_online_monitor:force_offline`；IAM 强制模式还会检查具体操作和资源范围。
- 使用桌面端查看详情、导出或强制下线。移动端可查看总览和筛选结果；当前移动端虽有查看详情按钮，但不显示详情抽屉。
- 会话包含 IP、地域和 User-Agent 等信息。仅向有权限的人员分享，导出文件也需妥善保管。

## 查找会话

1. 根据需要输入关键字、IP 或地域，或选择在线状态。文本输入提交变化后查询；状态变化立即查询，均返回第一页。
2. 关键字匹配用户 ID、用户名或姓名中的文本。IP 和地域也是文本匹配，不是网段匹配或地图范围筛选。
3. 查看目标会话，再在桌面端单击**查看详情**。

总览**每行是一条会话**，同一用户可以出现多行，也可以同时具有在线和离线记录。列表中的 IP 和地域是该会话最后记录的信息，不是完整 IP 变更历史。IP 归属地不能证明用户的精确位置。

默认每页 20 条，桌面端可调整每页数量；移动端不提供数量选择器。清除各输入框或状态可解除相应筛选。顶部**刷新**使用当前筛选重新查询当前页，同时更新总览指标，不会刷新已打开的详情。页面没有自动轮询。

查询失败时，列表和统计可能保留之前的值，首次失败时也可能保留初始零值。请检查错误提示，刷新成功后再判断当前状态。

## 理解在线状态和统计

心跳发送间隔和超时阈值以当前服务端配置为准。网络中断、浏览器后台调度或心跳请求失败可能使会话被判为离线；显示的结束时间也可能由心跳超时推算或由后续清理确定，不是精确关闭浏览器的时间。

IAM 强制模式下，总览统计基于当前账户中获准读取的有效会话：

| 指标         | 统计范围                                                                     |
| ------------ | ---------------------------------------------------------------------------- |
| 在线用户数   | 至少有一条获准读取的在线会话的不同用户数。                                   |
| 离线用户数   | 有可见会话、但没有可见在线会话的用户数；不包含从未有可见会话的全部注册用户。 |
| 活跃会话数   | 全部获准读取的在线会话数，不是在线用户数。                                   |
| 平均会话时长 | 当前筛选结果的**当前页**会话时长均值，切换页码或每页数量可能改变结果。       |
| 列表总数     | 符合筛选且获准读取的会话数，不是不同用户数。                                 |

前三项不会随普通关键字、IP 或地域筛选缩小；平均时长和列表总数会受筛选或分页影响。移动端只显示在线用户数和活跃会话数。

legacy 和 shadow 模式保留原统计口径：名为“在线用户数”的值实际按在线会话计数，并与“活跃会话数”相同；离线用户数由全部用户记录数减去该值计算，最低为 0。选择在线状态时，该计数还会受到当前查询筛选影响。请勿据此计算准确的用户在线率。

## 查看用户详情和时间线

1. 在桌面端打开目标用户详情，确认标题中的用户名正确且加载成功。
2. 检查当前会话数、总会话数、总在线时长，以及最近一次会话的 IP、地域、User-Agent 和时间。
3. 按需要选择日期时间范围。范围按会话的**开始时间**筛选，包含边界，不是按最后心跳、结束时间或与该时段是否重叠筛选。
4. 翻页查看当前在线会话卡片和历史离线时间线。

时间线默认每页 10 条，可切换为 20 或 50 条；按开始时间从新到旧排列。在线卡片和离线时间线只拆分**当前时间线页**的记录。某一区域为空不表示该用户没有其他在线或历史会话，请检查其他页。

详情顶部汇总不随日期筛选变化。总在线时长汇总已保存的会话时长，不会持续累加尚未结束会话的实时在线时长，也不是多会话去重后的实际在场时间。IAM 强制模式下，用户摘要可汇总该用户全部有效会话，而时间线只列出获准读取的会话，两者数量可能不一致。

重新打开详情时，日期控件可能保留上次选择，但首次加载的时间线不应用该范围。请重新选择或清除范围，等待查询成功后再查看或导出。导出始终使用控件当前显示的范围。

**详情加载失败时可能保留上一次查看的用户和会话。**关闭抽屉后重新打开目标用户，确认加载成功和标题正确后再强制下线或导出。筛选、翻页失败也可能保留旧时间线。需要最新详情时关闭后重新打开；顶部刷新只更新总览。

## 强制下线

### 结束单个会话

在目标在线会话卡片中单击强制下线，核对确认提示后提交。操作结束所选在线记录，并撤销其关联的认证会话；共享该认证会话的其他页面或连接也可能受影响，不一定只影响一张卡片。

### 结束用户的全部会话

在用户详情工具栏中单击强制用户下线，核对用户名后确认。该操作影响目标用户的全部当前会话，范围不限于时间线当前页、日期筛选或可见的几条记录。详情显示用户离线时，该按钮不可用。

操作成功后会重新加载目标详情和总览。若命中操作者自己的当前认证会话或用户，当前页面也会退出登录。该操作不会删除历史记录，也不会禁止用户以后重新登录。

下线依赖服务端后续认证和心跳检查生效，页面不会保证所有客户端画面在同一时刻关闭。IAM 强制模式下，撤销标记无法可靠保存时操作会报错。遇到网络错误或刷新失败，先重新查询目标状态，不要仅凭旧卡片反复执行。

## 导出会话记录

1. 确认用户详情加载成功，检查标题。
2. 重新选择或清除日期范围，确认时间线查询成功。
3. 在导出菜单中选择 **CSV** 或 **JSON**，等待浏览器下载。

导出会请求日期范围内所有匹配的时间线页，不只导出当前页。字段包含 `sessionId`、`authSessionId`、开始时间、最后心跳、结束时间、秒数及格式化时长、IP、地域、User-Agent 和在线状态。JSON 还包括用户摘要、筛选范围和导出时间；这些摘要不是日期范围内的重新统计。

日期时间按接口提供的 ISO 格式导出，界面则使用浏览器本地时区显示。分页请求期间会话可能变化，导出不保证所有行来自同一时刻的快照。任一页读取失败时应重试完整导出；大范围记录较多时可缩小日期范围。

## IAM 授权说明

IAM 强制模式下，仅处理当前账户内的有效用户和会话；列表及时间线先检查会话授权，再筛选和分页。

| 任务             | 所需操作                           | 资源                                                               |
| ---------------- | ---------------------------------- | ------------------------------------------------------------------ |
| 浏览总览         | `quyan:user:ListOnlineSessions`    | `acs:quyan:*:<accountOwnerId>:online-session/<userId>/<sessionId>` |
| 查看用户摘要     | `quyan:user:GetOnlineUser`         | `acs:quyan:*:<accountOwnerId>:user/<userId>`                       |
| 查看时间线或导出 | `quyan:user:GetOnlineUserTimeline` | 每条会话的 `online-session` 资源。                                 |
| 下线单个会话     | `quyan:user:ForceOfflineSession`   | 目标 `online-session` 资源。                                       |
| 下线整个用户     | `quyan:user:ForceOfflineUser`      | 目标 `user` 资源。                                                 |

这些操作互不替代。页面同时加载用户摘要和时间线，打开详情需两类读取授权；导出复用时间线读取。按钮可见不代表后端允许操作。角色会话需满足角色策略，匹配的显式 Deny 优先，权限或会话失效后需重新获取当前结果。

受委托的子账户不能强制账户所有者或其会话下线，即使策略允许该操作；账户所有者可以操作自己的会话。跨账户、无效目标或身份失效的操作会被拒绝。强制下线仍需满足重放保护要求；只授予读取权限不会获得下线能力。legacy 和 shadow 模式沿用既有权限与行为。
