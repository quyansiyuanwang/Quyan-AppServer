# 脚本管理

此页面用于编写、保存和运行自己的 JavaScript 脚本，并查看执行结果。

## 页面用途

- 维护已保存脚本。
- 运行选中的脚本。
- 查看输出和历史记录。
- 在需要时终止正在运行的脚本。

## 你会看到什么

### 脚本列表

- 脚本名称与选中状态。
- 安全警告和确认勾选项。
- 桌面端提供批量选择工具；移动端可逐个运行脚本。

### 执行动作

- 桌面端可运行所选脚本、终止全部脚本和清空结果。
- 桌面端和移动端均可终止单个正在运行的脚本。
- 单脚本运行、编辑、历史、删除动作。

### 结果区域

- 实时执行输出。
- 历史或过去结果入口。

## 常见操作

1. 先确认安全警告。
2. 桌面端可选择一个或多个脚本并批量运行，也可单独运行；移动端使用每个脚本的运行按钮。
3. 只运行你信任且理解用途的脚本。
4. 监控实时输出，异常时及时终止。
5. 需要对比时查看执行历史。

## 脚本来源说明

具有相应权限的用户可以自行编写和保存脚本。运行前需勾选安全确认并确认执行；页面检测到部分常见网络 API 时还会再次提醒，但这项检测不能保证识别所有风险。

## 等待异步操作

脚本的顶层代码可以使用 `await`。请等待需要完成的异步操作；脚本结束后 Worker 会被终止，未等待的定时器或其他后台回调可能来不及执行。例如：

```js
await new Promise((resolve) => setTimeout(resolve, 1000))
console.log('等待完成')
```

`console.log`、`console.warn` 和 `console.error` 的内容会显示在输出中。调用 `console.error` 本身不会将执行状态标记为失败；需要中止并标记失败时，可抛出异常。请同时检查输出和执行状态。

## 所需权限

| 操作            | 所需权限        |
| --------------- | --------------- |
| 查看脚本        | `SCRIPT_READ`   |
| 新建 / 编辑脚本 | `SCRIPT_CREATE` |
| 删除脚本        | `SCRIPT_DELETE` |

## 说明

- 脚本在当前浏览器的 Web Worker 中执行，可能发起网络请求；它不能直接操作页面 DOM。请先审查代码和请求目标，不要运行来源不明的脚本，也不要输出凭据或敏感数据。
- 桌面端“全选”选择整个列表的脚本，包括其他分页中的脚本。批量运行会同时启动所选脚本；请先确认选择范围和可能的副作用。
- 离开脚本管理页面会终止仍在运行的脚本。已发出的网络请求或其他外部操作不一定能撤销。
- 运行结束后页面会尝试将代码快照和输出保存为历史；保存失败、Worker 错误或手动终止时，历史可能缺失。清空结果会终止正在运行的脚本并清除当前页面结果，不会清除已保存的历史。
