# 脚本管理

此页面用于编写、保存和运行自己的 JavaScript 脚本，并查看执行结果。

## 创建或编辑脚本

登录后，具有相应权限的用户可管理自己的脚本。

1. 点击新建按钮，填写脚本名称和 JavaScript 代码，按需填写描述。名称最多 100 个字符，描述最多 500 个字符。
2. 点击**保存**，成功后在列表中找到脚本。保存只更新脚本内容，不会执行代码。
3. 要修改已有脚本，点击该脚本的编辑按钮，修改后保存。
4. 要删除脚本，点击删除并确认。删除前请先保存需要保留的代码。

## 运行与停止

1. 阅读安全提示并勾选确认，只运行你信任且理解用途的脚本。
2. 点击脚本的运行按钮。桌面端也可选中多个脚本，再运行所选脚本；移动端使用每个脚本的运行按钮。
3. 在确认框中确认执行。页面检测到部分常见网络 API 时还会再次提醒，但这项检测不能保证识别所有风险。
4. 在结果区域查看实时输出和状态，需要时终止单个正在运行的脚本。桌面端还可终止全部脚本或清空本次结果。

每次运行都会执行当时已保存的代码。修改脚本不会更新已启动的执行；需要使用新代码时，请保存后重新运行。

## 查看结果和历史

结果区域显示本次页面会话中的执行及其输出，状态包括运行中、已完成、错误和已终止。点击脚本的历史按钮，可查看已保存的执行时间、耗时和输出；输出较长时，将鼠标悬停在预览上可查看完整内容。

执行结果和历史是两个不同的范围：结果中出现一条执行，不代表其历史已经保存。保存失败、Worker 错误或手动终止时，历史可能缺失。清空结果会终止正在运行的脚本并清除当前页面结果，不会清除已保存的历史。

## 等待异步操作

脚本的顶层代码可以使用 `await`。请等待需要完成的异步操作；脚本结束后 Worker 会被终止，未等待的定时器或其他后台回调可能来不及执行。例如：

```js
await new Promise((resolve) => setTimeout(resolve, 1000))
console.log('等待完成')
```

`console.log`、`console.warn` 和 `console.error` 的内容会显示在输出中。调用 `console.error` 本身不会将执行状态标记为失败；需要中止并标记失败时，可抛出异常。请同时检查输出和执行状态。

## 所需权限

| 操作            | 所需权限        |
| --------------- | --------------- |
| 查看脚本        | `SCRIPT_READ`   |
| 新建 / 编辑脚本 | `SCRIPT_CREATE` |
| 删除脚本        | `SCRIPT_DELETE` |

## 说明

- 脚本在当前浏览器的 Web Worker 中执行，可能发起网络请求；它不能直接操作页面 DOM。请先审查代码和请求目标，不要运行来源不明的脚本，也不要输出凭据或敏感数据。
- 桌面端“全选”选择整个列表的脚本，包括其他分页中的脚本。批量运行会同时启动所选脚本；请先确认选择范围和可能的副作用。
- 离开脚本管理页面会终止仍在运行的脚本。已发出的网络请求或其他外部操作不一定能撤销。
- 运行结束后页面会尝试将代码快照和输出保存到服务端；脚本代码和输出中都不应包含凭据或不必要的敏感信息。
