# 账户余额与转出

此页面用于管理账户余额、兑换充值和资金转出。API 调用的用量指标与消费明细位于“消费记录”页面，不与账户资金流水混在一起。

## 使用前准备

登录后，在账户站点打开“账户余额”。兑换会充值到当前登录账户，操作前请确认账户身份。

生成余额兑换码和直接转账需由服务端启用，余额需足以支付到账金额与手续费。两种转出的单笔到账金额均为 0.01～100000，最多支持 4 位小数。

IAM 强制模式下，查看余额、查看流水、兑换、创建和取消兑换码、直接转账分别检查权限；显式 Deny 可以限制其中某项操作。兑换码列表只统计并展示获准查看的本人兑换码，列表为空不一定表示没有创建过兑换码。

## 支付宝充值

管理员启用支付宝后，账户余额页显示支付宝充值入口。输入人民币金额，核对预计到账额度后选择“支付宝付款”，在支付宝收银台完成支付。

金额必填，须大于零、最多保留两位小数，且在当前配置的最小和最大金额之间。输入框中的范围是提示，不是已填写的金额；未通过校验时页面会提示原因，不会创建订单。

- 到账额度使用下单时的充值比例。例如比例为 100 时，支付 1 元增加 100 额度；后续调整比例不会改变已有订单。
- 沙箱标签表示测试环境，不发生真实资金转移；沙箱需要使用测试付款账户。
- 从收银台返回后页面会查询付款状态。返回地址中的参数不能证明支付成功，只有服务端确认后才会入账。
- 已付款仍显示“等待支付确认”时，可使用订单的刷新按钮；后台也会补查订单。不要立即创建另一笔订单重复支付。
- 订单列表支持分页。退款记录显示管理员发起的原路退款及其处理结果。

退款由管理员处理，可全额或部分退款。退款按原订单比例扣回额度，要求当前可用余额充足；已消费、已转出或拼车预留的额度不能用于退款。处理中的退款先扣留额度，成功后完成退款，明确失败时返还额度；支付宝结果未知时继续处理中。多次部分退款累计不能超过原订单实付金额。

## 兑换充值

1. 在页面顶部的兑换码输入框中粘贴完整兑换码。
2. 点击“兑换”，等待成功提示。管理员兑换码与他人创建的余额兑换码都使用此入口；不能兑换自己创建的余额兑换码。
3. 核对更新后的余额。如需查看对应流水，使用资金流水区域的刷新按钮。

兑换码不存在、已兑换、已取消或已过期时无法使用。请向提供者核对，不要公开完整兑换码。

## 生成余额兑换码

1. 在转出区域点击“生成兑换码”，填写收款人最终到账金额，可选设置晚于当前时间的兑换截止时间。
2. 核对当前手续费率、手续费、实际扣除额，以及取消时预计返还的手续费和总额。付款方另外承担手续费。
3. 提交并完成要求的安全验证。创建成功时立即从余额扣除到账金额和手续费；余额不足时无法创建。

创建后，在“我的兑换码”列表中点击遮罩显示的兑换码，即可复制完整兑换码。请只将完整兑换码发送给预期的收款人；他人获取后也可能使用。

- 到期会阻止兑换，但不会自动退回余额；未兑换的过期码仍可由创建者取消。
- 兑换码只能由创建者以外的有效用户兑换。
- 未兑换前可以取消。取消后返还到账金额，并按创建时固化的比例返还部分或全部手续费。
- 已兑换或已取消的兑换码不能再次使用或取消。

费率和取消返还比例以创建时服务端快照为准。后台后续调整配置不会改变已经生成的兑换码。

### 取消未兑换的兑换码

在“我的兑换码”列表找到目标，点击“取消”，确认并完成要求的安全验证。成功后，兑换码状态变为已取消，退款计入创建者余额。若收款人已经先行兑换，取消会失败；请刷新列表核对状态。

## 直接转账

1. 在转出区域点击“直接转账”，填写收款人的精确用户名和到账金额，可选填写不超过 500 字符的备注。
2. 核对用户名、当前费率、手续费和实际扣除额。收款人到账金额不包含手续费，手续费由付款方额外承担。
3. 提交后确认不可撤回提示，并完成要求的安全验证。成功后核对余额和转出流水。

不能向自己或不可用的用户转账。直接转账成功后不可撤回。系统不会提供用户目录或模糊搜索，请确认用户名无误后再提交。

## 账户资金流水

资金流水用于核对余额变化来源。加载范围默认是最近 1 天，也可选择最近 7 天、30 天或全部；这些天数从当前时刻向前计算，不按自然日计算。日期筛选只筛选当前加载范围内的记录；查询更早的流水时，请先扩大加载范围并等待后台加载，再设置日期。选择“全部”时可能需要确认。

服务端当前只提供最近 30 天的流水，“全部”不代表账户创建以来的完整历史。本地缓存可能保留更早的记录，但不能据此保证历史完整。页面可能先展示缓存，加载或刷新失败时记录也可能不完整；可切换到较短范围后重新扩大范围重试。仍无法确认时，请联系管理员核对，不要仅凭列表判断资金操作是否完成。

消费类 API 调用记录不会显示在这里，请前往[消费记录]({{DOCS_BASE_URL}}/zh-CN/consumption-records)筛选模型、渠道、令牌和使用类型。

## 注意事项

- 顶部刷新按钮更新余额；转出区域的刷新按钮更新配置和当前页兑换码，资金流水有单独的刷新按钮。
- 兑换、创建或取消兑换码，或直接转账时若请求超时或连接中断，结果可能尚未确认。刷新余额和资金流水；创建或取消兑换码时还应刷新“我的兑换码”列表。核对操作是否已完成后再决定是否重试；仍不确定时请联系管理员。
- 兑换码创建、取消和直接转账可能要求额外的安全验证。
- 功能是否可用、手续费率和手续费返还比例由当前服务端配置决定。
- 页面中的金额预览用于帮助确认操作，最终扣除和返还金额以服务端处理结果为准。

## 常见问题

| 情况                           | 处理方法                                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| 找不到生成兑换码或直接转账按钮 | 点击转出区域的刷新按钮，等待配置和兑换码列表成功加载；仍无按钮时，请管理员确认功能是否启用。 |
| 翻页后列表未变化，或刷新失败   | 失败时可能保留上次成功加载的数据，不要将旧列表当作当前页结果；重新刷新并等待成功。           |
| 无法复制兑换码                 | 复制依赖浏览器剪贴板权限。确认允许访问后再次点击，并检查实际粘贴结果。                       |
| 过期兑换码仍显示可用状态       | 可用状态不代表尚未过期。创建者可取消未兑换的过期码取回相应退款。                             |
