# 账户余额与转出

此页面用于管理账户余额、兑换充值和资金转出。API 调用的用量指标与消费明细位于“消费记录”页面，不与账户资金流水混在一起。

## 你可以做什么

- 查看并刷新当前账户余额。
- 输入兑换码为自己的账户充值。
- 生成可分享的余额兑换码。
- 向唯一用户名对应的用户直接转账。
- 查看兑换、转入、转出、退款和管理员调整等账户资金流水。

## 兑换充值

输入有效兑换码后，系统会将对应余额记入当前账户。管理员兑换码与他人创建的余额兑换码都使用同一兑换入口；不能兑换自己创建的余额兑换码。 兑换成功后页面更新余额；如需查看对应流水，请使用资金流水区域的刷新按钮。

## 生成余额兑换码

创建时填写的是收款人最终到账金额，付款方另外承担手续费。创建窗口会在提交前展示当前手续费率、手续费、实际扣除额，以及取消时预计返还的手续费和总额。创建成功时立即从余额扣除到账金额和手续费；余额不足时无法创建。

创建后，在“我的兑换码”列表中点击遮罩显示的兑换码，即可复制完整兑换码。请只将完整兑换码发送给预期的收款人；他人获取后也可能使用。

- 可选设置兑换截止时间；未兑换的过期码仍可由创建者取消。
- 兑换码只能由创建者以外的有效用户兑换。
- 未兑换前可以取消。取消后返还到账金额，并按创建时固化的比例返还部分或全部手续费。
- 已兑换或已取消的兑换码不能再次使用或取消。

费率和取消返还比例以创建时服务端快照为准。后台后续调整配置不会改变已经生成的兑换码。

## 直接转账

填写收款人的精确用户名和到账金额即可转账。收款人到账金额不包含手续费，手续费由付款方额外承担。提交前会显示当前费率、手续费和实际扣除额。

直接转账成功后不可撤回。系统不会提供用户目录或模糊搜索，请确认用户名无误后再提交。

## 账户资金流水

资金流水用于核对余额变化来源。加载范围默认是最近 1 天，也可选择最近 7 天、30 天或全部。日期筛选只筛选当前加载范围内的记录；查询更早的流水时，请先扩大加载范围并等待加载完成，再设置日期。消费类 API 调用记录不会显示在这里，请前往“消费记录”筛选模型、渠道、令牌和使用类型。

## 注意事项

- 顶部刷新按钮更新余额；转出区域的刷新按钮更新配置和当前页兑换码，资金流水有单独的刷新按钮。
- 兑换、创建或取消兑换码，或直接转账时若请求超时或连接中断，结果可能尚未确认。刷新余额和资金流水；创建或取消兑换码时还应刷新“我的兑换码”列表。核对操作是否已完成后再决定是否重试；仍不确定时请联系管理员。
- 兑换码创建和直接转账可能要求额外的安全验证。
- 功能是否可用、手续费率和手续费返还比例由当前服务端配置决定。
- 页面中的金额预览用于帮助确认操作，最终扣除和返还金额以服务端处理结果为准。
