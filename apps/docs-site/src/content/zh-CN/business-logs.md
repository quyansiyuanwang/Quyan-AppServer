# 业务日志

在核心管理站的**业务操作日志**查看已经采集的业务审计记录，追踪谁执行了什么操作、影响了哪个用户或资源，以及记录中的成功或失败结果。排查 API 请求和服务端错误时，可结合[系统日志]({{DOCS_BASE_URL}}/zh-CN/system-logs)。

## 开始前

需要 `SYSTEM_BUSINESS_LOG_READ` 权限。IAM 强制模式还要求有效的部署管理全局组资格，并分别授权日志列表、统计和筛选目录，详见下文。

本页只读，不提供修改、删除日志或撤销业务操作的入口。日志只反映已采集且你有权查看的记录，不能代替完整操作历史或当前业务状态。

## 查找一项操作

1. 打开**业务操作日志**，按**操作类型**或**操作类别**缩小范围。选项是系统支持的操作目录，不表示每种操作都已经有日志。
2. 在**操作者**或**目标**中输入用户名或完整用户 ID。文本输入确认或失去焦点、选择器变更时会重新查询，不需要额外点击搜索按钮。
3. 按需填写 **IP 地址**和**日期范围**。筛选变化后列表回到第一页，同时重新加载统计。
4. 找到记录后，先核对时间、描述、目标和状态，再展开查看详情。

筛选可以组合使用。清空某项会取消该项限制；页面初始没有日期范围，因此可以查询仍在日志库中的历史记录。

### 筛选的匹配范围

| 条件               | 实际匹配方式                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------- |
| 操作类型、操作类别 | 匹配所选目录值                                                                           |
| 操作者             | 当前有效用户的用户名包含输入文本，或用户 ID 完整匹配                                     |
| 目标               | 当前有效目标用户的用户名包含输入文本，或用户 ID 完整匹配；不搜索资源类型、资源 ID 或描述 |
| IP 地址            | 部分文本匹配；回环及 IPv4 映射地址会按规范化后的地址查询                                 |
| 日期范围           | 按记录时间查询所选起止时刻，包含边界，跨度最多 30 天                                     |

用户名匹配每次最多展开 100 个有效用户。宽泛名称可能漏查，精确定位时优先输入完整用户 ID。已禁用或删除用户可能无法通过操作者或目标文本筛选找到；可清空该条件，改用操作类型、时间或 IP 缩小范围后查看。

**当前版本的状态筛选存在限制：选择“失败”时，也可能按成功记录查询。** 调查失败操作时，请清空状态条件，再按列表中的实际成功／失败标签核对，不要把筛选后没有失败记录理解为没有发生失败。

日期范围超过 30 天或结束早于开始时，页面会提示并恢复上一次有效范围。调查更长区间时，可分段查询，或清空日期范围查看仍保留的历史记录。清空范围不会恢复已归档或删除的数据。

## 阅读记录详情

桌面端点击行首展开图标；移动端展开卡片中的**变更**。详情使用列表已返回的数据，不另外加载一份操作记录。

| 字段                  | 阅读建议                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------- |
| 操作者                | 展示当前可解析的用户名；缺少可用用户名时可能显示“系统”，不能仅凭该标签认定一定是系统自动操作 |
| 目标                  | 优先展示目标用户；没有目标用户时可展示资源类型和资源 ID。目标筛选框只查用户                  |
| 描述与状态            | 描述说明该项已记录的动作；成功或失败属于该条记录，不保证后续外部投递或关联操作也成功         |
| 变更、元数据          | 仅在记录存在对应内容时展示，敏感凭据会脱敏；空白不等于没有发生变更                           |
| 错误信息              | 失败原因可能保存在此处，也可能没有采集，需结合相关日志判断                                   |
| 请求 ID、IP、用户代理 | 有记录时可用于关联同一次请求；页面没有按请求 ID 搜索的专用输入框                             |

用户名按当前有效用户信息解析，不是操作发生时的用户名快照。调查改名或账户停用后的历史操作时，应结合用户 ID 核实。敏感字段脱敏不代表整条描述或错误适合公开分享。

## 查看统计并刷新结果

桌面端显示日志总数、成功日志、失败日志、唯一操作者、唯一目标数和唯一 IP 等汇总，以及每日趋势、操作类型、类别和成功／失败分布。移动端不展示统计区域。

统计使用当前筛选条件下、对统计操作获准的全部记录，不只当前页。需要注意：

- **唯一目标数**只按目标用户 ID 去重，不包含仅有资源 ID 的目标；**系统触发日志**按没有操作者用户 ID 的记录计数。
- 趋势图按 UTC 日期归组，而列表时间按浏览器本地时间显示；跨时区或接近零点的记录可能出现在不同日期。
- 列表默认每页 10 条；桌面端可切换为 20、50 或 100 条。翻页和改变每页条数只更新列表。
- 顶部**刷新**只重新加载当前页列表，使用当前表单条件；不会刷新统计或筛选目录，也不会自动移动日期范围。
- 需要同步更新统计时，重新应用筛选条件或重新加载页面。页面不会自动轮询。

列表、统计和目录分别加载，权限范围也可能不同，因此列表总数与图表数量不一定一致。加载失败时旧数据可能保留；请留意错误提示，确认成功加载后再据此判断。

## 权限与可用范围

旧权限及影子模式沿用 `SYSTEM_BUSINESS_LOG_READ` 的有效权限检查。IAM 强制模式要求当前身份属于有效的部署管理全局组，且该组具有 `SYSTEM_BUSINESS_LOG_READ`。账号所有者、账号策略、私有组或个人附加权限不能替代该资格。接口使用登录身份，不接受 OAuth 访问令牌。

| 操作                   | Action                                       | 资源                                                  |
| ---------------------- | -------------------------------------------- | ----------------------------------------------------- |
| 获取操作类型和类别目录 | `quyan:system:business_log:GetFilterOptions` | `acs:platform:*:platform:system/business-log-options` |
| 查看列表及其中的详情   | `quyan:system:business_log:ListLogs`         | `acs:platform:*:platform:business-log/<日志 ID>`      |
| 查看统计               | `quyan:system:business_log:GetLogStatistics` | 同上，逐条授权后计入统计                              |

三种操作分别授权，目录访问不读取业务日志，也不授予列表或统计权限。显式 Deny 优先于 Allow；没有匹配 Allow 的记录不会进入列表或统计。列表先按权限过滤，再计算总数和分页；统计的去重和分布也只计算对该操作获准的记录。

单次查询固定数据截止范围，较新的日志会在下一次查询中出现。读取期间资格、策略、角色会话或参与结果计算的记录发生变化时，可能拒绝返回，请重新查询。影子模式额外评估 IAM，但保留原有响应行为。

## 常见问题

| 问题                   | 处理方法                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 输入资源 ID 后没有结果 | 清空“目标”，该条件只匹配用户；按操作类型和时间查找资源操作                                                                   |
| 图表没有随刷新更新     | 顶部刷新只更新列表，重新应用筛选或重新加载页面                                                                               |
| 选择失败后仍显示成功   | 清空状态筛选，按记录实际标签核对当前版本的结果                                                                               |
| 操作目录为空但列表可见 | 检查目录读取权限和加载错误，目录与列表分别授权                                                                               |
| 找不到较早的操作       | 核对筛选、当前用户状态和授权范围，再检查[数据归档与清理]({{DOCS_BASE_URL}}/zh-CN/data-lifecycle)；没有记录不能证明操作未发生 |
