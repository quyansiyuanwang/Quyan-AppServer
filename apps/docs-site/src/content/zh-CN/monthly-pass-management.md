# 月卡管理

月卡管理用于创建可兑换的月卡方案、向指定用户发放额度，以及查询抵扣流水。进入月卡管理页后，根据任务选择 **模板管理**、**用户分配** 或 **使用流水**。

## 使用前提

账号需要相应读取权限才能看到页签，需要写入权限才能操作。已启用两步验证的账号变更模板或分配时，可能需要完成二次验证。

模板的 **状态** 与 **推出状态** 相互独立。新建和复制的模板均为启用、未推出；手动分配只要求模板启用，无需先推出。

## 创建或复制模板

1. 在 **模板管理** 单击 **创建模板**；也可找到已有模板，单击 **复制模板**。
2. 填写唯一的模板名称、原价、折扣和有效期。有效期为 1～3650 天，默认 30 天。折扣按百分比填写，100 表示原价，80 表示八折，0 表示免费兑换。
3. 核对价格预览。折后价为原价乘以折扣百分比；推导额度为原价乘以保存时的充值倍率，按金额计量。降低折扣不会同比减少额度。
4. 按需配置每日额度、限购次数和统计天数、允许站内余额兑换、允许渠道与模型，以及多窗口规则。限购次数和天数需同时填写或同时留空。
5. 单击 **确认** 并完成页面要求的验证。保存后核对列表；供用户自助兑换时，再单击 **推出**。

复制会打开预填原模板内容的创建表单，不会复制用户分配记录或保留原推出状态。保存副本时按当前充值倍率重新计算额度。

原价和金额额度最多支持 4 位小数；按次或按 Token 的分配额度必须为正整数。允许渠道或模型留空表示未设置该维度的月卡限制，仍需满足正常的渠道访问与模型可用条件。更改渠道后请重新核对模型选择。

## 调整模板与停止兑换

在模板列表按关键词和状态筛选后，单击 **搜索**，再选择目标行的操作。

| 操作                   | 对新兑换或分配的影响                 | 对已发放月卡的影响                             |
| ---------------------- | ------------------------------------ | ---------------------------------------------- |
| 下架                   | 停止自助兑换，仍可手动分配启用的模板 | 不会单独停止已发放月卡                         |
| 关闭允许站内余额兑换   | 已推出的方案仍可展示，但无法自助兑换 | 不会单独停止已发放月卡                         |
| 编辑价格、额度或有效期 | 后续发放使用新的默认值               | 不改写已有月卡的总额度、有效期和分配时额度设置 |
| 编辑允许渠道或模型     | 后续月卡使用新的覆盖范围             | 普通月卡也使用当前关联模板的覆盖范围           |
| 将模板状态设为停用     | 停止该模板的新兑换与新分配           | 关联月卡无法继续参与抵扣                       |
| 删除模板               | 无法再兑换或分配                     | 关联月卡无法继续参与抵扣；页面没有恢复入口     |

编辑表单每次保存都会按当前充值倍率重新计算推导额度，即使只是修改名称。保存后请核对价格、额度与推出状态。模板删除和分配删除均不会自动退还购卡款。

限购按同一用户、同一模板在滚动统计天数内的新建分配计数，包含手动发放等来源及已停用分配，不等同于付费购买次数；手动发放本身不受自助兑换限购拦截。

## 向单个用户分配月卡

1. 在 **用户分配** 单击 **分配月卡**，选择 **单用户分配**。
2. 搜索并选择用户，再选择启用的模板。选定模板会按其有效期调整表单结束时间，请在选择后核对时间。
3. 设置开始、结束时间和计量方式。总额度留空时使用模板默认额度；每日额度留空时，新建分配会沿用模板每日额度，并不一定表示不限。
4. 如需自定义窗口，在本次分配中添加规则；空白表单不会自动复制模板的整组多窗口规则。
5. 填写备注，单击 **确认**。保存后用用户和模板筛选，再单击 **搜索** 核对分配。

手动分配不会扣用户余额。单用户分配每次都新建一张月卡，不会合并或延长旧月卡。到达开始时间且模板、分配均启用，并有可用额度时，月卡才可能抵扣符合条件的请求。

快捷操作中的 **设置时长** 以开始时间重算结束时间；**增加时长**、**减少时长** 及结束时间偏移只调整结束时间。结束时间必须晚于开始时间。

## 批量发放或续期

1. 在分配对话框选择 **批量分配**，选择发放模式，并核对目标用户范围。
2. 若只向手动选中的用户发放，先 **清空选择**，清除关键词和用户组筛选，搜索后选择所需用户，并保持“包含当前筛选结果中的全部用户”未勾选。
3. 若向所有匹配用户发放，设置关键词或用户组，勾选 **包含当前筛选结果中的全部用户**。**全选当前结果** 也会开启这一选项。
4. 设置模板、时间、额度和备注后单击 **确认**。查看结果中的新增、延长和失败数量，并到分配列表核对成功项。

> 当前只要提交时保留关键词或用户组筛选，所有匹配且在管理范围内的用户都会并入批量目标，即使“全部用户”未勾选。候选列表只加载前 100 人，界面的可见人数不是服务器实际目标上限。需要严格限定人员时，请清除筛选后逐个选择，或使用单用户分配。

| 发放模式           | 处理方式                                                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 重复发放，新增月卡 | 为每个目标创建一张独立月卡                                                                                                             |
| 延长现有同模板月卡 | 查找结束时间最晚的未删除同模板月卡；其结束时间不早于表单开始时间时，增加“表单结束时间减开始时间”的时长，并增加本次总额度；否则新建月卡 |

续期中的“总额度”是增量，留空使用模板默认额度。已用额度保持不变，总额度和剩余额度增加；旧月卡的开始时间及启停状态保持不变，因此延长已停用月卡不会自动启用。计量方式与旧月卡不一致时续期失败。单次编辑分配中的“总额度”则是修改后的总量，两者不要混用。

批量操作逐用户处理，可能部分成功。成功提示不代表每项成功；失败不会撤销其他成功项。当前结果区只展示数量汇总，请逐用户核对后再处理失败项。重复提交整个批次会再次新增月卡或增加额度和时长。

## 编辑或删除分配

在 **用户分配** 按用户、模板和状态查询，找到记录后单击 **编辑**。可以调整时间、额度、窗口、备注和启停状态，不能改换所属用户或模板。

修改总额度不会清零已用额度；新总额度不得小于已用额度，剩余额度按新总额度减去已用额度计算。切换计量方式不会自动换算历史用量，应避免对已消费月卡直接改变单位。清空已有备注后提交不会移除原备注。

暂停单张月卡时，将分配状态改为 **停用**；移除时单击 **删除** 并确认。删除后停止抵扣，页面没有恢复入口，也不会自动退款。“启用”仅表示分配状态，不代表当前时间、模板状态和额度均满足使用条件。

## 窗口额度的当前限制

每日额度使用滚动窗口，未指定时长时默认回看 24 小时，不是每天零点重置。窗口恢复不会补充月卡总额度或延长有效期。

**多窗口额度** 可保存最多 20 条规则，每条设置额度、计量方式和 1～720 小时的时长；同一计量方式和时长的组合不能重复。目前请求可用性检查会参考多窗口规则，但最终抵扣仍按总额度与单项每日额度处理，尚不支持把多窗口规则作为严格的并行结算上限。请勿据此承诺“每小时、每天分别严格封顶”；配置后应结合实际流水核对。

## 查询使用流水

1. 切换到 **使用流水**，按需选择用户、模板、模型和时间范围。
2. 单击 **搜索**，查看抵扣金额、请求成本、剩余成本和创建时间。
3. 对照分配中的已用、剩余额度，以及 [消费记录]({{DOCS_BASE_URL}}/zh-CN/consumption-records) 排查扣费。

一条流水只表示该张月卡对请求的一次抵扣，剩余成本可能继续由其他月卡或余额承担，不能直接当作最终余额扣款。没有流水也不证明没有请求，可能未命中该月卡或未发生抵扣。

顶部刷新只重新查询当前页签，不会重载所有候选选项。用户搜索默认只取前 50 条，找不到用户时请缩小关键词；选项为空也可能是读取权限不足。不要因为筛选选项中没有某项就删除或重建资源。

## 所需权限与资源授权

| 操作                                     | 所需权限                        |
| ---------------------------------------- | ------------------------------- |
| 查看模板                                 | `MONTHLY_PASS_TEMPLATE_READ`    |
| 创建、复制、编辑、推出、下架、删除模板   | `MONTHLY_PASS_TEMPLATE_WRITE`   |
| 查看分配记录                             | `MONTHLY_PASS_ASSIGNMENT_READ`  |
| 新建、编辑、删除分配，包括批量发放与续期 | `MONTHLY_PASS_ASSIGNMENT_WRITE` |
| 查看使用流水                             | `MONTHLY_PASS_USAGE_READ`       |

启用 IAM 强制授权后，操作者还需部署管理员配置的全局管理组资格。页面可见或拥有读取权限，不代表可以写入；账号自己的策略和用户组不能自行取得全局管理资格。

以下资源路径统一加前缀 `acs:platform:*:platform:`，标识替换为实际 ID。

| 操作对应的 Action                                                                                                       | 资源路径                                                                      |
| ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `quyan:monthly_pass:ListTemplates`                                                                                      | `monthly-pass-template/<templateId>`                                          |
| `quyan:monthly_pass:CreateTemplate`，也用于保存副本                                                                     | `monthly-pass-template-control` 及新建的 `monthly-pass-template/<templateId>` |
| `quyan:monthly_pass:UpdateTemplate`、`PublishTemplate`、`UnpublishTemplate`、`DeleteTemplate`（均使用相同 Action 前缀） | 目标 `monthly-pass-template/<templateId>`                                     |
| `quyan:monthly_pass:ListUserPasses`                                                                                     | `monthly-pass/<userId>/<passId>`                                              |
| `quyan:monthly_pass:ListUsages`                                                                                         | `monthly-pass-usage/<userId>/<passId>/<usageId>`                              |
| `quyan:monthly_pass:AssignUserPass`                                                                                     | 目标 `user/<userId>`、`monthly-pass-template/<templateId>` 及新建月卡         |
| `quyan:monthly_pass:AssignUserPassBatch`                                                                                | 每个目标的用户、模板及新建或延长月卡                                          |
| `quyan:monthly_pass:UpdateUserPass`、`DeleteUserPass`（相同前缀）                                                       | 目标 `monthly-pass/<userId>/<passId>`                                         |
| `quyan:monthly_pass:GetFilterOptions`                                                                                   | 对应模板、模型定价、渠道及用户组资源；不替代页面实际调用的各目录接口权限      |

列表只统计和分页获准记录。关联用户名、模板详情和模板名称还需对应读取 Action 对关联资源的授权。窗口用量只有在相关有效流水均可读取时才返回，字段缺失不能视为用量为零。

新建分配必须允许用户、模板和生成的月卡 ARN；可用 `monthly-pass/<userId>/*` 限定发放范围。仅允许用户和模板不足以创建月卡。未授权的关联详情可能隐藏；按筛选发现但未获准的用户不会出现在批量结果中。权限、模板或月卡用量在操作期间改变时，变更可能失败，请刷新核对后重新操作。

## 常见问题

| 现象                       | 处理建议                                                                 |
| -------------------------- | ------------------------------------------------------------------------ |
| 用户看不到可兑换方案       | 检查模板是否启用并已推出，再核对用户读取权限；关闭余额兑换的方案仍可展示 |
| 有剩余额度却未抵扣         | 检查模板与分配状态、有效期、窗口额度、模型和渠道范围，并核对请求流水     |
| 保存失败或提示额度冲突     | 刷新分配，核对最新已用额度、单位、权限和模板状态后重试                   |
| 提交后断线，不确定是否成功 | 先查询模板或目标用户分配；批量须逐项核对，不直接重交整个批次             |
