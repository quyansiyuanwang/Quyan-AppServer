# 系统日志

在核心管理站的**系统日志**排查 API 请求和服务端运行问题。**请求日志**展示已经记录的 API 请求与统计，**服务器日志**读取当前服务端日志目录中的文件；两个标签页分别授权。

业务操作审计见[业务日志]({{DOCS_BASE_URL}}/zh-CN/business-logs)，AI 推理内容调查见[AI 请求日志]({{DOCS_BASE_URL}}/zh-CN/ai-request-logs)。

## 开始前

- 查看请求日志需要 `API_LOG_READ` 或 `SYSTEM_LOG_READ` 任一权限。
- 查看服务器日志需要 `SYSTEM_SERVER_LOG_READ`。
- IAM 强制模式还要求对应部署管理全局组资格，以及列表、详情、统计或文件的独立资源授权，详见下文。

本页不提供编辑、删除日志或撤销请求的操作。页面不会自动轮询；排查时应手动刷新，并确认数据对应的筛选条件和时间。

## 查找 API 请求

1. 打开**请求日志**，选择需要的方法和状态码，可多选。
2. 按路径、用户、请求 ID 或 IP 地址缩小范围。文本输入确认或离开已修改字段后会重新查询，选择器变更也会立即查询。
3. 按需指定**日期范围**。查询范围包含起止时刻，跨度最多 30 天。
4. 查看记录的时间、用户、路径、大小和状态码，再展开详情。

| 条件              | 匹配方式与限制                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| 方法、状态码      | 同一项内匹配任一所选值，不同筛选项组合使用；状态码按具体值匹配，不是自动匹配整个 4xx 或 5xx 范围   |
| 路径、请求 ID、IP | 部分文本匹配；请求 ID 可用于关联同一次请求的其他日志                                               |
| 用户              | 当前有效用户的用户名部分匹配，或完整用户 ID 匹配；每次最多展开 100 个用户，精确定位优先使用完整 ID |
| 日期范围          | 不选择时默认最近 30 天；指定时可查询仍保留的较早记录，但每个区间最多 30 天                         |

点击**清除筛选**会清空表单并重新查询最近 30 天，不会读取全部历史。超宽或顺序错误的日期范围会被服务端拒绝，需调整后重新查询。

更改筛选回到第一页并更新列表及统计。列表默认每页 20 条，桌面端支持切换为 10、20、50 或 100 条；翻页和调整每页条数只更新列表。顶部**刷新**更新当前页列表和统计，使用当前条件；已选择的日期范围不会自动向当前时间移动。

### 阅读请求详情

桌面端展开行首图标，移动端展开卡片中的**响应**。查询参数和请求体参数随列表返回；响应、请求头、响应头及部分大小信息在展开时另行加载，需要该条日志的详情权限。

请求大小可能来自 `Content-Length`，也可能由已保存请求体估算；显示值不保证等于原始网络流量。响应、请求头和正文可能未采集、已脱敏、简化或截断，不能用空白、`null` 或占位提示推断原始请求没有内容。日志保留的脱敏内容也不能作为原始字节重放。

用户名按当前有效用户信息解析，不是历史用户名快照；缺少用户名不等于匿名请求，需同时核对用户 ID。HTTP 状态码描述 HTTP 结果，不必然代表业务成功；调查 AI 流式中断、额度结算等问题时还应查看专门的 AI 请求记录。

详情加载失败后，收起再展开不会重试。请先点击顶部**刷新**，再展开记录；仍为空时核对详情权限和采集范围。

## 理解统计口径

汇总和图表使用当前筛选条件下，对统计操作获准的全部 API 日志，不只当前页。手机端也可查看统计。

- **成功请求**按 HTTP 2xx 计数，**重定向请求**按 3xx，**客户端错误**按 4xx，**服务端错误**按 5xx。
- **每日请求趋势**展示总量、4xx 和 5xx 数量，不是错误率。
- 按日期归组使用服务端本地时区，列表时间使用浏览器本地时区；跨时区时需核对实际时间。
- **路径分布 Top 12**按归一化路径合并，部分数字或长标识段会显示为 `:id`，不是每个原始 URL 的独立数量。
- 列表、详情和统计分别授权，统计数量可能与列表不同；统计失败时初始零值或旧图表不应当作成功查询结果。

### 哪些请求可能缺失

通用 API 日志不保证覆盖全部流量。成功的高频请求，例如 AI 中转、Token 刷新和部分心跳，可能跳过记录；部分路径无论成功或失败都不记录。失败的中转请求可能被记录，其请求体也可能保留脱敏或截断内容。

日志写入存在短暂延迟，写入失败或缓冲压力也可能丢失记录。未查到请求时，先核对时间、权限、采集范围和相关专用日志，不要仅凭空列表认定请求未发生。页面查询当前日志库，已归档记录需到[数据归档与清理]({{DOCS_BASE_URL}}/zh-CN/data-lifecycle)核对。

## 查阅服务器日志文件

1. 切换到**服务器日志**，选择 `combined` 或 `error` 日志类型。文件按修改时间倒序排列，页面会自动加载当前选中文件，或列表中的首个文件。
2. 选择要排查的文件。`.log.gz` 为压缩文件，页面可以读取，不需要先下载解压。
3. 设置**最近行数**，范围 1–2000，默认 200。更改行数会重新加载所选文件。
4. 输入关键词后点击**加载内容**或按 Enter。清空关键词后也需重新加载，才会恢复查看文件末尾。
5. 核对内容区域显示的文件名、修改时间、搜索词及总行数、匹配行数和返回行数。

搜索只在所选文件内逐行执行，不区分大小写，按字面文本匹配，不支持正则表达式或跨文件搜索。未搜索时显示最后若干行；搜索时显示最后若干条匹配行，顺序保持文件中的先后。截断提示表示还有更多匹配行未返回，不表示文件已被修改或删除。

**刷新文件**和该标签页下的顶部**刷新**会重新列出文件并加载选中文件；所选文件已不在列表时，可能改为首个文件。文件列表为空可能是当前类型没有文件，也可能没有获准文件。界面没有完整文件下载、持续跟随新日志或删除文件的操作。

文件内容按保存的文本展示，不要假设它会像 API 详情一样对所有内容再次脱敏。共享片段前应核对其中的用户与运维信息。

## 权限与可用范围

IAM 强制模式下，这些接口使用登录身份，不接受 OAuth 访问令牌。API 日志要求有效部署管理全局组中的 `API_LOG_READ` 或 `SYSTEM_LOG_READ` 任一资格；服务器日志要求该组中的 `SYSTEM_SERVER_LOG_READ`。账号策略、个人附加权限、私有组或角色策略不能替代部署资格。

| 操作                 | Action                                   | 资源                                                   |
| -------------------- | ---------------------------------------- | ------------------------------------------------------ |
| API 日志列表         | `quyan:system:log:ListLogs`              | `acs:platform:*:platform:api-request-log/<日志 ID>`    |
| API 日志详情         | `quyan:system:log:GetLogDetail`          | 同上，针对指定日志                                     |
| API 日志统计         | `quyan:system:log:GetLogStatistics`      | 同上，逐条授权后参与统计                               |
| 服务器文件列表       | `quyan:system:server_log:ListFiles`      | `acs:platform:*:platform:server-log-file/<完整文件名>` |
| 服务器文件内容和搜索 | `quyan:system:server_log:GetFileContent` | 同上，针对指定文件                                     |

每种操作分别授权。列表不授予详情或统计，文件列表不授予文件读取。日志 ID 是记录 ID，不是请求 ID。压缩与未压缩文件是独立资源，例如 `combined-2026-10-14.log` 与 `combined-2026-10-14.log.gz` 分别授权。

显式 Deny 优先于 Allow，不能使用另一旧权限别名绕过。角色会话按自身有效策略授权，不继承调用用户的全局组 Allow，但执行身份仍须具备部署资格。

API 列表先按权限过滤再计算总数和分页；统计的总数、去重及分布仅涵盖对统计获准的记录。服务器文件列表只返回获准文件。没有可见记录不能证明部署中没有对应日志。

查询使用本次数据边界，较新日志在后续查询中出现。读取期间资格、策略、绑定、角色会话或参与结果计算的日志变化时，请求可能拒绝返回，需重新查询；不可安全读取的 API 详情也可能返回权限拒绝。旧权限和影子模式保留原有权限检查与响应，影子模式额外评估 IAM。

## 常见问题

| 问题                              | 建议                                                                 |
| --------------------------------- | -------------------------------------------------------------------- |
| 清除筛选后找不到一个月前的请求    | 显式选择较早的日期区间，每段不超过 30 天，并检查归档状态             |
| 看得到 API 记录但响应或请求头为空 | 刷新列表后重开详情，核对详情授权及是否采集、脱敏或截断               |
| 文件内容与当前搜索词或文件不一致  | 加载可能失败并保留旧内容；核对内容区域的文件名和已应用搜索词，再加载 |
| 选择文件后只有部分匹配结果        | 增加行数并检查截断提示；最多返回最后 2000 条匹配行                   |
| 图表和列表数量不同                | 核对各自权限、筛选条件与加载结果，两者独立查询                       |

API 列表、统计、文件列表和内容加载失败时均可能保留旧结果。页面当前表单不一定对应仍显示的数据，请确认成功加载后再作判断。
