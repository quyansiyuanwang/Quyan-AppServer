## 概述

本项目使用 Vue-i18n v11 实现国际化，支持英文 (en) 和简体中文 (zh-CN) 两种语言。

## 配置

### 核心配置 (locales/index.ts)

```typescript
const i18n = createI18n({
  legacy: false, // 使用 Composition API 模式
  locale: savedLocale, // 从 localStorage 读取，默认 'zh-CN'
  fallbackLocale: 'en', // 回退语言
  messages: { en, 'zh-CN': zhCN },
  globalInjection: false,
})
```

### 支持的语言

| 语言     | 代码    | 翻译文件           |
| -------- | ------- | ------------------ |
| English  | `en`    | `locales/en.ts`    |
| 简体中文 | `zh-CN` | `locales/zh-CN.ts` |

### 语言持久化

用户选择的语言保存在 localStorage:

```typescript
// 键名: 'Util-Locale'
localStorage.setItem(StorageKey.Util.LOCALE, locale)
```

## 使用方式

### i18ns 辅助函数

```typescript
import { i18ns } from '@/locales'

// 基本翻译
i18ns.t('key')

// Ref 包装的翻译（响应式）
i18ns.tref('key')

// 带参数的翻译
i18ns.tf('key', { name: 'John' })

// 带复数处理
i18ns.tf('key', { count: 5 }, 5) // 自动添加 's' 参数

// 条件翻译
i18ns.or_t(isActive, 'status.active', 'status.inactive')

// 返回函数（用于 Element Plus render）
i18ns.tc('key') // 返回 () => translatedText
```

### 在组件中使用

```vue
<template>
  <!-- 全局注入的 i18ns -->
  <span>{{ $i18ns.t('key') }}</span>

  <!-- 使用 i18ns -->
  <span>{{ i18ns.t('button.confirm') }}</span>
</template>

<script setup lang="ts">
import { i18ns } from '@/locales'
</script>
```

### 切换语言

```typescript
import { setLocale, getLocale, type Locale } from '@/locales'

// 获取当前语言
const currentLocale: Locale = getLocale()

// 切换语言
setLocale('en')
setLocale('zh-CN')
```

## 类型安全

### 翻译键类型

```typescript
// 从英文翻译文件推导所有可用键
export type I18nENAvailableKeys = NestedKeys<typeof en>

// 编译时检查中英文键一致性
type _AssertKeys = Assert<Equal<EnKeys, ZhKeys>>
```

**效果**:

- 使用 `i18ns.t('invalid.key')` 会得到 TypeScript 编译错误
- 如果 en.ts 和 zh-CN.ts 的键不一致，编译会失败

### 嵌套键支持

```typescript
// 翻译文件结构
export default {
  button: {
    confirm: 'Confirm',
    cancel: 'Cancel',
  },
  message: {
    warning: {
      sessionExpired: 'Session Expired',
    },
  },
}

// 使用嵌套键
i18ns.t('button.confirm') // 'Confirm'
i18ns.t('message.warning.sessionExpired') // 'Session Expired'
```

## 翻译文件结构

### 文件组织

```
src/locales/
├── index.ts     # i18n 配置和辅助函数
├── en.ts        # 英文翻译
└── zh-CN.ts     # 简体中文翻译
```

### 翻译键组织示例

```typescript
// en.ts
export default {
  // 按钮
  button: {
    confirm: 'Confirm',
    cancel: 'Cancel',
    save: 'Save',
    delete: 'Delete',
  },
  // 消息
  message: {
    warning: {
      sessionExpired: 'Session Expired',
      autoRedirectToLogin: 'Your session has expired...',
      permissionUpdated: 'Your permissions have been updated...',
    },
    error: {
      forbidden: 'Access Denied',
      forbiddenWithMessage: 'Access Denied: {msg}',
    },
  },
  // 错误
  error: 'Error',
  // 通知
  notification: {
    tokenExpiredDueToUpdate: {
      title: 'Permission Changed',
      message: 'Your permissions have been updated...',
    },
  },
}
```

## 事件总线集成

### 语言变更事件

```typescript
// 监听语言变更
i18nEventBus.on('LOCALE_CHANGED', (newLocale: string) => {
  console.log('Language changed to:', newLocale)
})

// 触发语言变更
i18nEventBus.emit('LOCALE_CHANGED', 'en')
```

## 添加新翻译

### 步骤

1. 在 `locales/en.ts` 中添加英文翻译:

```typescript
export default {
  // ... 现有翻译
  newFeature: {
    title: 'New Feature',
    description: 'This is a new feature',
  },
}
```

2. 在 `locales/zh-CN.ts` 中添加对应的中文翻译:

```typescript
export default {
  // ... 现有翻译
  newFeature: {
    title: '新功能',
    description: '这是一个新功能',
  },
}
```

3. 在组件中使用:

```typescript
i18ns.t('newFeature.title') // 'New Feature' / '新功能'
i18ns.t('newFeature.description') // 'This is a new feature' / '这是一个新功能'
```

### 注意事项

- **键一致性**: en.ts 和 zh-CN.ts 的键必须完全一致，否则 TypeScript 编译会失败
- **类型推导**: 类型从 en.ts 推导，添加新键后类型会自动更新
- **参数占位**: 使用 `{paramName}` 语法进行参数替换
